## 概要

画像→X投稿文生成は、アップロードした画像をAIが詳細に分析し、エンゲージメントの高いXポスト候補を自動生成するツールです。

<Info>
  画像をアップロードするだけで、異なるアプローチの5つの投稿候補を自動生成。あなたのXプラン（無料・Premium・Premium+）に合わせた最適な投稿形式を提案します。
</Info>

### 主な用途

- **SNS運用**: 画像投稿時の魅力的なキャプション作成
- **マーケティング**: 商品画像からの訴求力のある投稿文生成
- **クリエイター活動**: 作品・写真の魅力を最大限に伝える投稿作成
- **情報発信**: 画像の内容を効果的に伝えるポスト作成

## 料金

画像→X投稿文生成は、1画像の処理につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| 画像からポスト生成 | 10pt（画像毎） |

<Note>
  画像のサイズや生成される文字数に関わらず、1画像につき**10ポイント固定**です。
</Note>

## 入力オプション

### Xバッジタイプ

あなたのXプランに合わせてバッジタイプを選択できます。

<CardGroup cols={3}>
  <Card title="バッジなし（無料プラン）" icon="user">

  <Card title="青バッジ（X Premium）" icon="badge-check">
    最大25,000文字まで可能（読みやすさを考慮して調整）

  <Card title="金バッジ（X Premium+）" icon="crown">

### 画像アップロード

| 項目 | 仕様 |
|------|------|
| 対応形式 | JPEG、JPG、PNG、GIF |
| 最大サイズ | 10MB |
| 入力方法 | ファイル選択またはドラッグ&ドロップ |

<Warning>
  10MBを超える画像はアップロードできません。大きな画像は事前に圧縮してください。
</Warning>

## 出力フォーマット

### 生成されるポスト候補

AIは5つの異なるアプローチでポスト候補を生成します。

| パターン | 説明 | 特徴 |
|----------|------|------|
| 感情訴求型 | 画像から感じる感情や印象を共有 | 共感を得やすい、リツイートされやすい |
| 情報提供型 | 画像の特徴や背景情報を説明 | 専門性をアピール、信頼性向上 |
| 質問投げかけ型 | フォロワーの参加を促す質問 | コメント誘発、エンゲージメント向上 |
| ストーリー型 | 画像から想像される物語を展開 | 興味を引く、滞在時間向上 |
| キャッチー型 | インパクトのある表現で注目を集める | いいね獲得、バズりやすい |

### ポスト構成要素

| 要素 | 仕様 |
|------|------|
| 文字数 | バッジタイプに応じた制限に準拠 |
| 絵文字 | 効果的に使用してビジュアルインパクトを向上 |
| ハッシュタグ | 最大3つ、トレンドを意識した選択 |

<Info>
  各ポストは実際にXに投稿できる完成形で出力されます。コピーしてそのまま投稿可能です。
</Info>

## 利用手順

<Steps>
  <Step title="バッジタイプの選択">
    あなたのXプランに合わせてバッジタイプを選択します。

    **選択肢:**
    - バッジなし（無料プラン）: 140文字制限
    - 青バッジ（X Premium）: 長文投稿可能
    - 金バッジ（X Premium+）: 長文投稿可能
  </Step>
  <Step title="画像のアップロード">
    分析したい画像をアップロードします。

    **アップロード方法:**
    - ファイル選択ボタンをクリック
    - または画像をドラッグ&ドロップ

    <Note>
      JPEG、PNG、GIF形式、最大10MBまで対応しています。
    </Note>
  </Step>
  <Step title="ポスト生成">
    「画像からXポスト生成」ボタンをクリックして生成を実行します。

    <Warning>
      生成には10ポイント消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    生成完了後、5つの異なるアプローチのポスト候補が表示されます。
    各候補はカード形式で表示され、アプローチの種類が明示されます。
  </Step>
  <Step title="コピー・投稿">
    気に入ったポスト候補をコピーボタンでクリップボードにコピーし、Xに投稿します。
  </Step>
</Steps>

## 結果の保持

<Warning>
  分析結果は**SNSツールキャッシュ**に保存されます。
  履歴ページから過去の生成結果を確認できます。

## 活用例

### 商品プロモーション

商品画像から訴求力のある投稿文を生成。

1. 商品画像をアップロード
2. Premium/Premium+バッジを選択（長文投稿で詳細説明）
3. 5つの候補から最も商品の魅力が伝わるものを選択
4. Xに投稿してプロモーション

### クリエイター活動

作品・イラスト・写真の魅力を伝える投稿。

1. 作品画像をアップロード
2. 「感情訴求型」「ストーリー型」の候補を参考に
3. 作品の背景やこだわりを伝える投稿を選択
4. ハッシュタグを活用してリーチを拡大

### 日常投稿

旅行・食事・イベントなどの思い出を共有。

1. 思い出の写真をアップロード
2. 「バッジなし」で140文字以内のカジュアルな投稿
3. 「質問投げかけ型」でフォロワーとの交流を促進

## よくある質問

<AccordionGroup>
  <Accordion title="どのような画像が分析できますか？">
    JPEG、PNG、GIF形式の画像で、10MB以下のものが分析可能です。
    写真、イラスト、グラフィック、スクリーンショットなど、様々な種類の画像に対応しています。
  </Accordion>
  <Accordion title="生成にどのくらい時間がかかりますか？">
    通常、10〜30秒程度で5つのポスト候補が生成されます。
    画像の複雑さやサイバー負荷によっては、もう少し時間がかかることがあります。
  </Accordion>
  <Accordion title="バッジタイプはどれを選べばいいですか？">
    実際に使用しているXアカウントのプランに合わせて選択してください。
    - **無料プラン**: バッジなし（140文字制限）
    - **X Premium**: 青バッジ（長文可能）
    - **X Premium+**: 金バッジ（長文可能）
  </Accordion>
  <Accordion title="生成されたポストを編集できますか？">
    はい、生成された候補はあくまで提案です。
    コピー後に自由に編集してから投稿することを推奨します。
  </Accordion>
  <Accordion title="ハッシュタグは自動で付きますか？">
    はい、各ポスト候補には最大3つのハッシュタグが自動的に含まれます。
    画像の内容に関連したトレンドを意識したハッシュタグが選択されます。
  </Accordion>
  <Accordion title="同じ画像を再分析するとポイントは消費されますか？">
    はい、再分析ごとに10ポイントが消費されます。
    過去の分析結果は履歴ページから確認できます。
  </Accordion>
  <Accordion title="人物が写っている画像も分析できますか？">
    はい、人物が写っている画像も分析可能です。
    ただし、プライバシーに配慮した投稿文が生成されます。
  </Accordion>
  <Accordion title="生成結果が期待と異なる場合はどうすればいいですか？">
    以下をお試しください：
    - 別の画像を使用（より特徴的な画像の方が良い結果が得られます）
    - バッジタイプを変更（長文/短文で異なるアプローチ）
    - 再生成を実行（毎回異なる候補が生成されます）
  </Accordion>
</AccordionGroup>
