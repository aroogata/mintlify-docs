## 概要

Xスレッドジェネレーターは、Webコンテンツから魅力的で拡散力のあるXスレッドを自動生成するAIツールです。

<Info>
  記事URLを入力するだけで、エンゲージメントを高めるXスレッドを自動生成。複数のスレッドパターン、AIモデル選択、カスタムURL対応で、あなたのコンテンツをXで最大限に活用できます。
</Info>

### 主な用途

- **コンテンツマーケティング**: ブログ記事やニュースをXスレッドで効果的に拡散
- **アフィリエイト**: カスタムURL機能でトラッキングリンクに対応
- **SNS運用**: 複数記事を一括処理して効率的な投稿準備
- **情報発信**: 専門記事を分かりやすいスレッド形式で発信

## 料金

Xスレッドジェネレーターは、1URLの処理につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| スレッド生成 | 10pt（URL毎） |

<Note>
  複数URLを処理する場合は、URL数×10ポイントが消費されます。
  例：3URL処理 = 30ポイント
</Note>

## 入力オプション

### 記事URL入力

スレッド化したい記事のURLを入力します。

| 項目 | 仕様 |
|------|------|
| 入力形式 | URL（https://...） |
| 複数入力 | 「URL追加」ボタンで追加可能 |
| カスタムURL | 各URLに対応する表示用URLを指定可能（任意） |

<Tip>
  **カスタムURL機能**を使用すると、元記事URLとは異なるURLをスレッド内に表示できます。
  アフィリエイトリンク、UTMパラメータ付きURL、短縮URLなどに対応しています。
</Tip>

### スレッドパターン

目的に応じて5種類のスレッドパターンから選択できます。

| パターン | アイコン | 説明 | 特徴 |
|----------|---------|------|------|
| 丁寧解説系 | 📚 | 親切で分かりやすく、信頼性の高い詳細説明 | デフォルト。初心者向けコンテンツに最適 |
| 煽り・センセーショナル系 | 🚨 | 読者の危機感や興味を強く刺激 | 「知らないと損する」「あなたは大丈夫？」 |
| ストーリー・体験系 | 📖 | 物語性や体験談風で読者の感情に訴求 | ビフォー・アフター、感動ストーリー |
| データ・事実重視系 | 📊 | 客観的なデータと事実を中心に情報提供 | 統計、数値、客観的な分析 |
| 疑問提起・考察系 | ❓ | 読者に考えさせる問いかけで興味を引く | 「なぜ○○なのか？」「本当に○○？」 |

<Info>
  **推奨パターン**:
  - 初心者向け情報発信: 丁寧解説系
  - バズを狙いたい: 煽り・センセーショナル系
  - 共感を得たい: ストーリー・体験系
  - 信頼性重視: データ・事実重視系
  - 興味を引きたい: 疑問提起・考察系
</Info>

### AIモデル選択

複数のAIモデルから選択できます。

| モデル | 特徴 |
|--------|------|
| GPT-4o | 高品質なテキスト生成（デフォルト） |
| Gemini 2.5 Flash Lite | 高速な処理に最適 |
| その他 | 管理画面から登録されたモデル |

<Note>
  モデルによって生成結果の文体やニュアンスが異なります。
  いくつかのモデルを試して、目的に合ったモデルを見つけてください。
</Note>

## 出力フォーマット

生成されるXスレッドは以下の形式です。

### スレッド構成

| 項目 | 仕様 |
|------|------|
| ツイート数 | 3〜10ツイート |
| 各ツイート文字数 | 最大280文字 |
| 番号形式 | 「1/8」「2/8」「3/8」... |
| 継続マーカー | 「↓」「続き」 |
| 元記事リンク | 最終ツイートに含む |

### 出力例

```
1/8
最近話題の○○について調べてみました！
実はこれ、知らない人が多いんですが...

↓
続き

2/8
調査によると、○○を実践している人は
わずか3%しかいないそうです。

↓
続き

...

8/8
詳しくは元記事をチェック！
https://example.com/article

#キーワード #関連タグ
```

## 利用手順

<Steps>
  <Step title="記事URLの入力">
    スレッド化したい記事のURLを入力します。

    **入力方法:**
    - URLを1件入力
    - 「URL追加」ボタンで複数URL入力可能
    - 必要に応じてカスタムURL（表示用URL）を指定
  </Step>
  <Step title="設定の選択">
    スレッド生成の設定を選択します。

    **設定項目:**
    - Xバッジタイプ: バッジなし/認証バッジ/プレミアム
    - スレッドパターン: 5種類から選択
    - AIモデル: 使用するAIモデルを選択
  </Step>
  <Step title="スレッド生成">
    「スレッド生成」ボタンをクリックして生成を実行します。

    <Warning>
      生成には10ポイント（URL毎）消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    生成完了後、スレッドがツイートカード形式で表示されます。
    各ツイートは個別にコピーできます。
  </Step>
  <Step title="コピー・投稿">
    「全体をコピー」または個別コピーボタンでクリップボードにコピーし、Xに投稿します。
  </Step>
</Steps>

## カスタムURL機能

アフィリエイトリンクやトラッキングURLを使用したい場合に便利な機能です。

### 使用例

| 元記事URL | カスタムURL（表示用） |
|----------|---------------------|
| `https://example.com/article` | `https://example.com/article?ref=twitter` |
| `https://blog.com/review` | `https://affiliate.link/abc123` |
| `https://news.com/story` | `https://bit.ly/shortened` |

<Info>
  カスタムURLを指定すると、生成されたスレッド内の元記事リンクがカスタムURLに置き換えられます。
  元記事のコンテンツ抽出には元のURLが使用されるため、非公開ページのURLは指定できません。
</Info>

## 結果の保持

<Warning>
  分析結果は**SNSツールキャッシュ**に保存されます。
  履歴ページから過去の生成結果を確認できます。
</Warning>

- **履歴確認**: 「最近の分析結果を見る」ボタンから履歴ページへ
- **保存形式**: スレッド全文、処理情報を保存

## 活用例

### コンテンツマーケティング

ブログ記事をXスレッドで拡散し、アクセスを増やす。

1. ブログ記事のURLを入力
2. 「丁寧解説系」パターンを選択
3. スレッド生成→Xに投稿
4. フォロワーの反応を確認

### アフィリエイト運用

商品レビュー記事をスレッド化し、アフィリエイトリンクで収益化。

1. レビュー記事URLを入力
2. カスタムURLにアフィリエイトリンクを指定
3. 「煽り・センセーショナル系」パターンを選択
4. 生成されたスレッドを投稿

### ニュース・情報発信

最新ニュースを分かりやすくスレッド形式で発信。

1. ニュース記事URLを入力
2. 「データ・事実重視系」パターンを選択
3. 認証バッジを選択して信頼性をアピール
4. 生成されたスレッドを投稿

## よくある質問

<AccordionGroup>
  <Accordion title="一度に何URL処理できますか？">
    「URL追加」ボタンで複数URLを追加できます。
    ただし、処理にはURL数×10ポイントが消費されます。
  </Accordion>
  <Accordion title="生成にどのくらい時間がかかりますか？">
    通常、1URLあたり10〜30秒程度で生成が完了します。
    複数URLの場合は、順次処理されるため、その分時間がかかります。
  </Accordion>
  <Accordion title="どのようなURLが処理できますか？">
    公開されているWebページであれば、ほとんどのURLが処理可能です。
    ただし、ログインが必要なページ、JavaScript動的生成のみのページ、パスワード保護されたページは処理できない場合があります。
  </Accordion>
  <Accordion title="カスタムURLはどのような用途で使えますか？">
    以下のような用途で活用できます：
    - アフィリエイトリンクへの置き換え
    - UTMパラメータ付きURLでのトラッキング
    - 短縮URL（bit.ly等）への置き換え
    - 別ドメインへのリダイレクト
  </Accordion>
  <Accordion title="スレッドパターンはどれを選べばいいですか？">
    目的に応じて選択してください：
    - **一般的な情報発信**: 丁寧解説系（デフォルト）
    - **バズ・拡散を狙う**: 煽り・センセーショナル系
    - **共感を得たい**: ストーリー・体験系
    - **信頼性を重視**: データ・事実重視系
    - **興味を引きたい**: 疑問提起・考察系
  </Accordion>
  <Accordion title="AIモデルによって結果は変わりますか？">
    はい、モデルによって文体やニュアンスが異なります。
    GPT-4oは高品質な出力、Gemini Flash Liteは高速処理に向いています。
    いくつか試して、好みのモデルを見つけてください。
  </Accordion>
  <Accordion title="生成されたスレッドの文字数制限はありますか？">
    各ツイートは280文字以内に収まるように生成されます。
    Xの投稿文字数制限に準拠しています。
  </Accordion>
  <Accordion title="生成結果が期待と異なる場合はどうすればいいですか？">
    以下をお試しください：
    - 別のスレッドパターンを選択
    - 別のAIモデルを使用
    - 元記事のコンテンツ量を確認（短すぎる記事は情報が不足する場合があります）
  </Accordion>
</AccordionGroup>
