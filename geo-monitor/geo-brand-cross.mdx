## 概要

AIO引用サイトランキングは、複数のブランド・キーワード・ドメインを「グループ」として設定し、**AI検索（Google AI Overviews・ChatGPT）がどのサイトを引用しているか**を横断比較してランキング表示するツールです。自社と競合のAI引用状況を並べて可視化することで、コンテンツ戦略と競合分析の両方を支援します。

<Info>
  各グループを独立して分析し、引用が多いドメイン・ページをランキング化します。グループ間の引用格差を比較したり、1グループだけを深掘りしたりでき、結果をもとにAIが改善提案（AIインサイト）も自動生成します。
</Info>

### 主な活用シーン

- **自社 vs 競合の比較**: ブランドや製品をグループ化し、AI引用規模と引用元メディアの違いを比較
- **カテゴリ内の勢力把握**: 同カテゴリの複数サービスをグループ設定し、AI露出の差を分析
- **PR施策の効果測定**: 施策の前後で同じプロジェクトを再分析し、引用数の変化を追跡
- **引用元メディアの特定**: どの権威サイト・ページから引用されているかを把握

## 対応AIプラットフォーム

| プラットフォーム | 対応地域・言語 | 備考 |
| --- | --- | --- |
| **Google AI Overviews** | 多数の地域・言語に対応（デフォルト：日本・日本語） | 横断比較の主対象 |
| **ChatGPT** | 米国・英語のみ | 日本語分析にはGoogle AI Overviewsを使用してください |

## 料金

AIO引用サイトランキングは、**結果タイプ × グループ数**でポイントを消費します。グループ数（＝APIの呼び出し数）に比例して増加します。

| 結果タイプ | 1グループあたり |
| --- | --- |
| ドメイン分析 | **30pt** |
| ページ分析 | **30pt** |
| ドメイン＋ページ | **50pt** |

<Note>
  実際の消費は「1グループあたりのポイント × グループ数」です。

  - 例：2グループ × ドメイン＋ページ = 50pt × 2 = **100pt**
  - 例：3グループ × ドメイン分析 = 30pt × 3 = **90pt**
</Note>

その他のポイント：

| 操作 | 消費ポイント |
| --- | --- |
| AIチャット（通常） | 2pt / 質問 |
| AIチャット（Web検索オン） | 4pt / 質問 |
| AIインサイト生成 | 無料（分析実行に含まれる） |
| 結果閲覧・履歴確認・CSV出力 | 無料 |

## 比較グループの設定

各グループはブランド・製品・テーマなどを表します。**1グループから作成でき（個別分析）、2グループ以上で横断比較**になります（最大10グループ）。1グループには最大10個のターゲット（キーワード／ドメイン）を設定できます。

| ターゲット方式 | 検索スコープ | フィルター・オプション |
| --- | --- | --- |
| **キーワード** | 回答・質問の両方／質問文／回答本文 | 複数キーワードはAND条件 |
| **ドメイン** | 引用元（ソース）／検索結果／すべて | 含む・除外、サブドメイン包含 |

<Tip>
  複数キーワードはAND条件で動作します（例：「楽天カード」かつ「年会費」）。ブランドごとに別グループを作れば、横並びで比較できます。
</Tip>

## 分析条件

| 条件 | 選択肢 |
| --- | --- |
| **プラットフォーム** | Google AI Overviews / ChatGPT（米国・英語固定） |
| **地域・言語** | 多数の地域・言語に対応（デフォルト：日本・日本語） |
| **期間** | 7日間 / 30日間（推奨）/ 90日間 / 全期間 |
| **結果タイプ** | ドメイン分析 / ページ分析 / ドメイン＋ページ |

## 利用手順

<Steps>
  <Step title="プロジェクトの作成">
    プロジェクト名を入力して新規作成します。プロジェクト単位で分析履歴が永続的に保存されます。
  </Step>
  <Step title="比較グループの設定">
    比較したいブランド・キーワード・ドメインをグループとして設定します（1〜10グループ、各グループ最大10ターゲット）。
  </Step>
  <Step title="分析条件の設定">
    プラットフォーム・地域・期間・結果タイプを選択します。画面に消費ポイント（結果タイプ × グループ数）が表示されます。
  </Step>
  <Step title="分析の実行">
    「分析を実行」をクリックします。完了まで数十秒〜数分かかります。

    <Warning>
      分析が完了するまでページを離れないでください。
    </Warning>
  </Step>
  <Step title="結果の確認・深掘り">
    KPI・ランキング・AIインサイトを確認します。「AIに質問」で戦略を相談したり、CSVで結果を出力できます。
  </Step>
</Steps>

## 分析結果の見方

### グループ別KPI

グループごとに、引用数・AI検索ボリューム・引用元ドメイン数などのKPIを比較表示します。各KPIには5段階の星評価が付きます。

### ドメイン／ページランキングテーブル

| 列 | 内容 |
| --- | --- |
| 順位 | 総引用数による順位 |
| ドメイン／URL | 引用元の名称またはページURL |
| ドメインタイプ | Wikipedia / YouTube / ニュース / SNS / EC / 政府 / 教育 などの自動分類 |
| 総引用数 | 全グループ合計の引用回数 |
| グループ別引用数 | 各グループの引用回数 |

<Note>
  ヘッダーの「引用数」はAI回答の件数を、ドメイン別の引用数は各回答での引用元数を示します。1つの回答が複数サイトを引用するため、ドメイン別の合計の方が大きくなるのが通常です。列ヘッダーのクリックでソート、ドメインタイプのバッジで絞り込みができます。
</Note>

### AIインサイト

分析結果をAIが読み解き、改善提案を自動生成します。グループ数によって2つのモードがあります。

| モード | 条件 | 主な内容 |
| --- | --- | --- |
| **比較分析モード** | 2グループ以上 | スコア評価、比較サマリー、ページ分析、テーマ分析、コンテンツ戦略、アクションプラン |
| **個別分析モード** | 1グループ | スコア評価、強み分析、ギャップ分析、コンテンツ推奨、アクションプラン |

### AIチャット

分析結果を文脈として、AIアシスタントに相談できます。利用するAIモデルを選択でき、必要に応じてWeb検索を有効にできます。

| 選択できるモデル | Web検索 |
| --- | --- |
| Claude Sonnet 4.5 | ✓ |
| Gemini 2.5 Pro | ✓ |
| GPT-4.1 Chat | ✓ |
| Grok 4.1 Fast | ✓ |

通常の質問は2pt、Web検索を有効にすると4ptを消費します。競合に勝つコンテンツ戦略、上位ドメインの特性分析、経営層向けサマリー作成などに活用できます。

## CSV出力

ランキング結果をCSV形式でダウンロードできます（Excelで文字化けしないBOM付き）。グループ名・ドメイン／ページURL・引用数・AI検索ボリューム・グループ別引用数などが含まれます。

## プロジェクト管理と履歴

- **プロジェクト数**: 最大30件
- **履歴保存**: 分析結果はプロジェクト配下に**永続保存**され、いつでも履歴から再表示できます
- **再分析**: 同じプロジェクトで何度でも再分析でき、各実行は履歴として独立保存されます。時系列での引用数変化（施策前後の比較など）を追跡できます

## サンプル機能

ポイントを消費せずに、画面構成と各指標の見方を確認できます。サンプルのランキング結果が表示され、KPI・ランキングテーブル・AIインサイトなどの全体像を体験できます。使い方を案内するガイドツアーも利用できます。

## よくある質問

<AccordionGroup>
  <Accordion title="グループは何個まで設定できますか？">
    1〜10グループまで設定できます。1グループのみの場合は「個別分析モード」、2グループ以上で「比較分析モード」になります。1グループには最大10個のキーワード／ドメインを設定できます。
  </Accordion>

  <Accordion title="ポイントはどのように計算されますか？">
    「結果タイプの単価 × グループ数」で計算されます。ドメイン分析・ページ分析は1グループあたり30pt、ドメイン＋ページは50ptです。例えば3グループでドメイン＋ページなら 50pt × 3 = 150pt を消費します。
  </Accordion>

  <Accordion title="ドメインとキーワードを混ぜて設定できますか？">
    はい。1つのグループ内にキーワードとドメインを混在させて設定できます。複数キーワードはAND条件で動作します。
  </Accordion>

  <Accordion title="ChatGPTでも分析できますか？">
    はい。ただしChatGPTは米国・英語のみの対応です。日本語での分析にはGoogle AI Overviewsを使用してください。
  </Accordion>

  <Accordion title="引用数の合計が一致しないのはなぜですか？">
    ヘッダーの「引用数」はAI回答の件数、ドメイン別引用数は各回答での引用元数を示すためです。1つの回答が複数サイトを引用するので、ドメイン別合計の方が大きくなります。
  </Accordion>

  <Accordion title="分析結果はいつまで残りますか？">
    プロジェクトの配下に永続保存され、自動削除されません。プロジェクトを削除すると、その配下の分析結果もすべて削除されます。
  </Accordion>
</AccordionGroup>
