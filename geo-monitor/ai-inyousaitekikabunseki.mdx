## 概要

\*\*AI引用最適化分析（AI Ready）\*\*は、ChatGPT、Claude、Geminiなどの生成AIがあなたのサイトを正確に理解し、引用できるかをリアルタイムで診断する機能です。

<Info>
  AI検索時代において重要なのは、「検索エンジンに表示されるか」だけでなく、\*\*「AIに正しく理解され、引用されるか」\*\*です。AI引用最適化分析を使って、サイトのAI対応状況を診断し、改善ポイントを特定しましょう。
</Info>

### AI引用最適化分析とは

生成AI（ChatGPT、Claude、Gemini等）がWebサイトを情報源として参照する際、サイトの構造や技術的要素によって理解度が大きく変わります。この機能では：

- **技術的SEO診断**: 見出し構造、メタデータ、セマンティックHTMLなど10項目をチェック
- **AI強化分析**: AIによるコンテンツ品質、情報設計、機械可読性など8項目の詳細分析
- **改善提案**: 具体的な優先度付きアクションリストを生成

### 何のために使うか

- **AI対応状況確認**: 自社サイトがAIに正しく理解されるか診断
- **技術的SEO診断**: 見出し構造、メタデータ、セマンティックHTML等の最適化状況確認
- **AI発見性向上**: llms.txt、robots.txt、sitemap.xml対応状況の確認
- **コンテンツ品質評価**: AIが理解しやすいコンテンツ構造になっているか分析
- **改善提案**: 具体的なアクションアイテムの優先度付きリストを取得

## 分析フロー

AI引用最適化分析は**2段階分析アーキテクチャ**を採用しています。

### 分析の流れ

```
URL入力
    ↓
━━━ 基本分析（75ポイント）━━━
    ・見出し構造チェック
    ・可読性分析
    ・メタデータ品質
    ・セマンティックHTML検査
    ・アクセシビリティ検査
    ・robots.txt / sitemap.xml / llms.txt チェック
    ↓
━━━ AI強化分析（25ポイント）━━━
    ・コンテンツ品質分析
    ・情報設計評価
    ・セマンティック構造
    ・AI発見性
    ・知識抽出可能性
    ・コンテキスト完全性
    ・コンテンツ独自性
    ・機械可読性
    ↓
結果表示（合計100ポイント消費）
```

<Note>
  基本分析とAI強化分析は自動的に連続実行されます。途中でキャンセルした場合、実行済みの分析分のポイントのみ消費されます。
</Note>

## 分析項目詳細

### 基本分析（10項目）

技術的SEO要素を診断します。各項目には重み付けがあり、総合スコアに反映されます。

| 項目              | 重み  | チェック内容                                  |
| --------------- | --- | --------------------------------------- |
| **見出し構造**       | 1.4 | H1タグの個数、見出しレベルの階層構造が適切か                 |
| **可読性**         | 1.5 | Flesch可読性スコア、文章の読みやすさ                   |
| **メタデータ品質**     | 1.2 | og:title, og:description, author, 公開日など |
| **セマンティックHTML** | 1.0 | article, nav, main, section, header等の使用 |
| **アクセシビリティ**    | 0.9 | 画像altテキスト率、aria-label、lang属性            |
| **Robots.txt**  | 0.9 | user-agent設定、sitemap参照の有無               |
| **Sitemap**     | 0.8 | sitemap.xml / sitemap_index.xml の検出     |
| **LLMs.txt**    | 0.3 | AI利用許諾ファイルの有無                           |

## llms.txtとは

<Info>
  **llms.txt**は、AIクローラー向けの利用許諾ファイルです。robots.txtがWebクローラー向けであるのに対し、llms.txtはLLM（大規模言語モデル）向けに、サイトコンテンツの利用条件を明示します。
</Info>

### llms.txtの設置方法

ドメインのルートディレクトリに`llms.txt`ファイルを設置します：

```
https://example.com/llms.txt
```

### llms.txtの記載例

```text
# LLMs.txt - AI利用許諾ファイル
# https://example.com

User-agent: *
Allow: /

# このサイトのコンテンツはAIによる引用・参照を許可します
# 出典の明記をお願いします

Contact: ai@example.com
```

<Tip>
  llms.txtを設置することで、AIに「このサイトは引用してOK」という明確なシグナルを送ることができます。AI検索時代の新しいSEO対策として注目されています。
</Tip>

## スコアの基準

### 総合スコア（0-100点）

| スコア範囲      | 評価  | 説明                 |
| ---------- | --- | ------------------ |
| **90-100** | 優秀  | AIに非常に理解されやすいサイト構造 |
| **70-89**  | 良好  | 基本的なAI対応ができている     |
| **50-69**  | 要改善 | いくつかの重要な改善点がある     |
| **0-49**   | 要対策 | AI対応が不十分、優先的な改善が必要 |

### ドメインボーナス

一部の信頼性の高いドメインにはボーナススコアが加算されます：

| カテゴリ        | ボーナス   | 例                           |
| ----------- | ------ | --------------------------- |
| トップティアドメイン  | \+18pt | Google, OpenAI, Microsoft等  |
| セカンドティアドメイン | \+12pt | Figma, Linear, Notion等      |
| ドキュメント系     | \+20pt | docs._, api._, developer.\* |
