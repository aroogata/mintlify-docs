## 概要

GEO引用最適化分析は、**指定したWebページが生成AI（ChatGPT・Claude・Gemini など）に正確に理解され、引用されやすい状態になっているか**を総合診断するツールです。従来のSEOとは異なり、「AIに正しく理解され、引用されるか」というAI検索時代（GEO：Generative Engine Optimization）の視点でページを評価し、改善点を提示します。

<Info>
  1ページのURLを入力するだけで、基本構造・AI向けコンテンツ品質・技術（オンページ）・ページタイプ・AIクローラー許可状況・llms.txtまでをまとめて診断し、スコアと具体的な改善提案を表示します。
</Info>

### この機能でわかること・主な用途

- **AI引用への対応度チェック**: ページがAIに理解・引用されやすい構造になっているかを把握
- **改善ポイントの特定**: スコアの低い項目から、優先的に直すべき箇所を発見
- **技術的な健全性の確認**: 構造化データ・メタ情報・表示速度などを同時に点検
- **コンテンツの磨き込み**: AI向けのコンテンツ品質・知識抽出のしやすさを高める

## 分析の構成

### 基本分析（9項目）

ページの基本構造とAI対応の土台を評価します。

| 項目 | 評価内容 |
| --- | --- |
| 見出し構造 | H1〜H6の階層が適切か |
| 可読性 | 文章の読みやすさ（日本語・英語を自動判定） |
| メタデータ品質 | タイトル・ディスクリプション・著者・更新日など |
| セマンティックHTML | article・nav・main などの意味的なタグ使用 |
| アクセシビリティ | ARIA属性・画像alt などの配慮 |
| 構造化データ | JSON-LD / Microdata の有無と内容 |
| robots.txt | クローラー制御ファイルの検出 |
| sitemap.xml | サイトマップの検出 |
| llms.txt | AI向け案内ファイルの検出 |

### AI強化分析（8項目）

AIがページをどれだけ理解・引用しやすいかを、AIが評価しレーダーチャートで表示します。

| 項目 | 評価内容 |
| --- | --- |
| コンテンツ品質 | AI向けの情報の充実度・専門性・実用性 |
| AI発見可能性 | 構造化データ・メタデータ・OGPによる発見しやすさ |
| 知識抽出容易性 | FAQ・手順・表など、AIが知識を取り出しやすい形式か |
| 文脈と完全性 | E-E-A-T・著者情報・更新日などの信頼シグナル |
| 情報アーキテクチャ | 見出し階層・ナビゲーションの整理度 |
| 意味構造 | セマンティックHTML・ARIAによる意味づけ |
| コンテンツの独自性 | オリジナリティ・重複の少なさ |
| 機械可読性 | AIが解釈しやすい技術的要件の充足度 |

各項目には、状態（合格／要改善／要対策）と具体的な改善アクションが提示されます。

### 技術（オンページ）分析

| 項目 | 内容 |
| --- | --- |
| SEOチェック | HTTPS・canonical・H1・メタディスクリプションなどの項目を合否判定 |
| Core Web Vitals | LCP・CLS などの表示パフォーマンス指標 |
| コンテンツリソース | 単語数・テキスト比率・リンク数・画像数など |
| ページ基本情報 | HTTPステータス・ページサイズ・URL深度など |

<Note>
  別ボタンから、ページ表示速度（PageSpeed）のモバイル／デスクトップスコアを追加で計測できます（無料）。
</Note>

### AIクローラー・llms.txt の診断

| 項目 | 内容 |
| --- | --- |
| AIクローラー許可状況 | GPTBot（ChatGPT）・ClaudeBot（Claude）・Google-Extended（Gemini）・PerplexityBot などのアクセス可否 |
| llms.txt | AIに対してサイトの案内・引用許可を伝える新しいファイルの有無 |

## スコアと評価

診断結果は、**基本分析スコア**と**AI強化分析スコア**の2つ（各0〜100点）で表示されます。基本分析スコアは項目ごとの重み付けに加え、信頼性の高いドメインには加点が行われます。

スコアの目安：

| スコア | 評価 |
| --- | --- |
| 90〜100 | 優秀（AIに非常に理解されやすい） |
| 70〜89 | 良好（基本的なAI対応ができている） |
| 50〜69 | 要改善（重要な改善点あり） |
| 0〜49 | 要対策（AI対応が不十分） |

<Tip>
  コンテンツが薄いページ（トップページ・カテゴリ一覧・法的ページなど）は、AIに引用されにくい傾向があります。本ツールはページタイプを自動判定し、該当する場合は注意を表示します。**情報量の多い個別ページ**の分析がおすすめです。
</Tip>

  <Step title="深掘り・出力（任意）">

  </Step>
</Steps>

## 結果の見方

- **2つのスコアカード**: 基本分析スコアとAI強化分析スコア（円形ゲージ）
- **レーダーチャート**: 基本分析（9軸）とAI強化分析（8軸）でバランスを可視化
- **項目別の詳細**: 各項目の状態・詳細・改善提案（AI強化分析は具体的なアクション付き）
- **技術分析セクション**: SEOチェック・Core Web Vitals・コンテンツリソース・ページ基本情報
- **ページタイプ警告**: コンテンツが薄いページの場合に表示

## AIに質問

診断結果を文脈として、GEO（AI検索最適化）に詳しいAIアシスタントに相談できます。スコアや不合格項目に応じたサジェスト質問が自動生成され、「この項目をどう直せばいいか」「llms.txtの設置方法」などを実装レベルで相談できます。

## レポート・CSV出力

- **レポート**: 診断結果を印刷・PDF（A4最適化）レポートとして出力。スコア・各項目の詳細・レーダーチャート・改善提案がまとまります
- **CSV出力**: 基本分析・AI強化分析・SEOチェック・Core Web Vitals・コンテンツリソースなどの全データをCSVでダウンロード

## 結果の保存

<Info>
  分析結果は **12時間** 保存され、履歴から再表示できます。12時間以内の同一URLの再分析はポイントを消費しません。
</Info>

- **保存期間**: 12時間
- **最大保存件数**: 50件（ユーザーあたり。超過分は古いものから削除）
- **履歴ページ**: `/analysis-history` から過去の診断結果を再表示できます

## 日本語対応

可読性評価は日本語に最適化されています（文の長さ40〜60文字、漢字率20〜30%が最適の目安）。なお、英語向けに設計された可読性指標（Flesch-Kincaid など）は、日本語ページでは参考値として扱われます。

## よくある質問

<AccordionGroup>
  <Accordion title="どんなページを分析するのがおすすめですか？">
    情報量の多い個別ページ（記事・解説ページなど）がおすすめです。トップページやカテゴリ一覧、法的ページはコンテンツが薄く、AIに引用されにくいため、該当する場合は注意が表示されます。
  </Accordion>

  <Accordion title="基本分析スコアとAI強化分析スコアの違いは？">
    基本分析スコアは見出し・可読性・構造化データなどページの基本構造を、AI強化分析スコアはAI向けのコンテンツ品質・知識抽出のしやすさなどを評価します。両方を高めることでAIに引用されやすくなります。
  </Accordion>

  <Accordion title="llms.txtとは何ですか？">
    AIに対してサイトの案内や引用に関する方針を伝えるための新しいファイルです。robots.txtがWebクローラー向けであるのに対し、llms.txtはAI（LLM）向けの案内として注目されています。本ツールでは有無を検出します。
  </Accordion>

  <Accordion title="同じURLを何度も分析するとポイントがかかりますか？">
    12時間以内であれば、保存済みの結果が無料で表示され、ポイントは消費されません。12時間を過ぎると新規分析（100pt）になります。
  </Accordion>

  <Accordion title="AIクローラーの許可状況は何を見ていますか？">
    robots.txtの設定をもとに、GPTBot（ChatGPT）・ClaudeBot（Claude）・Google-Extended（Gemini）・PerplexityBotなどがページにアクセスできるかを判定します。ブロックしているとAIに引用されにくくなります。
  </Accordion>
</AccordionGroup>
