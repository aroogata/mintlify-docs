## 概要

**AI引用最適化分析（AI Ready）**は、ChatGPT、Claude、Geminiなどの生成AIがあなたのサイトを正確に理解し、引用できるかを総合的に診断する機能です。

<Info>
AI検索時代において重要なのは、「検索エンジンに表示されるか」だけでなく、**「AIに正しく理解され、引用されるか」**です。AI引用最適化分析を使って、サイトのAI対応状況を診断し、改善ポイントを特定しましょう。
</Info>

### AI引用最適化分析とは

生成AI（ChatGPT、Claude、Gemini等）がWebサイトを情報源として参照する際、サイトの構造や技術的要素によって理解度が大きく変わります。この機能では：

- **技術的SEO診断**: 見出し構造、メタデータ、セマンティックHTMLなど基本項目をチェック
- **AI強化分析**: AIによるコンテンツ品質、情報設計、機械可読性など詳細分析
- **Onpage分析**: Core Web Vitals、SEOチェック、コンテンツリソースなど詳細な技術分析
- **改善提案**: 具体的な優先度付きアクションリストを生成

技術的SEO要素を診断します。各項目には重み付けがあり、総合スコアに反映されます。

| **可読性** | 1.5 | Flesch可読性スコア、文章の読みやすさ |

| **セマンティックHTML** | 1.0 | article, nav, main, section, header等の使用 |

| **Sitemap** | 0.8 | sitemap.xml / sitemap_index.xml の検出 |
| **LLMs.txt** | 0.3 | AI利用許諾ファイルの有無 |

## llms.txtとは

<Info>
**llms.txt**は、AIクローラー向けの利用許諾ファイルです。robots.txtがWebクローラー向けであるのに対し、llms.txtはLLM（大規模言語モデル）向けに、サイトコンテンツの利用条件を明示します。
</Info>

### llms.txtの設置方法

ドメインのルートディレクトリに`llms.txt`ファイルを設置します：

```
https://example.com/llms.txt
```

### llms.txtの記載例

```text
# LLMs.txt - AI利用許諾ファイル
# https://example.com

User-agent: *
Allow: /

# このサイトのコンテンツはAIによる引用・参照を許可します
# 出典の明記をお願いします

Contact: ai@example.com
```

<Tip>
llms.txtを設置することで、AIに「このサイトは引用してOK」という明確なシグナルを送ることができます。AI検索時代の新しいSEO対策として注目されています。
</Tip>

| スコア範囲 | 評価 | 説明 |

## よくある質問

<AccordionGroup>
  <Accordion title="1回の分析で何ポイント消費しますか？">
    **100ポイント**です。基本分析、AI強化分析、Onpage分析を含むすべての分析が1回100ポイントで実行されます。12時間以内に同じURLで再分析した場合はキャッシュから結果が返され、ポイントは消費されません。
  </Accordion>
  <Accordion title="llms.txtとは何ですか？">
    llms.txtは、AIクローラー向けの利用許諾ファイルです。robots.txtがWebクローラー向けであるのに対し、llms.txtはLLM（大規模言語モデル）向けに、サイトコンテンツの利用条件を明示します。設置することでAIに「引用OK」のシグナルを送れます。
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常**1〜2分**程度です。基本分析、AI強化分析、Onpage分析が順次実行され、完了次第結果が表示されます。
  </Accordion>
  <Accordion title="結果の保存期間は？">
    分析結果は**12時間**保存されます。12時間以内に同じURLで再分析すると、キャッシュから結果が返されポイントは消費されません。
  </Accordion>
  <Accordion title="Core Web Vitalsとは何ですか？">
    Googleが定義するWebページの体験品質指標です。**LCP（最大コンテンツ描画）**、**FID（初回入力遅延）**、**CLS（累積レイアウトシフト）**の3つが主要指標で、検索ランキングにも影響します。
  </Accordion>
  <Accordion title="SEOチェック結果の「要改善」はどう対処すべき？">
    各項目には具体的な改善推奨が表示されます。優先度の高いものから順に対応することをお勧めします。特に**HTTPS化**、**タイトル・Description設定**、**H1タグ**は基本かつ重要な項目です。
  </Accordion>
  <Accordion title="どのURLを分析すべきですか？">
    トップページよりも、コンテンツが充実した個別ページを分析することをお勧めします。商品ページ、ブログ記事、サービス説明ページなど、AIに引用されたいコンテンツを優先的に分析しましょう。
  </Accordion>
</AccordionGroup>
