## 概要

AIOドメイン分析は、指定したドメインが **AI検索エンジン（Google AI Overviews・ChatGPT）で、どのページがどれだけ引用・言及されているか** を分析するツールです。AI回答に取り上げられているページ・言及回数・AI検索ボリュームを定量的に把握でき、AI検索時代の可視性（GEO：Generative Engine Optimization）を測定できます。

<Info>
  1回の分析で、AIに引用されたページの一覧・言及回数・AI検索ボリューム・引用された質問例・月次推移をまとめて取得し、さらにAIが結果を読み解いた改善提案（AIインサイト）を自動生成します。
</Info>

### 主な用途

- **AI検索での可視性測定**: 自社サイトのどのページがAIに引用されているかを把握
- **競合サイトの分析**: 任意のドメインを対象に、競合のAI露出状況を調査
- **コンテンツ強化の優先順位付け**: 引用されている／されていないページを特定し、施策を立案
- **継続モニタリング**: プロジェクト単位で対象を管理し、分析結果を蓄積して推移を確認

## 対応AIプラットフォーム

| プラットフォーム | 対応地域・言語 | 備考 |
| --- | --- | --- |
| **Google AI Overviews** | 多数の地域・言語に対応（デフォルト：日本・日本語） | 地域・言語を自由に選択可能 |
| **ChatGPT** | 米国・英語のみ | 選択時は地域・言語が自動で米国・英語に固定されます |

<Note>
  Google AI OverviewsとChatGPTでは、同じドメインでも結果が異なる場合があります。両方のプラットフォームで分析し、それぞれの露出状況を比較することをおすすめします。
</Note>

## 料金

AIOドメイン分析は、**分析の規模（処理された言及数）に応じて消費ポイントが変動**します。

| 処理言及数 | 消費ポイント |
| --- | --- |
| 500件以下 | **100pt** |
| 500件超 | **200pt** |

<Note>
  「処理言及数」は、AI検索結果から実際に処理された言及レコードの件数です。分析実行前に最大値（200pt）の残高を確認し、分析完了後に実際の処理件数に応じて100ptまたは200ptを消費します。
</Note>

無料で利用できる操作：

- **AIインサイトの生成**（分析実行に含まれます）
- **CSV出力**
- **過去の分析結果の閲覧（履歴）**
- **AIに質問**

## プロジェクトの考え方

AIOドメイン分析は **プロジェクト単位** で対象を管理します。1つのプロジェクトに対象ドメイン（または対象キーワード）とプラットフォーム・地域などの設定を保存し、その配下に分析結果を蓄積していきます。

- 自社サイト・競合サイトなど、対象ごとにプロジェクトを作成
- **最大50プロジェクト** まで作成可能
- プロジェクトを削除すると、その配下の分析結果もすべて削除されます

## 設定項目

プロジェクト作成・編集時に、以下を設定します。

| 項目 | 説明 |
| --- | --- |
| **プロジェクト名** | プロジェクトの識別名（必須） |
| **説明** | プロジェクトの補足メモ（任意） |
| **分析対象** | ドメイン または キーワードを指定 |
| **サブドメインを含む** | 対象ドメインのサブドメインを分析に含めるか |
| **プラットフォーム** | Google AI Overviews / ChatGPT |
| **地域・言語** | 分析対象の検索市場（ChatGPT時は米国・英語に固定） |
| **言及取得数** | 分析する言及の最大件数（100〜1000件、100件刻み。多いほど網羅的で、処理件数に応じてポイントが変動） |

## 利用手順

<Steps>
  <Step title="プロジェクトの作成">
    「プロジェクト管理」からプロジェクトを新規作成し、分析対象ドメイン・プラットフォーム・地域などを設定します。
  </Step>
  <Step title="分析の実行">
    ダッシュボードで対象プロジェクトを選び、分析を実行します。処理された言及数に応じて100ptまたは200ptを消費します。

    <Warning>
      分析が完了するまでページを離れないでください。分析が中断される場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    KPI（検出ページ数・処理言及数・月間AI検索Vol）と、ページ別詳細テーブルを確認します。
  </Step>
  <Step title="AIインサイトの確認">
    自動生成されるAIインサイト（露出度スコアと改善提案）を確認します。
  </Step>
  <Step title="深掘り・出力（任意）">
    「AIに質問」で改善案を相談したり、CSVで結果をダウンロードして社内共有・レポートに活用します。
  </Step>
</Steps>

## 出力指標

### KPIカード

| 指標 | 説明 |
| --- | --- |
| **検出ページ数** | 対象ドメインのうち、AIに引用・言及されたユニークページ数 |
| **処理言及数** | 分析で処理されたAI言及レコードの総数 |
| **月間AI検索Vol** | 各言及に紐づくAI検索ボリュームの合計 |

### ページ別詳細テーブル

| 項目 | 説明 |
| --- | --- |
| ページURL | 引用されたページのURL |
| タイトル | ページタイトル |
| 言及回数 | そのページが引用された回数 |
| AI検索ボリューム | そのページが含まれた検索のボリューム合計 |
| 関連質問例 | そのページが引用された質問の例 |
| 月次推移 | 月別のAI検索ボリュームの推移 |

<Note>
  ページは、AI検索関連キーワードのボリュームを考慮して、言及数の多い順に表示されます。
</Note>

### AIインサイト

分析結果をAIが読み解き、以下を自動生成します。

| 要素 | 内容 |
| --- | --- |
| **露出度スコア** | AI露出度を5段階（★1〜5）で評価 |
| **サマリー** | 全体評価の簡潔な要約 |
| **ページ別分析** | 引用されているページの傾向と特徴 |
| **テーマ別分析** | 引用されているトピック・テーマの分析 |
| **コンテンツ戦略** | 露出を高めるためのコンテンツ方針 |
| **アクションプラン** | 優先度を踏まえた具体的な実行項目 |

生成されたAIインサイトは分析結果とともに保存され、履歴から開いた際は再生成されずに保存内容が表示されます。

### AIに質問

分析結果の画面では、AIアシスタントに分析内容についてのフォローアップ質問ができます。露出を高めるための具体的な施策などを、チャット形式で相談できます。

## CSV出力

KPIサマリーとページ別詳細をCSV形式でダウンロードできます（Excelで文字化けしないBOM付き）。

- **含まれる内容**: プロジェクト名・分析日時、KPI（検出ページ数・処理言及数・月間AI検索Vol）、ページ別詳細（URL・タイトル・言及回数・AI検索ボリューム・関連質問例）
- **ファイル名**: `リンクサージ_GEOページ分析_{ドメイン名}_{日付}.csv`

## 結果の保存

<Info>
  分析結果は **プロジェクトの配下に保存され、いつでも履歴から再表示** できます。一定時間で自動削除されることはありません。不要になった場合は、プロジェクトを削除すると配下の結果もまとめて削除されます。
</Info>

- **保存単位**: プロジェクトごとに分析結果を蓄積
- **再分析**: 同じプロジェクトで再度分析すると、新しい結果が履歴に追加されます（過去の結果は保持されます）

## サンプル機能

ポイントを消費せずに、画面構成と各指標の見方を確認できます。サンプルの分析結果が表示され、KPI・ページ別詳細・AIインサイトなどの全体像を体験できます。使い方を案内するガイドツアーも利用できます。

## よくある質問

<AccordionGroup>
  <Accordion title="ドメインとキーワードのどちらで分析できますか？">
    両方に対応しています。ドメインを指定すると、そのサイトのどのページがAIに引用されているかを分析します。キーワードを指定する分析も選択できます。
  </Accordion>

  <Accordion title="Google AI OverviewsとChatGPTの結果が違うのはなぜですか？">
    AIプラットフォームごとに参照する情報源や回答の組み立て方が異なるためです。両方で分析し、それぞれの露出状況を比較することをおすすめします。なお、ChatGPTは米国・英語のみの対応です。
  </Accordion>

  <Accordion title="「AI検索ボリューム」はどのように計算されますか？">
    Google検索結果のPAA（People Also Ask）セクションのデータなど、複数のシグナルを考慮した独自のアルゴリズムに基づいて算出される推定指標です。
  </Accordion>

  <Accordion title="ポイントが100ptと200ptで変わるのはなぜですか？">
    分析で実際に処理された言及数によって変動します。処理言及数が500件以下なら100pt、500件を超えると200ptを消費します。
  </Accordion>

  <Accordion title="分析結果はいつまで残りますか？">
    プロジェクトの配下に保存され、自動削除されることはありません。プロジェクトを削除すると、その配下の分析結果もすべて削除されます。
  </Accordion>

  <Accordion title="競合サイトも分析できますか？">
    はい。任意のドメインを対象にプロジェクトを作成して分析できます。競合がAI検索でどのページを引用されているかを把握し、自社のGEO戦略に活用できます。
  </Accordion>
</AccordionGroup>

## 仕様

| 項目 | 仕様 |
| --- | --- |
| 消費ポイント | 100pt（処理言及数500件以下）/ 200pt（500件超） |
| 対応プラットフォーム | Google AI Overviews / ChatGPT（米国・英語固定） |
| 分析対象 | ドメイン / キーワード |

| 最大プロジェクト数 | 50件 |

| 結果の保存 | プロジェクト配下に永続保存（自動削除なし） |
| 出力形式 | 画面表示 / CSVダウンロード |
