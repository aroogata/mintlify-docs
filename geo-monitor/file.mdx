## 概要

クエリファンアウト可視化は、質問（プロンプト）を入力するだけで、**AI（Gemini）が回答を組み立てる際に内部で実行した検索キーワード**をすべて取り出して一覧表示するツールです。AIが「どんなキーワードで情報を集めたか」を把握することで、SEO記事のキーワード選定やコンテンツの網羅性チェック、AI検索（LLMO）への最適化に活用できます。

<Info>
  本ツールが表示するのは、AIが生成した架空のクエリではなく、**Geminiが実際に検索した実ログに基づくキーワード**です。あわせて、AIの回答本文・引用元サイト・関連検索ウィジェットも取得します。
</Info>

### クエリファンアウトとは

ChatGPTやGeminiなどの生成AIは、ユーザーの質問をそのまま1回だけ検索するのではなく、**複数の検索キーワードに自動で分解**して情報を集めています。この「1つの質問 → 複数の検索」への展開を **クエリファンアウト（Query Fan-out）** と呼びます。

たとえば「おすすめのクレジットカード」と質問すると、AIは内部で次のような複数の具体的なキーワードで検索しています。

- 「年会費無料 クレジットカード」
- 「ポイント還元率 比較」
- 「国際ブランド おすすめ」

つまり、AIが重要と判断した関連キーワードを発見できます。

### この機能でわかること・主な用途

- **AIが裏側で使ったキーワードの把握**: 自社テーマに対してAIがどんなキーワードで情報収集しているかを可視化
- **SEO・LLMOのキーワード選定**: 抽出キーワードをコンテンツのキーワード設計に直接活用
- **コンテンツの抜け漏れ発見**: まだカバーできていないサブトピックを特定し、記事改善のヒントに
- **AI検索への露出強化**: AIが参照するキーワードを網羅し、AI検索結果に引用されやすいコンテンツを制作
- **競合との差分把握**: 競合が引用されていて自社が含まれないキーワードを優先的に強化

## 料金

クエリファンアウト可視化は、**1回の分析につき固定10ポイント**を消費します。

| 操作 | 消費ポイント |
| --- | --- |
| クエリファンアウト分析（1回） | **10pt** |
| 同一クエリで再分析（1回） | **10pt** |

<Note>
  分析実行前にポイント残高をチェックし、不足している場合は実行せず警告を表示します。再分析も初回と同じ10ポイントを消費します（AIは毎回異なる検索戦略を使うため、再実行で結果が変わることがあります）。
</Note>

## 利用手順

<Steps>
  <Step title="質問（プロンプト）を入力">
    調べたいテーマを質問形式で入力します（最大2,000文字）。 例: `2026年のSEO対策の最前線について教えてください`

    <Tip>
      最新情報や事実確認が必要な質問（「2026年の〜」など時事性のあるテーマ）ほど、AIがWeb検索を実行しやすく、ファンアウトクエリが抽出されやすくなります。
    </Tip>
  </Step>
  <Step title="分析を実行">
    「ファンアウトクエリを取得」ボタンをクリック、または **Ctrl\+Enter（Macは Cmd\+Enter）** で実行します。10ポイントを消費します。
  </Step>
  <Step title="ファンアウトクエリの確認">
    Geminiが内部で使用した検索キーワードが番号付きで一覧表示されます。各クエリはGoogle検索リンクから実際の検索結果も確認できます。
  </Step>
  <Step title="回答と引用元の確認">
    AIの回答本文と、根拠となった引用元サイトを確認します。回答の脚注（引用チップ）から対応する情報源にジャンプできます。
  </Step>
  <Step title="コピー・CSV出力（任意）">
    抽出キーワードをコピー、または結果をCSVでダウンロードして、キーワード設計やレポートに活用します。
  </Step>
</Steps>

## 結果の見方

分析が完了すると、以下の要素が表示されます。

### ファンアウトクエリ一覧

Geminiがプロンプトに回答するために内部で実行した、実際の検索キーワードの一覧です。各キーワードには番号が振られ、「Google検索」リンクから実際の検索結果を確認できます。

<Note>
  抽出されるキーワードは一般的に3〜8個程度ですが、質問の複雑さや具体性によって変わります。専門的で多角的な質問ほど多くなり、20個以上になることもあります。
</Note>

### AIによる回答（Gemini）

検索結果をもとにGeminiが生成した回答本文です。文末の**引用チップ**（ファビコン＋ドメイン）は、その記述の根拠となった情報源を示します。チップにマウスを乗せると詳細が表示され、クリックすると元サイトが開きます。

### 引用元サイト（情報源パネル）

Geminiが回答時に引用した情報源を一覧表示します。各カードにはサイトのタイトル・スニペット・サムネイル・ドメインが表示され、番号は回答内の脚注に対応します。クリックすると元サイトを開けます。

### 関連検索ウィジェット

Geminiが提示する関連検索（Google検索ウィジェット）です。Google検索の利用規約上の条件のため表示しています。

## AI検索最適化（LLMO）での活用

これからのSEO・LLMOで成果を出すには、AIが「どう回答を組み立てたか」ではなく「**どんなキーワードで情報を探したか**」を把握することが鍵になります。推測ではなく、AIが実際に実行した検索クエリをもとにコンテンツを設計することで、AI検索結果に選ばれるページ作りが可能になります。

- **キーワード網羅性の強化**: ファンアウトクエリを記事内でカバーし、AIに引用されやすくする
- **コンテンツの抜け漏れ発見**: 各ファンアウトクエリが、新規コンテンツや既存ページ改善のヒントになる
- **競合との比較**: 引用元に競合が並び自社が含まれないキーワードを、優先的に強化する

## CSV出力

抽出したファンアウトクエリと引用元をCSV形式でダウンロードできます（Excelで文字化けしないBOM付き）。

| 列 | 内容 |
| --- | --- |
| 種別 | 入力クエリ / ファンアウトクエリ / 情報源 の区分 |
| 内容 | クエリ本文、または情報源のドメイン |
| URL | 情報源の実URL（取得できた場合） |
| ページタイトル | 情報源のページタイトル |

- **ファイル名**: `リンクサージ_クエリファンアウト分析_{質問の冒頭}_{日時}.csv`
- セキュリティのため、表計算ソフトで意図しない数式として解釈される値は自動で無害化されます

## 注意事項

<Warning>
  分析結果は保存されません。ページを再読み込みすると結果は消えます。必要な結果はCSVで保存してください。
</Warning>

- **結果は毎回変わることがあります**: 同じ質問でも、AIが毎回異なる検索戦略で情報収集するため、ファンアウトクエリや引用元が変化することがあります。複数回実行して傾向を把握することをおすすめします。
- **Web検索が実行されない場合があります**: AIが学習済みの知識だけで回答できると判断した場合、Web検索を行わずファンアウトクエリが表示されないことがあります。

## よくある質問

<AccordionGroup>
  <Accordion title="クエリファンアウトとは何ですか？">
    ChatGPTやGeminiなどの生成AIが、ユーザーの質問に対して1回の検索ではなく複数の関連キーワードに分解して情報を収集する仕組みのことです。このツールでは、Geminiが回答を組み立てる際に裏側で実行した検索キーワードを取り出して一覧表示します。AIが生成した架空のクエリではなく、実際の検索ログに基づくデータです。
  </Accordion>

  <Accordion title="1回の質問で何個くらいのキーワードが抽出されますか？">
    一般的には3〜8個程度ですが、質問の複雑さや具体性によって大きく変わります。専門的で多角的な質問ほど多くのファンアウトクエリが生成される傾向があり、場合によっては20個以上になることもあります。
  </Accordion>

  <Accordion title="SEOやLLMO（AI検索最適化）にどう役立ちますか？">
    ファンアウトクエリを分析することで、AIがあなたのテーマに関連する情報をどんなキーワードで探しているかがわかります。自社コンテンツがこれらのキーワードを網羅していれば、AIの回答に引用される可能性が高まります。逆に、競合サイトが引用されていて自社が含まれていないキーワードは、優先的にコンテンツを強化すべき領域です。
  </Accordion>

  <Accordion title="質問してもファンアウトクエリが表示されないことはありますか？">
    はい、あります。AIは質問の内容によっては、Web検索を行わず学習済みの知識だけで回答することがあります。最新情報を含む質問や、具体的なデータが必要な質問のほうがWeb検索が実行されやすいため、「2026年の〜」のように時事性のあるテーマや、事実確認が必要な質問を入力してみてください。
  </Accordion>

  <Accordion title="結果を保存できますか？">
    分析結果はサーバーに保存されません（履歴機能はありません）。残しておきたい結果は、CSV出力機能でダウンロードして保存してください。
  </Accordion>
</AccordionGroup>
