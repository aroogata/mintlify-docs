## 概要

**GEOブランドメンション**は、AI（LLM）があなたのブランド・製品・キーワードについて**言及した回数と具体的な事例**を構造化して分析できる機能です。

<Info>
  「メンション」とは、\*\*AIがあるクエリ（question）に対して回答（answer）し、その回答で参照・引用したソース（sources）\*\*の1件分を指します。つまり「AIがあなたのブランドを言及した回数・事例」を数値とともに可視化します。
</Info>

### AI検索時代の新しいマーケティング指標

従来のSEOでは「検索順位」が重要でしたが、AI検索時代では\*\*「AIにどれだけ引用されるか」\*\*が新たな競争軸です。GEOブランドメンションを使えば：

- AIがどんな質問に対して自社ブランドを言及しているか
- どのメディア・サイトを情報源として引用しているか
- スケジュール実行による**時系列変化の追跡**
- **定点観測ダッシュボード**でトレンドを可視化

これらを**データで可視化**し、戦略的な意思決定を支援します。

## 何のために使うか

GEOブランドメンションは、以下のような実務課題を解決します：

### ブランド監視（Reputation）

<Card title="対象ユーザー" icon="user">
  マーケティング担当者、PR担当者、ブランドマネージャー
</Card>

AIが自社や競合をどう言及しているかを把握できます。**ネガティブな言及や誤情報を早期に検知**し、ブランドイメージの毀損を防ぎます。

- AIが「〇〇は品質に問題がある」と回答していないか
- 競合と比較してどのような文脈で言及されているか
- 言及のトーン（ポジティブ/ネガティブ）の傾向
- **スケジュール機能で定期監視を自動化**

### PR/危機管理

<Card title="対象ユーザー" icon="user">
  広報担当者、危機管理チーム、経営企画
</Card>

あるトピックでメンションが急増した場合、**原因ソース（どのメディアが起点か）を特定**して迅速に対応できます。

- 炎上の発生源となっているメディアの特定
- 誤情報がどのソースから広がっているかの追跡
- **定点観測でメンション数の急増/急減をアラート検知**

### コンテンツ戦略（被引用対策）

<Card title="対象ユーザー" icon="user">
  SEO担当者、コンテンツマーケター、Webディレクター
</Card>

AIが参照しているドメイン・ページを把握し、**AIに引用される確率を上げるコンテンツ設計**が可能になります。

- よく引用されているドメインの特徴分析
- 引用されやすいコンテンツ形式の発見
- **時系列で引用元の変化を追跡**

### SEO/AI可視性最適化（AI Search Optimization）

<Card title="対象ユーザー" icon="user">
  SEOコンサルタント、デジタルマーケター、事業責任者
</Card>

`ai_search_volume`（AI検索ボリューム）や月次推移を見て、**AIトラフィックポテンシャルが高いキーワードを優先的に対策**できます。

- AI検索で需要が高いキーワードの発見
- 月次トレンドから季節性や成長傾向を把握
- **定点観測ダッシュボードで長期トレンドを分析**

### 競合分析・ベンチマーク

<Card title="対象ユーザー" icon="user">
  事業戦略担当、マーケティングマネージャー、リサーチャー
</Card>

自社と競合それぞれでプロジェクトを作成し、**AI上での言及量や参照ドメインの差**を比較できます。

- 自社 vs 競合のAI露出度比較
- 競合が引用されているソースの分析
- **スケジュール実行で定期的にベンチマーク更新**

### ファクトチェック/品質管理

<Card title="対象ユーザー" icon="user">
  品質管理担当、法務、コンプライアンス
</Card>

AIの回答と参照元が一致しないケースを抽出して**誤情報を洗い出し**、是正要求などの対応が可能です。

- AIが誤った情報を回答していないか
- 引用元と回答内容の整合性チェック
- 訂正依頼先の特定

## スケジュール機能

プロジェクトごとに自動実行スケジュールを設定し、**定期的なブランド監視を自動化**できます。

### スケジュール設定項目

| 項目        | 説明              | 選択肢                                     |
| --------- | --------------- | --------------------------------------- |
| **実行頻度**  | 分析を実行する間隔       | 毎日 / 2日に1回 / 3日に1回 / 週1回 / 2週間に1回 / 月1回 |
| **実行時刻**  | 分析を実行する時刻（日本時間） | 00:00〜23:30（30分刻み）                      |
| **メール通知** | 実行完了時にメールで通知    | オン / オフ                                 |

### スケジュール設定手順

<Steps>
  <Step title="プロジェクトを選択">
    スケジュールを設定したいプロジェクトの詳細画面を開きます
  </Step>
  <Step title="スケジュール設定を有効化">
    「スケジュール設定」セクションでスケジュールをオンにします
  </Step>
  <Step title="実行頻度と時刻を設定">
    - **実行頻度**: 監視目的に応じて選択（ブランド監視は毎日〜3日推奨）
    - **実行時刻**: 業務時間に合わせて設定（朝9:00推奨）
  </Step>
  <Step title="保存">
    設定を保存すると、次回実行予定が表示されます
  </Step>
</Steps>

<Warning>
  スケジュール実行ごとに **100ポイント** が自動消費されます。ポイント残高にご注意ください。
</Warning>

### スケジュール実行履歴

実行履歴では以下を確認できます：

- **実行日時**: いつ実行されたか
- **ステータス**: 成功 / 実行中 / 失敗
- **取得件数**: 検出されたメンション数
- **消費ポイント**: 使用されたポイント

履歴は新しい順/古い順/月別でソート可能で、不要な履歴は選択削除できます。

## 定点観測ダッシュボード

スケジュール実行で蓄積されたデータを**時系列で可視化**し、ブランドメンションの変化を追跡します。

### 期間フィルター

| 期間         | 用途               |
| ---------- | ---------------- |
| **過去7日間**  | 直近の急な変化を確認       |
| **過去30日間** | 月次のトレンド確認（デフォルト） |
| **過去90日間** | 四半期のトレンド確認       |
| **全期間**    | プロジェクト開始からの全データ  |

### KPIカード（7項目）

| KPI            | 説明                |
| -------------- | ----------------- |
| **総メンション数**    | 期間内の累計メンション数      |
| **AI検索ボリューム**  | 累計AI検索ボリューム       |
| **ユニーク質問数**    | 異なる質問パターンの数       |
| **ユニーク引用元数**   | 引用されたドメイン数        |
| **平均メンション/計測** | 1回の計測あたりの平均メンション数 |
| **平均ボリューム/計測** | 1回の計測あたりの平均ボリューム  |
| **計測回数**       | 期間内のスケジュール実行回数    |

各KPIには**前期間比の増減率**が表示され、±5%を超える変化はトレンドアイコンで強調されます。

### 時系列グラフ

メンション数、AI検索ボリューム、引用元数、質問数の推移を折れ線グラフで表示。 複数の指標を重ねて表示し、相関関係を分析できます。

### 特徴的メンションアラート

AIが以下のパターンを自動検出してアラート表示：

| アラートタイプ | 説明                |
| ------- | ----------------- |
| **急増**  | メンション数が前回比で大幅に増加  |
| **急減**  | メンション数が前回比で大幅に減少  |
| **新規**  | 新しく出現した引用元や質問パターン |
| **消失**  | 以前あった引用元や質問が消失    |

### 質問カテゴリ分析

AIへの質問を自動分類し、どのようなカテゴリでブランドが言及されているかを可視化。

### データテーブル

- **履歴別表示**: 各計測ごとの詳細データ
- **ドメイン別集計**: 引用元ドメインごとの出現回数

## 出力指標（KPI）

分析を実行すると、以下の主要指標が表示されます：

| 指標            | 説明                    | 活用方法                         |
| ------------- | --------------------- | ---------------------------- |
| **総メンション数**   | AIがブランド/キーワードを言及した総件数 | ブランド露出規模の把握、時系列での変化追跡        |
| **AI検索ボリューム** | 対象クエリがAIで検索された推定回数    | トラフィックポテンシャルの評価、優先対策キーワードの選定 |
| **ユニーク質問数**   | 異なる質問パターンの数           | 言及されている文脈の多様性を把握             |
| **引用元ドメイン数**  | AIが引用した情報源ドメインの種類     | 情報源の多様性、権威性の評価               |

### 各メンションの詳細データ

| データ項目                | 説明                            |
| -------------------- | ----------------------------- |
| **question**         | AIへの質問テキスト                    |
| **answer**           | AIの回答テキスト（マークダウンリンク形式）        |
| **sources**          | 引用元ソース一覧（URL、ドメイン、タイトル、スニペット） |
| **ai_search_volume** | このクエリのAI検索ボリューム               |
| **monthly_searches** | 過去12ヶ月の月次検索ボリューム推移            |

## 利用手順

### Step 1: プロジェクトを作成

<Steps>
  <Step title="GEO Monitorにアクセス">
    サイドバーから「GEO Monitor」→「ブランドメンション」タブを選択
  </Step>
  <Step title="新規プロジェクト作成">
    「新規プロジェクト」ボタンをクリック
  </Step>
  <Step title="プロジェクト情報を入力">
    - **プロジェクト名**: 識別しやすい名前を入力（例: 「自社ブランド監視」）
    - **説明**（任意）: プロジェクトの目的などをメモ
  </Step>
</Steps>

### Step 2: ターゲットを設定

<Steps>
  <Step title="ターゲットを入力">
    1つのキーワードまたはドメインを設定します

    <Note>
      現在は1つのターゲットのみ設定可能です。
    </Note>
  </Step>
  <Step title="ターゲットタイプを選択">
    - **キーワード**: ブランド名、製品名、トピックなど
    - **ドメイン**: 特定サイトの引用状況を追跡
  </Step>
  <Step title="検索設定を調整">
    - **マッチタイプ**: 完全一致 / 部分一致
    - **検索スコープ**: 質問のみ / 回答のみ / 全体 など
    - **フィルター**: include（含む）/ exclude（除外）

    <Tip>
      **プリセットテンプレート**を使用すると、用途に最適化された設定が自動適用されます。
    </Tip>
  </Step>
</Steps>

### Step 3: 地域・言語・プラットフォームを選択

<Steps>
  <Step title="プラットフォームを選択">
    - **Google AI Overviews**: 全地域・言語対応
    - **ChatGPT Search**: US/Englishのみ対応（自動設定）

    <Warning>
      ChatGPT Searchを選択すると、地域は自動的に「United States」、言語は「English」に設定され、変更できません。
    </Warning>
  </Step>
  <Step title="地域・言語を選択（Google AI Overviewsの場合）">
    - **地域**: 12ヶ国から選択（US, JP, UK, DE, FR, AU, CA, IT, ES, BR, KR, IN）
    - **言語**: 9言語から選択（英語, 日本語, ドイツ語, フランス語, スペイン語, イタリア語, ポルトガル語, 韓国語, 中国語）
    - **デフォルト**: 日本 / 日本語
  </Step>
</Steps>

### Step 4: 分析を実行

<Steps>
  <Step title="手動実行">
    「分析を実行」ボタンをクリックして即時実行

    <Warning>
      分析には **100ポイント** が消費されます。実行前にポイント残高をご確認ください。
    </Warning>
  </Step>
  <Step title="結果を確認">
    分析完了後（約10-30秒）、結果画面で詳細を確認
  </Step>
</Steps>

### Step 5: スケジュールを設定（任意）

<Steps>
  <Step title="スケジュール設定を開く">
    プロジェクト詳細画面の「スケジュール設定」セクションへ
  </Step>
  <Step title="スケジュールを有効化">
    スケジュールトグルをオンにします
  </Step>
  <Step title="頻度と時刻を設定">
    - **実行頻度**: 毎日〜月1回から選択
    - **実行時刻**: 30分刻みで選択
    - **メール通知**: 必要に応じてオン
  </Step>
  <Step title="保存">
    設定を保存すると自動実行が開始されます
  </Step>
</Steps>

### Step 6: 定点観測で変化を追跡

<Steps>
  <Step title="定点観測タブを開く">
    スケジュール実行でデータが蓄積されると、定点観測ダッシュボードが利用可能に
  </Step>
  <Step title="期間を選択">
    7日/30日/90日/全期間から分析期間を選択
  </Step>
  <Step title="トレンドを確認">
    - KPIカードで主要指標の増減を確認
    - グラフで時系列変化を可視化
    - アラートで急な変化を検知
  </Step>
</Steps>

## ターゲット設定パラメータ詳細

### キーワードターゲット

| パラメータ             | 説明      | 選択肢                                               |
| ----------------- | ------- | ------------------------------------------------- |
| **value**         | 検索キーワード | 自由入力（例: 楽天ペイ）                                     |
| **match_type**    | マッチ方式   | `word_match`（完全一致）/ `partial_match`（部分一致）         |
| **search_filter** | フィルター   | `include`（含む）/ `exclude`（除外）                      |
| **search_scope**  | 検索範囲    | `any` / `question` / `answer` / `question,answer` |

### ドメインターゲット

| 説明     | 選択肢                                    |
| ------ | -------------------------------------- |
| ドメイン名  | 例: example.com                         |
| フィルター  | `include`（含む）/ `exclude`（除外）           |
| 検索範囲   | `sources`（引用元）/ `search_results`（検索結果） |
| サブドメイン | `true` / `false`                       |

### 共通設定

| 説明       | デフォルト                       |
| -------- | --------------------------- |
| 地域コード    | 2392（日本）                    |
| 言語コード    | ja（日本語）                     |
| プラットフォーム | google（Google AI Overviews） |
| 取得件数上限   | 100件                        |
| ソート順     | AI検索ボリューム降順                 |

### 例1: 継続的なブランド監視

<Steps>

    - **ターゲット**: 自社ブランド名（キーワード、include）

    - **地域/言語**: 日本/日本語
  </Step>
  <Step title="スケジュール設定">
    - **頻度**: 毎日

    - **メール通知**: オン
  </Step>
  <Step title="定点観測での活用">
    - 30日間のトレンドで増減傾向を把握
    - 急増/急減アラートでPR施策の効果や炎上を検知
    - 引用元ドメインの変化でメディア露出状況を追跡
  </Step>
</Steps>

### 例2: 競合ベンチマーク

<Steps>
  <Step title="シナリオ">
    自社と競合3社のAI露出度を定期的に比較したい
  </Step>
  <Step title="プロジェクト設定">
    - 自社用プロジェクト: 自社ブランド名
    - 競合A用プロジェクト: 競合Aブランド名
    - 競合B用プロジェクト: 競合Bブランド名
    - 競合C用プロジェクト: 競合Cブランド名
  </Step>
  <Step title="スケジュール設定">
    - **頻度**: 週1回（全プロジェクト同じ曜日・時刻に設定）
    - **時刻**: 月曜 9:00
  </Step>
  <Step title="分析方法">
    - 各プロジェクトの定点観測ダッシュボードを比較
    - メンション数、AI検索ボリュームの推移を並べて確認
    - 引用元ドメインの違いから差別化ポイントを発見
  </Step>
</Steps>

### 例3: PR施策の効果測定

<Steps>
  <Step title="シナリオ">
    新製品「スマートウォッチX」のプレスリリース効果を追跡
  </Step>
  <Step title="施策前">
    - プロジェクト作成: 「スマートウォッチX」（キーワード）
    - 手動実行でベースライン（施策前の状態）を記録
  </Step>
  <Step title="施策後のスケジュール設定">
    - **頻度**: 施策直後1週間は毎日 → その後は3日に1回
    - **時刻**: 9:00
  </Step>
  <Step title="効果測定">
    - 定点観測で施策前後のメンション数変化を確認
    - 新しく出現した引用元（プレスリリース配信先）を把握
    - AI検索ボリュームの増加でブランド認知の向上を測定
  </Step>
</Steps>

### 例4: 自社サイトの被引用最適化

<Steps>
  <Step title="シナリオ">

  </Step>
  <Step title="プロジェクト設定">

    - **検索スコープ**: sources
    - **サブドメイン**: 含める
  </Step>
  <Step title="スケジュール設定">

  </Step>

    3. 次週の計測で引用状況の変化を確認

  </Step>
</Steps>

## AIチャット機能

分析結果をコンテキストとして、AIに直接質問・相談できます。

### 特徴

- **データを理解したAI**: 分析結果が自動的にAIに共有されるため、具体的なデータに基づいた回答を得られます
- **複数モデル対応**: Claude 4.5、Gemini 2.5 Pro、GPT-4.1、Grok 4.1から選択可能

## よくある質問

<AccordionGroup>
  <Accordion title="ターゲットは何個設定できますか？">
    現在は1つのターゲットのみ設定可能です。自社と競合を比較したい場合は、それぞれ別のプロジェクトを作成してください。
  </Accordion>
  <Accordion title="ChatGPT Searchで日本語分析できますか？">
    現在、ChatGPT SearchはUS/English固定となっています。ChatGPT Searchを選択すると、自動的にUnited States / Englishが設定され、変更できません。日本語での分析はGoogle AI Overviewsをご利用ください。
  </Accordion>
  <Accordion title="スケジュール実行でポイントは自動消費されますか？">
    はい、スケジュール実行ごとに100ポイントが自動消費されます。ポイント残高が不足している場合、実行はスキップされます。
  </Accordion>
  <Accordion title="定点観測を使うにはどうすればいいですか？">
    スケジュールを設定して複数回の分析データが蓄積されると、定点観測ダッシュボードが利用可能になります。最低2回以上の計測データが必要です。
  </Accordion>
  <Accordion title="スケジュールを一時停止できますか？">
    はい、スケジュール設定画面でスケジュールをオフにすることで一時停止できます。設定内容は保持され、再度オンにすれば同じ設定で再開されます。
  </Accordion>
  <Accordion title="分析結果の保存期間は？">
    プロジェクトと分析結果は永続保存されます。
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常10〜30秒程度で完了します。
  </Accordion>
  <Accordion title="「メンション」とは何ですか？">
    メンションとは、AIがあるクエリ（質問）に対して回答し、参照・引用したソースの1件分を指します。具体的には、質問テキスト・AIの回答・引用元URLがセットになったデータです。
  </Accordion>
  <Accordion title="ai_search_volumeとは？">
    AIに対してそのクエリ（質問）が検索された推定回数です。この数値が高いほど、AIトラフィックポテンシャルが高いキーワードと言えます。
  </Accordion>
</AccordionGroup>
