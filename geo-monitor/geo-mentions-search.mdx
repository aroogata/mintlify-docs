## 概要

**GEO検索メンション**は、AI（LLM）があなたのブランド・製品・キーワードについて**言及した回数と具体的な事例**を構造化して分析できる機能です。

<Info>
  「メンション」とは、\*\*AIがあるクエリ（question）に対して回答（answer）し、その回答で参照・引用したソース（sources）\*\*の1件分を指します。つまり「AIがあなたのブランドを言及した回数・事例」を数値とともに可視化します。
</Info>

### AI検索時代の新しいマーケティング指標

従来のSEOでは「検索順位」が重要でしたが、AI検索時代では\*\*「AIにどれだけ引用されるか」\*\*が新たな競争軸です。GEO検索メンションを使えば：

- AIがどんな質問に対して自社ブランドを言及しているか
- どのメディア・サイトを情報源として引用しているか
- 競合と比較してAI上での露出はどうか

これらを**データで可視化**し、戦略的な意思決定を支援します。

## 何のための機能？

GEO検索メンションは、以下のような実務課題を解決します：

### ブランド監視（Reputation）

<Card title="対象ユーザー" icon="user">
  マーケティング担当者、PR担当者、ブランドマネージャー
</Card>

AIが自社や競合をどう言及しているかを把握できます。**ネガティブな言及や誤情報を早期に検知**し、ブランドイメージの毀損を防ぎます。

- AIが「〇〇は品質に問題がある」と回答していないか
- 競合と比較してどのような文脈で言及されているか
- 言及のトーン（ポジティブ/ネガティブ）の傾向

### PR/危機管理

<Card title="対象ユーザー" icon="user">
  広報担当者、危機管理チーム、経営企画
</Card>

あるトピックでメンションが急増した場合、**原因ソース（どのメディアが起点か）を特定**して迅速に対応できます。

- 炎上の発生源となっているメディアの特定
- 誤情報がどのソースから広がっているかの追跡
- 対応策の優先順位付け

### コンテンツ戦略（被引用対策）

<Card title="対象ユーザー" icon="user">
  SEO担当者、コンテンツマーケター、Webディレクター
</Card>

AIが参照しているドメイン・ページを把握し、**AIに引用される確率を上げるコンテンツ設計**が可能になります。

- よく引用されているドメインの特徴分析
- 引用されやすいコンテンツ形式の発見
- 競合が引用されている情報源との差分分析

### SEO/AI可視性最適化（AI Search Optimization）

<Card title="対象ユーザー" icon="user">
  SEOコンサルタント、デジタルマーケター、事業責任者
</Card>

`ai_search_volume`（AI検索ボリューム）や月次推移を見て、**AIトラフィックポテンシャルが高いキーワードを優先的に対策**できます。

- AI検索で需要が高いキーワードの発見
- 月次トレンドから季節性や成長傾向を把握
- 対策優先度の数値化

### 競合分析・ベンチマーク

<Card title="対象ユーザー" icon="user">
  事業戦略担当、マーケティングマネージャー、リサーチャー
</Card>

複数ブランドを同条件で調べ、**AI上での言及量や参照ドメインの差**を比較できます。

- 自社 vs 競合のAI露出度比較
- 競合が引用されているソースの分析
- 市場でのポジショニング把握

### ファクトチェック/品質管理

<Card title="対象ユーザー" icon="user">
  品質管理担当、法務、コンプライアンス
</Card>

AIの回答と参照元が一致しないケースを抽出して**誤情報を洗い出し**、是正要求などの対応が可能です。

- AIが誤った情報を回答していないか
- 引用元と回答内容の整合性チェック
- 訂正依頼先の特定

## 出力指標（KPI）

分析を実行すると、以下の主要指標が表示されます：

| 指標            | 説明                    | 活用方法                         |
| ------------- | --------------------- | ---------------------------- |
| **総メンション数**   | AIがブランド/キーワードを言及した総件数 | ブランド露出規模の把握、時系列での変化追跡        |
| **AI検索ボリューム** | 対象クエリがAIで検索された推定回数    | トラフィックポテンシャルの評価、優先対策キーワードの選定 |
| **ユニーク質問数**   | 異なる質問パターンの数           | 言及されている文脈の多様性を把握             |
| **引用元ドメイン数**  | AIが引用した情報源ドメインの種類     | 情報源の多様性、権威性の評価               |

### 各メンションの詳細データ

| データ項目                | 説明                            |
| -------------------- | ----------------------------- |
| **question**         | AIへの質問テキスト                    |
| **answer**           | AIの回答テキスト（マークダウンリンク形式）        |
| **sources**          | 引用元ソース一覧（URL、ドメイン、タイトル、スニペット） |
| **ai_search_volume** | このクエリのAI検索ボリューム               |
| **monthly_searches** | 過去12ヶ月の月次検索ボリューム推移            |

## 利用手順

### Step 1: プロジェクトを作成

<Steps>
  <Step title="GEO Monitorにアクセス">
    サイドバーから「GEO Monitor」→「検索メンション」タブを選択
  </Step>
  <Step title="新規プロジェクト作成">
    「新規プロジェクト」ボタンをクリック
  </Step>
  <Step title="プロジェクト情報を入力">
    - **プロジェクト名**: 識別しやすい名前を入力（例: 「自社ブランド監視」）
    - **説明**（任意）: プロジェクトの目的などをメモ
  </Step>
</Steps>

### Step 2: ターゲットを設定

<Steps>
  <Step title="ターゲットを追加">
    2〜10個のキーワード/ドメインを設定します

    <Note>
      最低2つのターゲットが必要です。1つだけでは分析できません。
    </Note>
  </Step>
  <Step title="ターゲットタイプを選択">
    - **キーワード**: ブランド名、製品名、トピックなど
    - **ドメイン**: 特定サイトの引用状況を追跡
  </Step>
  <Step title="検索設定を調整">
    - **マッチタイプ**: 完全一致 / 部分一致
    - **検索スコープ**: 質問のみ / 回答のみ / 全体 など
    - **フィルター**: include（含む）/ exclude（除外）

    <Tip>
      **プリセットテンプレート**を使用すると、用途に最適化された設定が自動適用されます。
    </Tip>
  </Step>
</Steps>

### Step 3: 地域・言語・プラットフォームを選択

<Steps>
  <Step title="プラットフォームを選択">
    - **Google AI Overviews**: 全地域・言語対応
    - **ChatGPT**: US/Englishのみ対応

    <Warning>
      ChatGPTを選択した場合、地域・言語は米国・英語に固定されます。
    </Warning>
  </Step>
  <Step title="地域・言語を選択">
    - **地域**: 12ヶ国から選択（US, JP, UK, DE, FR, AU, CA, IT, ES, BR, KR, IN）
    - **言語**: 9言語から選択（英語, 日本語, ドイツ語, フランス語, スペイン語, イタリア語, ポルトガル語, 韓国語, 中国語）
    - **デフォルト**: 日本 / 日本語
  </Step>
</Steps>

### Step 4: 分析を実行・結果確認

<Steps>
  <Step title="分析を実行">
    「分析を実行」ボタンをクリック

    <Warning>
      分析には **50ポイント** が消費されます。実行前にポイント残高をご確認ください。
    </Warning>
  </Step>
  <Step title="結果を確認">
    分析完了後（約10-30秒）、以下のビューで結果を確認できます
  </Step>
</Steps>

## プリセットテンプレート

設定を簡略化するため、4種類のプリセットテンプレートを用意しています：

<AccordionGroup>
  <Accordion title="ブランド監視" icon="eye">
    **用途**: 自社/競合ブランドのAI言及状況を監視

    **設定内容**:

    - ターゲットタイプ: キーワード
    - 検索スコープ: `any`（質問・回答すべてを検索）
    - フィルター: include

    **活用シーン**: 定期的なブランド言及の追跡、ネガティブ言及の早期発見
  </Accordion>
  <Accordion title="競合ベンチマーク" icon="scale-balanced">
    **用途**: 複数ブランドのAI露出を比較

    **設定内容**:

    - ターゲット数: 2つ（自社 vs 競合）
    - 検索スコープ: `any`
    - フィルター: include

    **活用シーン**: 自社と競合のAI露出度比較、市場ポジショニング分析
  </Accordion>
  <Accordion title="ドメイン引用分析" icon="link">
    **用途**: 特定ドメインがAIにどれだけ引用されているか分析

    **設定内容**:

    - ターゲットタイプ: ドメイン
    - 検索スコープ: `sources`（引用元のみを検索）
    - サブドメイン: 含める

    **活用シーン**: 自社サイトの被引用状況、競合サイトの引用傾向分析
  </Accordion>
  <Accordion title="PR効果測定" icon="chart-line">
    **用途**: プレスリリースや施策後のメンション変化を追跡

    **設定内容**:

    - ターゲットタイプ: キーワード
    - 検索スコープ: `question, answer`
    - フィルター: include

    **活用シーン**: 新製品発表後の反応測定、キャンペーン効果の数値化
  </Accordion>
</AccordionGroup>

## ターゲット設定パラメータ詳細

### キーワードターゲット

| パラメータ             | 説明      | 選択肢                                               |
| ----------------- | ------- | ------------------------------------------------- |
| **value**         | 検索キーワード | 自由入力（例: 楽天ペイ）                                     |
| **match_type**    | マッチ方式   | `word_match`（完全一致）/ `partial_match`（部分一致）         |
| **search_filter** | フィルター   | `include`（含む）/ `exclude`（除外）                      |
| **search_scope**  | 検索範囲    | `any` / `question` / `answer` / `question,answer` |

### ドメインターゲット

| パラメータ                  | 説明     | 選択肢                                    |
| ---------------------- | ------ | -------------------------------------- |
| **value**              | ドメイン名  | 例: example.com                         |
| **search_filter**      | フィルター  | `include`（含む）/ `exclude`（除外）           |
| **search_scope**       | 検索範囲   | `sources`（引用元）/ `search_results`（検索結果） |
| **include_subdomains** | サブドメイン | `true` / `false`                       |

### 共通設定

| パラメータ             | 説明       | デフォルト                       |
| ----------------- | -------- | --------------------------- |
| **location_code** | 地域コード    | 2392（日本）                    |
| **language_code** | 言語コード    | ja（日本語）                     |
| **platform**      | プラットフォーム | google（Google AI Overviews） |
| **items_limit**   | 取得件数上限   | 100件                        |
| **order_by**      | ソート順     | AI検索ボリューム降順                 |

## 具体的な利用例

### 例1: PR効果測定

<Steps>
  <Step title="シナリオ">
    新製品「スマートウォッチX」をリリース後、AIでの言及状況を追跡したい
  </Step>
  <Step title="設定">
    - **ターゲット**: 「スマートウォッチX」（キーワード、include）
    - **プラットフォーム**: Google AI Overviews
    - **地域/言語**: 日本/日本語
  </Step>
  <Step title="分析">
    日次または週次で分析を実行し、以下を確認：

    - `ai_search_volume` の推移 → 検索需要の増減
    - `sources` → どのメディアが情報源として引用されているか
    - `answer` → AIの回答が正確か、誤情報がないか
  </Step>
  <Step title="アクション">
    - 主要メディアに引用されていなければ、プレスリリースの配信先を見直す
    - 誤情報があれば、該当メディアに訂正依頼
  </Step>
</Steps>

### 例2: ブランド防衛

<Steps>
  <Step title="シナリオ">
    自社ドメイン以外で、自社ブランドがどう言及されているかを監視したい
  </Step>
  <Step title="設定">
    - **ターゲット1**: 自社ドメイン（ドメイン、**exclude**）
    - **ターゲット2**: 自社ブランド名（キーワード、**include**）
    - 検索スコープ: `any`
  </Step>
  <Step title="分析">
    この設定により、**自社サイト以外でのブランド言及のみ**を抽出：

    - 外部メディアでの言及
    - 口コミサイトや掲示板での言及
    - 誤情報の発生源
  </Step>
  <Step title="アクション">
    - ネガティブな言及があれば、広報チームに共有
    - 誤情報の発生源を特定し、対応策を検討
  </Step>
</Steps>

### 例3: コンテンツ戦略

<Steps>
  <Step title="シナリオ">
    AIに引用されやすいコンテンツを作成するため、引用元の傾向を分析したい
  </Step>
  <Step title="設定">
    - **ターゲット**: 業界キーワード（例: 「電子決済」「QRコード決済」）
    - 検索スコープ: `any`
    - ソート: AI検索ボリューム降順
  </Step>
  <Step title="分析">
    分析結果から以下を抽出：

    - **上位引用ドメイン**: どのサイトがよく引用されているか
    - **引用されているコンテンツ形式**: 解説記事、比較記事、FAQ形式など
    - **質問パターン**: ユーザーがどんな質問をしているか
  </Step>
  <Step title="アクション">
    - 上位引用サイトの特徴を分析（構造、文体、更新頻度）
    - 同等かそれ以上のコンテンツを作成
    - 質問パターンに答える形式のコンテンツを追加
  </Step>
</Steps>

- **データを理解したAI**: 分析結果が自動的にAIに共有されるため、具体的なデータに基づいた回答を得られます
- **複数モデル対応**: Claude 4.5、Gemini 2.5 Pro、GPT-4.1、Grok 4.1から選択可能
- **Web検索オプション**: 最新情報を加味した回答が必要な場合に有効化

  </Accordion>

    通常10〜30秒程度で完了します。ターゲット数やフィルター設定により変動します。
  </Accordion>
  <Accordion title="「メンション」とは何ですか？">
    メンションとは、AIがあるクエリ（質問）に対して回答し、参照・引用したソースの1件分を指します。具体的には、質問テキスト・AIの回答・引用元URLがセットになったデータです。
