## 概要

GEOモニタリングは、**主要なAI検索（ChatGPT・Google AI Overviews・Gemini・Claude・Perplexity）の回答の中で、自社ブランドがどのように言及・引用・評価されているか**をクエリ単位で継続監視するダッシュボードです。重要なキーワード・質問を登録しておき、AIの回答を定期的に取得することで、AI検索時代のブランド可視性（GEO：Generative Engine Optimization）の変化を追跡できます。

<Info>
  プロジェクトに監視クエリを登録し、「AIライブチェック」を実行すると、各AIプラットフォームの回答を取得して、ブランド言及・引用・感情（センチメント）・推奨度などを自動スコア化します。スケジュール実行で定期的に自動取得することもできます。
</Info>

### 主な用途

- **AI露出の継続監視**: 重要クエリでブランドがAIに引用・言及されているかを追跡
- **施策の効果測定**: PR・コンテンツ施策の前後でスコアの変化を確認
- **競合との比較**: AI回答内での競合の出現状況を把握
- **ネガティブ文脈の早期発見**: 望ましくない言及・感情の傾向を検知
- **経営層への報告**: AI分析レポートをPDFで出力

## 対応AIプラットフォーム

監視したいプラットフォームを複数選択でき、それぞれで回答を取得します。

| プラットフォーム | 消費ポイント | 取得速度 |
| --- | --- | --- |
| **ChatGPT Search** | 1pt / クエリ | 数分 |
| **Google AI Overviews** | 1pt / クエリ | 数秒 |
| **Gemini** | 1pt / クエリ | 数分 |
| **Perplexity** | 1pt / クエリ | 数秒 |
| **Claude** | 2pt / クエリ | 20分以上 |

<Note>
  Claudeは回答取得に20分以上かかる場合があります。取得はバックグラウンドで継続するため、完了を待つ間に他のページへ移動できます。ChatGPTは米国・英語に固定されます。
</Note>

## 仕組み

GEOモニタリングは「プロジェクト → 監視クエリ → AIライブチェック → スコア化」という流れで動作します。

<Steps>
  <Step title="プロジェクトを作成">
    監視対象のドメイン・ブランド名・競合・地域・言語、監視するAIプラットフォームを設定します。
  </Step>
  <Step title="監視クエリを登録">
    AIに尋ねたいキーワードや質問を登録します（手動追加またはURLからの自動提案）。
  </Step>
  <Step title="AIライブチェックを実行">
    登録クエリを各AIプラットフォームで実行し、回答を取得します（または定期実行をスケジュール）。
  </Step>
  <Step title="スコアと傾向を確認">
    GEO総合スコア・センチメント・引用率などを確認し、推移を追跡します。
  </Step>
</Steps>

## プロジェクト設定

| 項目 | 説明 |
| --- | --- |
| **プロジェクト名** | 監視プロジェクトの識別名 |
| **ドメイン** | 監視対象のメインドメイン（例：`example.com`） |
| **ブランド名** | AI回答内で検出するブランド名（複数登録可） |
| **競合ドメイン・ブランド名** | 比較対象の競合（回答内での出現を検出） |
| **地域・言語** | 監視する検索市場（多数の地域・言語に対応／デフォルト：日本・日本語） |
| **AIプラットフォーム** | ChatGPT / AI Overviews / Gemini / Claude / Perplexity（複数選択可） |
| **サブドメイン設定** | 引用判定でサブドメインを含めるか |

## クエリ管理

| 方法 | 説明 |
| --- | --- |
| **手動追加** | キーワードや質問文を入力して追加 |
| **AI自動提案** | URLを入力すると、ページ内容を解析してGEO対策に有効なクエリを自動生成。必要なものを選んで追加 |

- **クエリ数の上限**: 1プロジェクトあたり最大50件
- **1クエリの文字数**: 最大500文字

各クエリには、AIライブチェックの結果に応じてステータス（引用あり／引用なし／未チェック）が表示されます。

## 料金

AIライブチェックは、**プラットフォーム別のポイント × クエリ数**を消費します。

| プラットフォーム | ポイント / クエリ |
| --- | --- |
| ChatGPT Search | 1pt |
| Google AI Overviews | 1pt |
| Gemini | 1pt |
| Perplexity | 1pt |
| Claude | 2pt |

<Note>
  複数プラットフォームを選択している場合は、それぞれのポイントが加算されます。

  - 例：5クエリ × \[ChatGPT(1pt) \+ Gemini(1pt)\] = **10pt**
  - 例：10クエリ × Claude(2pt) = **20pt**

  分析実行前にポイント残高を確認し、不足している場合は実行しません。取得に失敗したクエリ分は返金されます。
</Note>

無料で利用できる操作：結果・履歴の閲覧、プロジェクト・クエリ管理、スケジュール設定。

## GEO総合スコア

各計測結果には、AI検索でのブランド存在感を示す **GEO総合スコア（0〜100点）** が付きます。スコアは以下の観点を総合して算出されます。

| 観点 | 評価内容 |
| --- | --- |
| **ブランド言及** | AI回答内でブランド名が言及されているか・回数 |
| **引用** | 引用元に自社サイトが含まれているか |
| **感情分析（センチメント）** | ブランド言及がポジティブか |
| **推奨度** | AIがどの程度推奨的に言及しているか |
| **リンク順位** | 引用元リンクの表示位置 |

<Note>
  スコアの算出方法は、プラットフォームが引用情報を返すかどうかによって最適化されます。一般に60点以上で良好、80点以上で強い存在感の目安です。
</Note>

## ダッシュボード

選択したプロジェクトの状況を一覧表示します。

- **KPIカード**: GEO総合スコア、センチメント構成比、引用率、競合検出率、ブランド言及数
- **グラフ**: 引用可視性の推移（折れ線）、センチメント構成比（円グラフ）
- **クエリ一覧カード**: クエリごとのステータス・スコア推移（スパークライン）・引用率などのサマリー
- **日付セレクター**: 特定日付のデータに絞り込んで表示

## クエリ詳細ページ

クエリをクリックすると、全期間のデータを詳細に分析できます。

| 要素 | 内容 |
| --- | --- |
| **Visibility Trend** | GEO総合スコアなどの推移グラフ（プラットフォーム別に色分け、目標・警告ラインを表示） |
| **メトリクスカード** | ブランド言及・引用率・計測回数・引用内訳・感情分析・AI推奨度・競合検出などの全期間集計 |
| **タイムラインビュー** | 計測日時・プラットフォーム・スコア・AI回答全文・引用元・感情を時系列で表示 |
| **データテーブル** | 計測データを表形式で一覧（ソート可能） |
| **メモ機能** | 各計測に施策日などのメモを記録（施策との因果を後から確認できる） |

<Tip>
  同じクエリでも、AIプラットフォーム（ChatGPT・AI Overviews・Gemini・Claude・Perplexity）ごとに回答・引用・感情が異なります。プラットフォーム別に個別確認できます。
</Tip>

## AI分析レポート

クエリ詳細画面から、計測データをAIが読み解いた**分析レポートを自動生成**できます。

- **内容**: エグゼクティブサマリー、AI露出分析、センチメント分析、競合ポジション、推奨アクション
- **保存期間**: 3ヶ月間（経過後は自動削除）
- **出力**: 印刷・PDF出力に対応（経営層への報告に最適）
- **一覧管理**: レポート一覧ページ（`/geo/ai-monitor/reports`）でプロジェクト・期間・キーワードで検索・絞り込み

## スケジュール実行

クエリを定期的に自動取得できます。AIの回答は日々変動するため、定期取得で傾向を捉えるのが効果的です。

| 設定 | 選択肢 |
| --- | --- |
| **実行頻度** | 毎日 / 3日ごと / 毎週 / 毎月（手動のみも選択可） |
| **実行時刻** | 30分刻みで指定（日本時間で実行） |
| **メール通知** | 実行完了時に通知（オプション） |

<Warning>
  ポイント不足・プロジェクト無効化・クエリ削除などの場合、スケジュール実行は自動的に停止し、画面に警告が表示されます。
</Warning>
