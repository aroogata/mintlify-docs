## 概要

**GEOモニタリング**は、AI検索エンジン（Google AI Overviews、ChatGPT、Gemini、Claude）における自社ブランドの露出・言及状況をモニタリングするダッシュボードです。

<Info>
  AI検索時代において、SEOの次に重要なのが\*\*GEO（Generative Engine Optimization）\*\*です。従来の検索エンジン最適化に加え、「AIに正しく引用されるか」が今後のデジタルマーケティングの鍵を握ります。
</Info>

### GEOとは

**GEO = Generative Engine Optimization**

ChatGPT、Google AI Overviews、Gemini、Claudeなどの生成AI検索において、自社のコンテンツやブランドが適切に引用・言及されるように最適化する取り組みです。

<Info>
  AIに引用される新常識「GEO」とは？ChatGPTやGeminiに選ばれるための完全ガイド
</Info>

### 何のために使うか

- **AI検索での露出状況把握**: 自社ドメイン・キーワードがAIにどれだけ引用されているかを数値で可視化
- **競合モニタリング**: 競合他社のAI露出状況と自社を比較分析
- **クエリ監視**: 重要なキーワードでのAI回答内容を定期的に監視
- **自動スケジュール実行**: 定期的なAI検索結果の自動取得・蓄積

ダッシュボードには、登録したクエリのAI検索露出状況が一目でわかるKPIカードとグラフが表示されます。

### KPIカード（スコア指標）

<AccordionGroup>
  <Accordion title="GEO総合スコア（/100）" icon="gauge">
    **AI検索での露出品質を100点満点で総合評価したスコアです。**

    以下の5つの成分の合計で算出されます（各20点満点）：

    | 成分     | 配点  | 意味                   |
    | ------ | --- | -------------------- |
    | ブランド言及 | /20 | AI回答内でブランド名が言及されているか |
    | 引用     | /20 | 回答の引用元に自社サイトが含まれているか |
    | 感情分析   | /20 | ブランドへの言及がポジティブか      |
    | 推奨度    | /20 | AIがどれだけ推奨的に言及しているか   |
    | リンク順位  | /20 | 引用元リンクの表示位置          |

    <Tip>
      60点以上を目指しましょう。80点以上であればAI検索で強い存在感を示しています。
    </Tip>
  </Accordion>
  <Accordion title="ブランド言及スコア（/20）" icon="message-square">
    **AI回答内でブランド名がテキストで言及されているかを評価します。**

    | 言及状況   | スコア |
    | ------ | --- |
    | 言及なし   | 0点  |
    | 1回言及   | 12点 |
    | 2回以上言及 | 20点 |

    <Info>
      複数回言及されることで、ユーザーへの認知度が高まります。
    </Info>
  </Accordion>
  <Accordion title="引用スコア（/20）" icon="link">
    **AI回答の引用元（参照リンク）に自社ドメインが含まれているかを評価します。**

    | 引用状況 | スコア |
    | ---- | --- |
    | 引用あり | 20点 |
    | 引用なし | 0点  |

    <Warning>
      引用されることで、AI経由のトラフィック獲得につながります。最も重要な指標の一つです。
    </Warning>
  </Accordion>
  <Accordion title="感情分析スコア（/20）" icon="smile">
    **ブランドへの言及がポジティブ・ニュートラル・ネガティブのどれかを評価します。**

    | 感情            | スコア |
    | ------------- | --- |
    | Positive（好意的） | 20点 |
    | Neutral（中立的）  | 12点 |
    | Negative（否定的） | 0点  |

    <Info>
      ネガティブな言及が続く場合は、PR戦略の見直しが必要かもしれません。
    </Info>
  </Accordion>
  <Accordion title="推奨度スコア（/20）" icon="thumbs-up">
    **AIがどれだけ推奨的・肯定的にブランドを言及しているかを評価します。**

    内部的には0-100のスコアを計算し、それを20点満点に変換しています。言及位置、言及回数、文脈の肯定度を総合的に判断します。
  </Accordion>
  <Accordion title="リンク順位スコア（/20）" icon="list-ordered">
    **引用元リンクの表示順位を評価します。上位に表示されるほど高スコアです。**

    | 順位    | スコア |
    | ----- | --- |
    | 1位    | 20点 |
    | 2位    | 18点 |
    | 3位    | 15点 |
    | 4〜5位  | 10点 |
    | 6〜10位 | 5点  |
    | 11位以下 | 0点  |

    <Tip>
      引用元リンクの1〜3位を目指すことで、クリック率が大幅に向上します。
    </Tip>
  </Accordion>
  <Accordion title="センチメント傾向" icon="chart-pie">
    **全クエリの感情分析結果のうち、最も多い傾向を表示します。**

    - **Positive**: ポジティブな言及が最多
    - **Neutral**: ニュートラルな言及が最多
    - **Negative**: ネガティブな言及が最多
  </Accordion>
</AccordionGroup>

## スケジュール機能

GEOモニタリングでは、AIライブチェックを自動で定期実行するスケジュール機能を利用できます。

![GEOモニタリング02](/images/GEOモニタリング02.jpg)

### スケジュール設定オプション

| 設定項目      | 選択肢                                    |
| --------- | -------------------------------------- |
| **実行頻度**  | 毎日 / 2日に1回 / 3日に1回 / 週1回 / 2週に1回 / 月1回 |
| **実行時刻**  | 0:00〜23:30（30分刻みで選択）                   |
| **メール通知** | 実行完了時にメールで通知（オプション）                    |

### スケジュール設定手順

<Steps>
  <Step title="プロジェクト管理タブを開く">
    GEOモニタリングの「プロジェクト管理」タブに移動
  </Step>
  <Step title="プロジェクトを選択">
    スケジュールを設定したいプロジェクトを選択または編集
  </Step>
  <Step title="スケジュール設定を有効化">
    「スケジュール実行」セクションでスケジュールを有効化
  </Step>
  <Step title="頻度と時刻を設定">
    実行頻度（毎日〜月1回）と実行時刻（JST）を選択
  </Step>
  <Step title="設定を保存">
    「スケジュール設定を保存」ボタンをクリック
  </Step>
</Steps>

<Tip>
  次回実行予定時刻は設定画面に表示されます。スケジュールはすべて日本時間（JST）で動作します。
</Tip>

## 利用手順

### Step 1: プロジェクトを作成

![GEOモニタリング03](/images/GEOモニタリング03.jpg)

<Steps>
  <Step title="GEOモニタリングにアクセス">
    サイドバーから「GEOモニタリング」を選択してダッシュボードを開きます
  </Step>
  <Step title="新規プロジェクト作成">
    各ページの右上にある「新規プロジェクト」ボタンをクリック
  </Step>
  <Step title="プロジェクト情報を入力">
    以下の情報を設定します：

    - **プロジェクト名**: 識別しやすい名前（例: 「自社ブランド監視」）
    - **ドメイン**: 監視対象のメインドメイン（例: mycompany.com）
    - **地域・言語**: 分析対象の地域と言語
    - **AIプラットフォーム**: 監視対象のAIエンジンを選択
  </Step>
</Steps>

### Step 2: 監視クエリを追加

![GEOモニタリング04](/images/GEOモニタリング04.jpg)

<Steps>
  <Step title="プロジェクト管理タブを開く">
    GEOモニタリングの「プロジェクト管理」タブに移動
  </Step>
  <Step title="監視クエリ管理セクション">
    手動で追加：新しいキーワードを入力にチェックしたいキーワードや簡単な文章を入力してプラスボタンをクリックで追加
  </Step>
  <Step title="AI自動提案">
    AI自動提案ボタンをクリックするとURLの入力欄が出てきます。チェックしたいページのURLを入力して生成ボタンをクリックで自動的に指定したURLのコンテンツを解析して、GEO対策に有効な質問形式のクエリを50個提案します。必要なものをチェックして追加してください。

    <Tip>
      ブランド名、製品名、業界キーワードなど、自社に関連する重要なキーワードを設定しましょう。
    </Tip>
  </Step>
</Steps>

### Step 3: AIライブチェックを実行

![GEOモニタリング05](/images/GEOモニタリング05.jpg)

<Steps>
  <Step title="AIライブチェックを実行">
    ダッシュボードの「AIライブチェック」ボタンをクリックして、登録したクエリの一括分析を実行します。

    <Warning>
      分析にはポイントが消費されます（AIプラットフォームごとに1〜2pt/クエリ）。実行前にポイント残高をご確認ください。
    </Warning>
  </Step>
  <Step title="進行状況を確認">
    実行中は画面右下にトースト通知が表示され、リアルタイムで進捗状況を確認できます。

    - **処理中**: 青色のトーストで現在の処理状況を表示
    - **完了**: 緑色のトーストで成功を通知
    - **エラー**: 赤色のトーストでエラー内容を表示

    <Tip>
      分析中に他のページに移動しても、バックグラウンドで処理が継続されます。ダッシュボードに戻ると最新の結果が反映されています。
    </Tip>
  </Step>
  <Step title="結果を確認">
    分析完了後、クエリ一覧に最新の結果が表示されます。各クエリの行をクリックすると詳細画面に移動できます。
  </Step>
</Steps>

    <Tip>
      ソースとリンクの両方に含まれると、より高い露出効果が期待できます。

  <Accordion title="競合検出" icon="users">
    **AI回答内で競合ブランドが検出された割合（%）です。**

    - **表示例**: `33%`
    - **計算方法**: 競合が検出された計測数 ÷ 総計測数 × 100

    <Warning>
      競合検出率が高い場合、AIが競合ブランドも一緒に言及している可能性があります。差別化ポイントを明確にするコンテンツ戦略が必要かもしれません。
    </Warning>
  </Accordion>
</AccordionGroup>

### Step 5: AI分析レポートを作成

クエリ詳細画面から、AIによる詳細な分析レポートを生成できます。

![GEOモニタリング08](/images/GEOモニタリング08.jpg)

    - **AI露出分析**: 各AIプラットフォームでの言及状況
    - **センチメント分析**: ブランドに対する感情傾向
    - **競合ポジション**: 競合との相対的な位置づけ

</Steps>

## よくある質問

<AccordionGroup>
  <Accordion title="プロジェクトは何個まで作成できますか？">
    1アカウントあたり最大50個までプロジェクトを作成できます。目的別にプロジェクトを整理することをお勧めします。
  </Accordion>
  <Accordion title="監視クエリは何個まで登録できますか？">
    1プロジェクトあたり最大50個までクエリを登録できます。重要なキーワードに絞って登録することをお勧めします。
  </Accordion>
  <Accordion title="スケジュール実行はいつ行われますか？">
    設定した時刻（日本時間）に自動で実行されます。実行頻度は毎日〜30日に1回まで選択可能です。
  </Accordion>
  <Accordion title="分析はどのくらいの頻度で実行すべきですか？">
    週1〜2回の定期的な実行を推奨します。AI回答は日々変動するため、定期的なモニタリングが効果的です。スケジュール機能を活用すると便利です。
  </Accordion>
  <Accordion title="Gemini・Claudeの取得に時間がかかるのはなぜですか？">
    GeminiとClaudeは他のプラットフォームと比較して処理に時間がかかります。20分以上かかる場合がありますので、余裕を持ってご利用ください。
  </Accordion>
  <Accordion title="ChatGPTで日本語分析できますか？">
    現在、ChatGPTはUS/English固定となっています。日本語での分析はGoogle AI Overviewsをご利用ください。
  </Accordion>
  <Accordion title="分析結果の保存期間は？">
    分析結果は永続保存されます。過去のデータと比較してトレンドを分析できます。履歴一覧では過去12時間分の結果を確認できます。
  </Accordion>
  <Accordion title="サブドメインを含めるとどうなりますか？">
    「サブドメインを含む」を選択すると、メインドメインに加えてサブドメイン（例: blog.example.com, shop.example.com）のAI言及も分析対象になります。
  </Accordion>
</AccordionGroup>
