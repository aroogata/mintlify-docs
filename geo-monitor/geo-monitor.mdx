## 概要

GEOモニタリングは、**主要なAI検索（ChatGPT・Google AI Overviews・Gemini・Claude・Perplexity）の回答の中で、自社ブランドがどのように言及・引用・評価されているか**をクエリ単位で継続監視するダッシュボードです。重要なキーワード・質問を登録しておき、AIの回答を定期的に取得することで、AI検索時代のブランド可視性（GEO：Generative Engine Optimization）の変化を追跡できます。

<Info>
  プロジェクトに監視クエリを登録し、「AIライブチェック」を実行すると、各AIプラットフォームの回答を取得して、ブランド言及・引用・感情（センチメント）・推奨度などを自動スコア化します。スケジュール実行で定期的に自動取得することもできます。蓄積したデータは **ブランド言及CSV** や **引用ドメインCSV** として書き出し、ExcelやBIツールで二次分析できます。
</Info>

### 主な用途

- **AI露出の継続監視**: 重要クエリでブランドがAIに引用・言及されているかを追跡
- **施策の効果測定**: PR・コンテンツ施策の前後でスコアやブランド言及率の変化を確認
- **競合との比較**: AI回答内での競合ブランド・競合サイトの出現状況を把握
- **引用元の把握**: AIがどのサイト・どのページを根拠にしているかをランキングで確認
- **二次分析・報告**: CSV出力でExcel・BIツールに取り込み、レポート印刷やAI分析レポートで共有

</Note>

## 仕組み

GEOモニタリングは「プロジェクト → 監視クエリ → AIライブチェック → スコア化」という流れで動作します。

<Steps>
  <Step title="プロジェクトを作成">
    監視対象のドメイン・ブランド名・競合・地域・言語、監視するAIプラットフォームを設定します。
  </Step>
  <Step title="監視クエリを登録">
    AIに尋ねたいキーワードや質問を登録します（手動追加またはURLからの自動提案）。
  </Step>
  <Step title="AIライブチェックを実行">
    登録クエリを各AIプラットフォームで実行し、回答を取得します（または定期実行をスケジュール）。
  </Step>
  <Step title="スコアと傾向を確認">
    GEO総合スコア・センチメント・引用率・引用元ドメインなどを確認し、推移を追跡します。必要に応じてCSVで書き出して二次分析します。
  </Step>
</Steps>

## プロジェクト設定

![プロジェクト設定](/images/プロジェクト設定.png "プロジェクト設定")

| 項目 | 説明 |
| --- | --- |
| **プロジェクト名** | 監視プロジェクトの識別名 |
| **ドメイン** | 監視対象のメインドメイン（例：`example.com`） |
| **ブランド名** | AI回答内で検出するブランド名。カンマ区切りで複数登録できます（例：`デル, Dell, XPS13`） |
| **競合ドメイン・競合ブランド名** | 比較対象の競合。回答内での出現（競合ブランド名）と参照元での引用（競合ドメイン）を検出します |
| **地域・言語** | 監視する検索市場（多数の地域・言語に対応／デフォルト：日本・日本語） |
| **AIプラットフォーム** | ChatGPT / AI Overviews / Gemini / Claude / Perplexity（複数選択可） |
| **除外URLパス** | 自社サイトの引用としてカウントしないURLパス（例：`/campaign/`）。カンマ区切りで複数指定できます |
| **備考** | プロジェクトの説明や計測目的など（任意。レポート印刷にも表示されます） |

<Tip>
  ブランド名の判定は大文字・小文字を区別しません。「Dell」と「DELL」のように大文字・小文字だけが違う名前は同じ名前として扱われるため片方だけ登録し、「デル」と「Dell」のように文字そのものが異なる表記ゆれをそれぞれ登録してください。
</Tip>

## クエリ管理

![クエリ管理](/images/クエリ管理.png "クエリ管理")

| 方法 | 説明 |
| --- | --- |
| **手動追加** | キーワードや質問文を入力して追加 |
| **AI自動提案** | URLを入力すると、ページ内容を解析してGEO対策に有効なクエリを自動生成。必要なものを選んで追加 |

- **クエリ数の上限**: 1プロジェクトあたり最大50件
- **1クエリの文字数**: 最大500文字
- 同じ質問文を重複して登録しないでください。CSVでは「取得日 × 監視クエリ × 生成AI」で計測を識別するため、重複登録すると区別できなくなります

各クエリには、AIライブチェックの結果に応じてステータス（引用あり／引用なし／未チェック）が表示されます。

## 料金

AIライブチェックは、**プラットフォーム別のポイント × クエリ数**を消費します。

| プラットフォーム | ポイント / クエリ |
| --- | --- |
| ChatGPT Search | 1pt |
| Google AI Overviews | 1pt |
| Gemini | 1pt |
| Perplexity | 1pt |
| Claude | 10pt |

<Note>
  複数プラットフォームを選択している場合は、それぞれのポイントが加算されます。

  - 例：5クエリ × \[ChatGPT(1pt) \+ Gemini(1pt)\] = **10pt**
  - 例：10クエリ × Claude(10pt) = **100pt**

  分析実行前にポイント残高を確認し、不足している場合は実行しません。取得に失敗したクエリ分は返金されます。
</Note>

| 操作 | ポイント |
| --- | --- |
| AI分析レポート生成（クエリ詳細ページ） | 100pt / レポート |
| 結果・履歴の閲覧、プロジェクト・クエリ管理、スケジュール設定 | 無料 |
| ブランド言及CSV・引用ドメインCSVのダウンロード、レポート印刷 | 無料 |

## GEO総合スコア

各計測結果には、AI検索でのブランド存在感を示す **GEO総合スコア（0〜100点）** が付きます。5つの観点をそれぞれ20点満点で評価し、合計します。

| 観点 | 評価内容 |
| --- | --- |
| **ブランド言及** | AI回答内でブランド名が言及されているか・回数 |
| **引用** | 参照元（出典）に自社サイトが含まれているか |
| **感情分析（センチメント）** | ブランド言及がポジティブか |
| **推奨度** | AIがどの程度推奨的に言及しているか |
| **リンク順位** | 引用元リンクの表示位置 |

<Note>
  スコアの算出方法は、プラットフォームが引用情報を返すかどうかによって最適化されます。一般に60点以上で良好、80点以上で強い存在感の目安です。
</Note>

### 引用元ドメイン分析

![引用元ランキング](/images/引用元ランキング.png "引用元ランキング")

AI回答が参照元（出典）や回答内リンクとして引用したサイト・ページを集計するセクションです。

| 要素 | 内容 |
| --- | --- |
| **期間切替** | 全期間／月／週。月・週はカレンダーから対象を選びます |
| **日付チップ** | 期間内の計測日を個別に除外できます（例：異常値の日を外す）。除外は上部の集計カードにも反映されます |
| **ドメインランキング** | 引用されたサイトの Top 20。自社・競合にはバッジが付きます |
| **トレンド** | Top 10 ドメインの日別推移（計測日が2日以上あるときに表示） |
| **引用URLランキング** | 引用されたページ単位の Top 20。ページのフルURLをリンクで表示し、その下にページタイトル（参照元の場合）またはリンクテキスト（回答内リンクの場合）を表示します |

引用URLランキングの各行には次の情報が付きます。

- **N回出現**: 表示中の期間の回答のうち、そのページが参照元または回答内リンクとして登場した**回答の数**です。1回答 = 監視クエリ × 生成AI × 計測日の1件で、同じ回答内に同じURLが複数回あっても1回と数えます
- **引用元／回答内リンク**: 参照元（出典）として提示されたか、回答文中のリンクとして登場したか。両方に登場したページには両方のバッジが付きます
- **ドメイン表示**: 2026年8月27〜28日ごろの Google AI Overviews は引用先をページURLではなくリダイレクト用のリンクで提供していたため、その期間の引用はドメインまでを表示しています（現在は通常どおりページURLを表示します）

<Tip>
  各見出しやボタンの横にある「i」マークにカーソルを合わせると、数え方や対象期間の説明が表示されます。
</Tip>

## ブランド言及CSV

「どのクエリで」「どの生成AIで」「いつから」自社ブランドが登場するようになったか、競合とどれだけ露出差があるかを、Excel・BIツールで横断分析するためのCSVです。「ブランド言及CSV」ボタンを押すと次のメニューが表示されます。

| メニュー | 内容 |
| --- | --- |
| **詳細（1行 = 1計測結果）** | 監視クエリ × 生成AI × 取得日ごとに1行。時系列の推移やピボットテーブルでの自由な集計向け |
| **集計（クエリ × 生成AI）** | 監視クエリ × 生成AI ごとに計測回数・ブランド言及率・競合言及率などをまとめた表。まず全体の傾向をつかむのに便利 |
| **項目の説明を2行目に含める** | オンにすると各列の意味が2行目に入ります（Excelで見る用）。BIツールやピボットテーブルに取り込む場合はデータ行として数えられるためオフにしてください |
| **項目の説明（CSV）** | 詳細・集計の全列の「列名」と「説明」を一覧にした別ファイル |

メニューの先頭に「出力対象期間: 2026-09（月）・2日を除外」のように現在の対象が表示されます。対象期間は引用元ドメイン分析の期間切替と除外日にそのまま連動し、ファイル名にも期間が入ります。

### 詳細CSVの主な列

| 列 | 意味 |
| --- | --- |
| 取得日 | 生成AIに質問して回答を記録した日 |
| 監視クエリ／生成AI／プラットフォームコード | 質問文、回答したAI（ChatGPT Search など）、AIのシステム上の識別子 |
| ステータス | 成功＝回答を取得できた計測、エラー＝取得できなかった計測（率の計算からは除く） |
| 自社ブランド言及（1=あり） | 回答に自社ブランド名が1回でも出てきたら 1、出てこなければ 0 |
| 自社ブランド名の出現回数 | 回答に自社ブランド名が出てきた回数（全ブランド名の合計） |
| 出現回数:ブランド名 | ブランド名ごとの出現回数。登録したブランド名の数だけ列が増えます |
| 競合言及（1=あり）／競合出現回数:競合ブランド名 | 競合ブランド名が回答に出てきた、または競合サイトが参照元として引用されていたら 1。競合ブランド名ごとの回数も出力 |
| 競合ドメイン引用（1=あり） | 参照元に競合サイトのドメインが含まれていたら 1 |
| 自社サイト引用（1=あり）／自社サイト引用順位 | 参照元に自社サイトが含まれていたか、何番目に出てきたか |
| プロジェクト名 | LinkSurge 上のプロジェクト名 |

真偽値は Excel で合計・平均をそのまま計算できるよう `1／0` で出力します。たとえば「ステータス」が「成功」の行だけに絞って「自社ブランド言及（1=あり）」の列を平均すると、そのまま言及率になります。

### 集計CSVでよく聞かれる2つの列

| 列 | 意味 | 例（3回計測して出現回数が 2回・0回・3回のとき） |
| --- | --- | --- |
| 自社ブランド言及あり計測数 | ブランド名が1回でも出てきた**計測の数** | 2 |
| 自社ブランド名の出現回数合計 | 全回答に出てきたブランド名の**延べ回数** | 5 |
| 自社ブランド言及率（%） | 言及あり計測数 ÷ 計測回数（成功） | 66.7 |

「どのくらいの頻度で言及されるか」は言及率、「言及されるときにどれだけ強く推されているか」の目安には出現回数合計を使います。

### 言及の数え方

- 回答文にブランド名が含まれるかを、大文字・小文字の区別なく数えます
- 対象はプロジェクト設定の「ブランド名」に登録した名前です。競合はプロジェクト設定の「競合ブランド名」「競合ドメイン」をもとに判定します
- 競合ドメインの引用は、参照元のドメインが競合ドメインと完全一致またはそのサブドメインのときに「あり」とします

<Note>
  1回のダウンロードで扱える計測結果は 100,000 件までです（例：監視クエリ50件 × 生成AI5種類 × 毎日計測で約400日分）。これを超える場合はメッセージが表示されるので、「月」や「週」を選んで期間を絞ってからダウンロードしてください。短時間に何度も実行すると制限がかかることがあります（目安として1分間に5回程度）。
</Note>

## AI分析レポート

クエリ詳細画面から、計測データをAIが読み解いた**分析レポートを自動生成**できます（100pt／レポート）。

- **内容**: エグゼクティブサマリー、AI露出分析、センチメント分析、競合ポジション、推奨アクション
- **保存期間**: 3ヶ月間（経過後は自動削除）
- **出力**: 印刷・PDF出力に対応（経営層への報告に最適）
- **一覧管理**: レポート一覧ページ（`/geo/ai-monitor/reports`）でプロジェクト・期間・キーワードで検索・絞り込み

## スケジュール実行

クエリを定期的に自動取得できます。AIの回答は日々変動するため、定期取得で傾向を捉えるのが効果的です。

| 設定 | 選択肢 |
| --- | --- |
| **実行頻度** | 毎日 / 3日ごと / 毎週 / 毎月（手動のみも選択可） |
| **実行時刻** | 30分刻みで指定（日本時間で実行） |
| **メール通知** | 実行完了時に通知（オプション） |

<Warning>
  ポイント不足・プロジェクト無効化・クエリ削除などの場合、スケジュール実行は自動的に停止し、画面に警告が表示されます。
</Warning>

## 制限事項

| 項目 | 制限 |
| --- | --- |
| プロジェクト数 | 最大50件 / アカウント |
| クエリ数 | 最大50件 / プロジェクト |
| 1クエリの文字数 | 最大500文字 |
| レポート保存期間 | 3ヶ月 |
| ブランド言及CSVの1回あたり件数 | 計測結果 100,000 件まで（期間を絞って分割可能） |
| ChatGPTの地域・言語 | 米国・英語に固定 |

## よくある質問

<AccordionGroup>
  <Accordion title="どのAIプラットフォームに対応していますか？">
    ChatGPT Search・Google AI Overviews・Gemini・Claude・Perplexity の5つに対応しています。プロジェクトごとに複数選択でき、それぞれで回答を取得します。
  </Accordion>

  <Accordion title="ポイントはどのように消費されますか？">
    プラットフォーム別のポイント × クエリ数で消費します。ChatGPT・AI Overviews・Gemini・Perplexityは1pt/クエリ、Claudeは10pt/クエリ（2026年9月7日〜）です。複数プラットフォームを選択するとそれぞれ加算されます。AI分析レポートの生成は100pt/レポートです。CSVダウンロードとレポート印刷は無料です。
  </Accordion>

  <Accordion title="Claudeの結果はどのくらいで届きますか？">
    1分程度で届きます（計測方式の刷新前は20分以上かかっていました）。取得はバックグラウンドで継続するため、他のページに移動して待つことができます。
  </Accordion>

  <Accordion title="GEO総合スコアは何を表していますか？">
    AI検索でのブランド存在感を0〜100点で示す指標です。ブランド言及・引用・感情分析・推奨度・リンク順位の5成分（各20点満点）を合計して算出されます。60点以上で良好、80点以上で強い存在感が目安です。
  </Accordion>

  <Accordion title="ブランド言及CSVの「詳細」と「集計」はどちらを使えばよいですか？">
    まず全体の傾向をつかむなら「集計」、日付ごとの変化を追ったりピボットテーブルで自由に集計したりするなら「詳細」をお使いください。どちらも引用元ドメイン分析で選んでいる期間と除外日がそのまま反映されます。
  </Accordion>

  <Accordion title="CSVの各項目の意味はどこで確認できますか？">
    ブランド言及CSVのメニューにある「項目の説明を2行目に含める」をオンにすると、各列の意味が2行目に入ります。「項目の説明（CSV）」を選ぶと、全列の説明を一覧にした別ファイルをダウンロードできます。
  </Accordion>

  <Accordion title="引用URLランキングの「3回出現」は何を数えていますか？">
    表示中の期間の回答のうち、そのページが参照元または回答内リンクとして登場した回答の数です。1回答は「監視クエリ × 生成AI × 計測日」の1件で、同じ回答内に同じURLが複数回あっても1回と数えます。ドメインランキングは同じ数え方をサイト単位にまとめたものです。
  </Accordion>

  <Accordion title="引用URLがサイトのトップページになっている行があるのはなぜですか？">
    多くは、AIの回答文中のリンク（回答内リンク）がサイトのトップページを指していたケースです。その場合、下に表示される文字列はページタイトルではなくリンクの表示テキストです。また「ドメイン表示」バッジが付いている行は、2026年8月27〜28日ごろの Google AI Overviews が引用先をリダイレクト用のリンクで提供していた期間のデータで、ドメインまでを表示しています。
  </Accordion>

  <Accordion title="クエリは自分で考える必要がありますか？">
    手動で追加することも、URLを入力してAIに監視クエリを自動提案させることもできます。自動提案では、ページ内容を解析してGEO対策に有効なクエリが生成されます。
  </Accordion>

  <Accordion title="日本語で分析できますか？">
    はい。地域「日本」・言語「日本語」で分析できます。ただしChatGPTは米国・英語に固定されるため、日本語分析にはAI Overviewsなどの利用をおすすめします。
  </Accordion>
</AccordionGroup>

## 仕様

| 項目 | 仕様 |
| --- | --- |
| 対応プラットフォーム | ChatGPT Search / AI Overviews / Gemini / Claude / Perplexity |
| 消費ポイント | 1pt/クエリ（ChatGPT・AI Overviews・Gemini・Perplexity）／10pt/クエリ（Claude）× クエリ数 |
| GEO総合スコア | 0〜100点（ブランド言及・引用・感情・推奨度・リンク順位の5成分 × 20点） |
| 引用元ドメイン分析 | 期間切替（全期間／月／週）・日付除外・ドメインランキング Top20・トレンド Top10・引用URLランキング Top20 |
| CSV出力 | 引用ドメインCSV／ブランド言及CSV（詳細・集計・項目説明）。BOM付きUTF-8、Excelでそのまま開ける。1回あたり計測結果 100,000 件まで |
| レポート印刷 | 別タブでA4レポートを表示し、印刷・PDF保存 |
| プロジェクト数 | 最大50件 |
| クエリ数 | 最大50件 / プロジェクト（1クエリ最大500文字） |
| スケジュール | 毎日 / 3日ごと / 毎週 / 毎月（時刻指定・メール通知あり） |
| AI分析レポート | 自動生成（100pt）・3ヶ月保存・PDF出力 |
| 対応地域・言語 | 多数の地域・言語（デフォルト：日本・日本語。ChatGPTは米国・英語固定） |
