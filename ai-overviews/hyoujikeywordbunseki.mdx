## 概要

<video src="/videos/aio-ranking.mp4" controls={true} />

**AIO表示キーワード分析**は、Google検索結果に表示されるAI Overview（AIオーバービュー）で、自社サイトが引用されているキーワードを網羅的に分析する機能です。

AI Overviewは2024年から本格的に導入されたGoogle検索の新機能で、検索結果の最上部にAIが生成した回答を表示します。この回答には参照元として複数のWebサイトが引用され、新たなトラフィック獲得チャネルとして注目されています。

### 主な特徴

  </Card>

## 月間流入予想の計算方法

<Warning>
  この計算方法は複数の調査データに基づく推定値です。実際のトラフィックは、コンテンツの品質、表示位置の変動、ユーザー行動の変化などにより異なる場合があります。
</Warning>

### AI Overview内CTR係数

AI Overviewは検索結果の最上部に表示されますが、ユーザーはAI生成回答で満足する傾向があり、引用リンクのCTR（クリック率）は従来のSERP順位より**大幅に低い**ことが調査で判明しています。

<Tabs>
  <Tab title="CTR係数一覧">
    | AIO内位置 | CTR係数 | 従来SERP相当順位 |
    | ------ | ----- | ---------- |
    | 1位     | 4.0%  | 6位相当       |
    | 2位     | 2.2%  | 8位相当       |
    | 3位     | 1.2%  | 10-11位相当   |
    | 4位     | 0.6%  | 14位相当      |
    | 5位     | 0.3%  | 19位相当      |
    | 6位以降   | 0.1%  | -          |
  </Tab>
  <Tab title="計算式">
    ```
    AIO月間流入予想 = 月間検索ボリューム × AIO CTR係数
    ```

    **計算例**：

    - 検索ボリューム: 10,000
    - AIO内位置: 1位
    - CTR係数: 4.0%（0.040）
    - **月間流入予想: 10,000 × 0.040 = 400**
  </Tab>
  <Tab title="実装コード">
    ```typescript
    // src/lib/ctr-coefficients.ts
    export const AIO_CTR_COEFFICIENTS: Record<number, number> = {
      1: 0.040,  // 4.0%
      2: 0.022,  // 2.2%
      3: 0.012,  // 1.2%
      4: 0.006,  // 0.6%
      5: 0.003,  // 0.3%
    };
    export const AIO_CTR_DEFAULT = 0.001;  // 6位以降: 0.1%
    
    export function calculateAIOTraffic(
      searchVolume: number,
      aioPosition: number
    ): number {
      if (!searchVolume || searchVolume <= 0) return 0;
      if (!aioPosition || aioPosition <= 0) return 0;
    
      const ctr = AIO_CTR_COEFFICIENTS[aioPosition] ?? AIO_CTR_DEFAULT;
      return Math.round(searchVolume * ctr);
    }
    ```
  </Tab>
</Tabs>

### AIO表示時のSERP CTR減衰

<Note>
  AI Overviewが表示されるキーワードでは、ユーザーの注意がAIOに集中するため、従来のオーガニック検索結果のCTRは大幅に低下します。
</Note>

複数の調査結果を総合的に分析した結果、AIO表示時のSERP CTRは\*\*非表示時の約40%\*\*に低下することが判明しました。

| 調査機関                | AIO表示時CTR | 非表示時CTR | 減衰率     |
| ------------------- | --------- | ------- | ------- |
| Pew Research Center | 8%        | 15%     | 53%     |
| Seer Interactive    | 0.61%     | 1.62%   | 38%     |
| **本システム採用値**        | -         | -       | **40%** |

<Tabs>
  <Tab title="計算式">
    ```
    SERP月間流入予想（AIO表示あり）= 月間検索ボリューム × SERP CTR係数 × 0.40
    SERP月間流入予想（AIO表示なし）= 月間検索ボリューム × SERP CTR係数
    ```

    **計算例**（AIO表示あり）：

    - 検索ボリューム: 10,000
    - SERP順位: 3位
    - SERP CTR係数: 9.73%（0.0973）
    - 減衰係数: 40%（0.40）
    - **月間流入予想: 10,000 × 0.0973 × 0.40 = 389**
  </Tab>
  <Tab title="実装コード">
    ```typescript
    // src/lib/ctr-coefficients.ts
    export const SERP_CTR_WITH_AIO_FACTOR = 0.40;
    
    export function calculateSERPTraffic(
      searchVolume: number,
      serpPosition: number,
      hasAIO: boolean = true
    ): number {
      if (!searchVolume || searchVolume <= 0) return 0;
      if (!serpPosition || serpPosition <= 0) return 0;
    
      const baseCtr = SERP_CTR_COEFFICIENTS[serpPosition] ?? SERP_CTR_DEFAULT;
      const adjustedCtr = hasAIO ? baseCtr * SERP_CTR_WITH_AIO_FACTOR : baseCtr;
    
      return Math.round(searchVolume * adjustedCtr);
    }
    ```
  </Tab>
</Tabs>

### CTR係数の根拠データソース

本システムのCTR係数は、以下の調査データを参考に設定しています。

<AccordionGroup>
  <Accordion icon="chart-pie" title="Pew Research Center（2024年）">
    **調査内容**: AI Overview表示時のユーザー行動調査

    **主な発見**:

    - AI Overview表示時のリンククリック率: 約8%
    - AI Overview非表示時のリンククリック率: 約15%
    - **結論**: AI Overview表示により、リンクへのクリックが約半分に減少
  </Accordion>
  <Accordion icon="newspaper" title="Search Engine Land（2024年）">
    **調査内容**: AI Overview内のポジション別CTR分析

    **主な発見**:

    - AI Overview内1位のCTRは、従来オーガニック6位相当
    - AI Overview内で上位でも、従来SERPの上位ほどのCTRは得られない
    - **結論**: AI Overview引用は新たなトラフィックソースだが、1位あたりのCTRは低い
  </Accordion>
  <Accordion icon="users" title="TrustRadius（2024年）">
    **調査内容**: AI Overview内ポジション間のCTR比較

    **主な発見**:

    - AI Overview内ポジション1のCTRは、ポジション2の約2倍
    - 上位ポジションへの集中度が高い
    - **結論**: AI Overview内でも上位ポジションの重要性は高い
  </Accordion>
  <Accordion icon="microscope" title="Seer Interactive（2024年）">
    **調査内容**: AI Overview表示がオーガニックCTRに与える影響

    **主な発見**:

    - AI Overview表示時のオーガニックCTR: 0.61%
    - AI Overview非表示時のオーガニックCTR: 1.62%
    - **結論**: AI Overview表示により、オーガニックCTRが約38%に低下
  </Accordion>
</AccordionGroup>

## よくある質問

<AccordionGroup>
  <Accordion title="AIO引用とSERP順位は連動していますか？">
    必ずしも連動していません。AI Overviewはコンテンツの質や関連性を独自に評価して引用元を選定するため、SERP順位が低くてもAIOに引用されることがあります。逆に、SERP1位でもAIOに引用されないケースもあります。
  </Accordion>
  <Accordion title="月間流入予想はどの程度正確ですか？">
    本システムの月間流入予想は、複数の調査データに基づく推定値です。実際のトラフィックは以下の要因により変動します：

    - AI Overviewの表示頻度の変化
    - ユーザー行動の地域差・時期差
    - コンテンツの更新による引用位置の変動
    - Googleアルゴリズムの更新

    目安として活用し、Google Search Consoleの実測値と併せて評価することを推奨します。
  </Accordion>
  <Accordion title="データが見つからない場合はポイントが消費されますか？">
    いいえ、データが見つからなかった場合はポイントは消費されません。ただし、検索は実行されるため、ドメインやURLの入力ミスがないか事前にご確認ください。
  </Accordion>
  <Accordion title="どのくらいの頻度で分析すべきですか？">
    AI Overviewの引用状況は日々変動する可能性があります。以下を目安に定期的な分析を推奨します：

    - **重要ドメイン**: 週1回
    - **一般的なモニタリング**: 月1回
    - **競合分析**: 月1回
  </Accordion>
  <Accordion title="SERP順位が「-」と表示されるのはなぜですか？">
    AIOには引用されているが、同一キーワードのオーガニック検索結果（100位以内）にはランクインしていない場合、SERP順位は「-」と表示されます。これはAIO独自の引用選定基準によるものです。
  </Accordion>
  <Accordion title="DataForSEOのETVとの違いは何ですか？">
    DataForSEOが提供するETV（Estimated Traffic Value）は従来のSERP CTR係数をベースに計算されています。しかし、AI Overviewからの流入は従来SERPより大幅に低いCTRとなるため、本システムでは独自の調査データに基づくCTR係数を適用し、より正確な流入予想を算出しています。
  </Accordion>
</AccordionGroup>
