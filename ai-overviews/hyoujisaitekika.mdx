## 概要

AIO表示分析は、ドメインまたはURLを入力するだけで、そのサイトが **Google AI Overviews（AIO）で表示されているキーワード** を一覧で取得できるツールです。各キーワードについて、AI Overviewsからの推定流入数・従来の検索順位・検索ボリューム・検索意図・SEO難易度などをまとめて確認でき、AI検索時代の可視性（GEO：Generative Engine Optimization）を把握できます。

<Info>
  1回の分析で、AI Overviews内での掲載順位・推定流入・従来検索（SERP）順位と推定流入・月間検索ボリューム・検索意図・SEO難易度・SERP機能・競合指標までをまとめて取得します。キーワードごとに何度も調べる必要はありません。
</Info>

### 主な用途

- **AI検索での可視性チェック**: 自社サイトがAI Overviewsでどのキーワードに表示されているかを把握
- **競合サイトの分析**: 任意のドメイン/URLを入力し、競合がAI検索でどれだけ露出しているかを調査
- **GEO（AI検索最適化）の優先順位付け**: 流入ポテンシャルの高いキーワードを特定して施策を立案
- **流入インパクトの試算**: AI Overviews表示が従来検索の流入に与える影響を推定

## 料金

AIO表示分析は、**取得するキーワード件数に応じた固定ポイント**を消費します。取得件数が多いほど消費ポイントが増加します。

| 最大取得件数 | 消費ポイント |
| --- | --- |
| 100件 | **30pt** |
| 500件 | **50pt** |
| 1000件（デフォルト） | **100pt** |

<Note>
  ポイントは **AI Overviews表示キーワードが1件以上見つかった場合のみ** 消費されます。対象が見つからなかった場合（AI Overviewsでの表示がない場合）はポイントを消費しません。また、ポイントが不足している場合は分析を実行せず、必要ポイントを表示します。
</Note>

<Tip>
  まずは少額の **100件（30pt）** から試し、流入が見込めるサイトであれば1000件で網羅的に取得する、という使い分けがおすすめです。
</Tip>

## 分析範囲（マッチタイプ）

入力したURLをどの範囲で分析するかを3種類から選択できます。選択した範囲によって、集計対象となるページが変わります。

| マッチタイプ | 説明 | 例 |
| --- | --- | --- |
| **ドメイン一致** | 指定ドメイン全体を分析（既定） | `example.com/*` |
| **前方一致** | サブドメイン・サブフォルダを含めて分析 | `*.example.com/path/*` |
| **完全一致** | 指定したURLそのものだけを分析 | `example.com/page` |

<Tip>
  サブドメインやサブディレクトリ全体の結果を取得したい場合は、`aaa.bbb.com` や `aaa.com/bbb/` のように入力し、**前方一致** で分析してください。入力時に `https://` は自動で取り除かれます。
</Tip>

## 詳細設定

### 地域・言語

分析対象とする検索市場を選択します。言語は地域に応じて自動で決定されます。

| 地域 | 言語 |
| --- | --- |
| 日本（デフォルト） | 日本語 |
| アメリカ | 英語 |
| イギリス | 英語 |

### 最大取得件数

AI Overviewsで表示されているキーワードを最大何件まで取得するかを指定します（100件 / 500件 / 1000件）。件数が多いほど網羅性が高まりますが、消費ポイントも増加します。

### トラフィック推定レベル（L1〜L5）

検索結果へのAIの登場により、トラフィック推定は従来より複雑になっています。業界やAIの出現状況によって推定値は大きく変動するため、推定の保守度を5段階で切り替えられます。

| レベル | 名称 | 説明 |
| --- | --- | --- |
| **L1** | 控えめ推定 | AI Overviewの影響を大きく見積もり、最も少なめの推定値を表示 |
| **L2** | やや控えめ推定 | 影響をやや大きめに見積もる保守的な設定 |
| **L3** | 標準推定（デフォルト） | 標準的な検索環境を想定。多くのサイトに適した設定 |
| **L4** | やや積極的推定 | 影響をやや小さめに見積もる。ブランド力が強いサイト向け |
| **L5** | 積極的推定 | 影響を小さく見積もる。ナビゲーショナル検索が多いサイト向け |

<Info>
  レベルを切り替えると、テーブルやチャートに表示される **AIO流入予想・SERP流入予想がリアルタイムで再計算** されます。分析をやり直す必要はなく、ポイントも消費しません。
</Info>

## 出力指標

分析が完了すると、順位分布チャートとキーワードの詳細テーブルが表示されます。

### 推定流入の考え方

LinkSurgeでは、独自にキャリブレーションしたCTR（クリック率）モデルで推定流入を算出します。可能な場合は **実際のユーザー行動データ（クリックストリーム）に基づく検索ボリューム** を優先して計算するため、より実態に近い数値が得られます。

| 指標 | 説明 |
| --- | --- |
| **AIO流入予想** | AI Overviews内での掲載順位とCTR係数から算出した月間の推定流入数 |
| **SERP流入予想** | 従来検索（オーガニック）順位からの推定流入。AI Overviews表示による従来クリックの減少を考慮して算出 |

### 順位分布チャート

AI Overviews内での掲載順位の分布を、**1位 / 2-3位 / 4-10位 / 11-20位 / 21-100位** の区分で可視化します。上位掲載が多いほど、AI検索での流入ポテンシャルが高いことを示します。

### キーワードテーブル

取得した各キーワードについて、以下の指標を一覧表示します。任意の列でソートでき、キーワード名での絞り込み検索も可能です。

| 列 | 説明 |
| --- | --- |
| **キーワード** | AI Overviews内で引用されているキーワード（Google検索へのリンク・コピー対応） |
| **AIO流入予想** | 選択中の推定レベルでのAI Overviewsからの月間推定流入 |
| **SERP順位** | そのキーワードでの従来検索（オーガニック）順位 |
| **SERP流入予想** | 従来検索からの月間推定流入（AIO表示による減衰を考慮） |
| **UR** | ページの強さを0〜100で評価するURL Rating |
| **ページタイトル** | AI Overviewsに引用されたページのタイトル |
| **月間検索Vol** | キーワードの月間検索ボリューム（実測データを優先） |
| **CPC** | クリック単価（リスティング広告の参考指標） |
| **広告競合難易度** | リスティング広告の競合度（低 / 中 / 高） |
| **SEO難易度** | キーワードの難易度スコア（0〜100、色分け表示） |
| **SERP機能** | 検索結果に表示される機能（強調スニペット・FAQ・動画など） |
| **検索意図** | 商業 / 情報 / ナビゲーション / 取引 / 複合の分類バッジ |
| **月別検索ボリューム** | 過去12ヶ月の検索ボリューム推移（簡易グラフ） |
| **競合指標** | そのキーワードでランクインしている競合の被リンク数・参照ドメイン数・DRの平均 |

<Tip>
  SEO難易度は数値が小さいほど上位表示しやすいキーワードです。**AIO流入予想が大きく、SEO難易度が低い** キーワードは、優先的に対策する価値があります。
</Tip>

## 利用手順

<Steps>
  <Step title="ドメイン/URLの入力">
    分析したいドメインまたはURLを入力します。 例: `example.com`、`example.com/blog/`
  </Step>
  <Step title="分析範囲の選択">
    ドメイン一致 / 前方一致 / 完全一致 から分析範囲を選択します。
  </Step>
  <Step title="地域・取得件数の設定">
    地域（日本 / アメリカ / イギリス）と、最大取得件数（100 / 500 / 1000件）を選択します。
  </Step>
  <Step title="分析開始">
    分析を実行すると、取得件数に応じたポイントを消費し、結果が表示されます。

    <Warning>
      AI Overviews表示キーワードが見つかった場合のみポイントを消費します。分析結果がすべて表示される前にページを離れると、履歴に記録されない場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    順位分布チャートとキーワードテーブルを確認します。トラフィック推定レベル（L1〜L5）を切り替えて、推定流入の変化を確認できます。
  </Step>
  <Step title="深掘り・出力（任意）">
    「AIに質問」でGEO改善案を相談したり、CSVで結果をダウンロードして社内共有・レポート作成に活用します。
  </Step>
</Steps>

## AIに質問（GEOアシスタント）

分析結果の画面では、右下のボタンからAIアシスタントに質問できます。取得したキーワードや順位分布のデータを踏まえて、**AI Overviewsで表示されるための具体的な改善策（GEO対策）** を相談できます。

- 「AI Overviewsで表示されるためにはどうすればいいですか？」といった基本的な質問
- 順位分布や高ボリュームキーワードに基づいた、データドリブンな最適化提案
- 低順位キーワードの改善アドバイス

## CSV出力

取得したキーワードと全指標をCSV形式でダウンロードできます（Excelで文字化けしないBOM付き）。社内共有やクライアント向けレポートの素材として活用してください。

## 結果の保持

<Warning>
  分析結果は **12時間** 保持されます。12時間経過後、または保存件数が上限を超えた場合、古い結果から自動的に削除されます。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり。12時間以内でも50件を超えた分は古いものから削除）
- **履歴ページ**: フォーム右側の「履歴」ボタン、または `/aio-ranking-history` から過去の分析結果を再表示できます

## よくある質問

<AccordionGroup>
  <Accordion title="分析できるURLの形式は？">
    以下の形式に対応しています。

    - ドメインのみ: `example.com`
    - パス付き: `example.com/blog/`
    - サブドメイン: `blog.example.com`

    入力時に `https://` は自動で取り除かれます。分析範囲（マッチタイプ）で「ドメイン一致／前方一致／完全一致」を選べます。
  </Accordion>

  <Accordion title="結果が0件のときもポイントは消費されますか？">
    いいえ。AI Overviews表示キーワードが1件も見つからなかった場合は、ポイントを消費しません。対象サイトがAI Overviewsで表示されていないことを意味します。
  </Accordion>

  <Accordion title="取得件数はどれを選べばよいですか？">
    まずは **100件（30pt）** で表示状況を確認し、流入が見込めるサイトであれば **1000件（100pt）** で網羅的に取得するのがおすすめです。件数が多いほど消費ポイントが増加します。
  </Accordion>

  <Accordion title="トラフィック推定レベル（L1〜L5）はどれを選べばよいですか？">
    多くのサイトはデフォルトの **L3（標準推定）** が適しています。ブランド力が強くナビゲーショナル検索が多いサイトはL4〜L5、保守的に見積もりたい場合はL1〜L2を選択してください。レベルを変えると推定流入の数値がリアルタイムで再計算され、ポイントは消費しません。
  </Accordion>

  <Accordion title="AIO流入予想とSERP流入予想の違いは？">
    AIO流入予想はAI Overviews内での掲載順位に基づく推定流入、SERP流入予想は従来検索（オーガニック）順位に基づく推定流入です。SERP流入予想は、AI Overviews表示によって従来検索のクリックが減少する影響を考慮して算出しています。
  </Accordion>

  <Accordion title="競合サイトも分析できますか？">
    はい。任意のドメイン/URLを入力して分析できます。競合がAI検索でどのキーワードに表示されているかを把握し、自社のGEO戦略立案に活用できます。
  </Accordion>

  <Accordion title="結果を保存しておきたい場合は？">
    分析結果の保持期間は12時間です。長期保存したい場合は、CSV出力機能でダウンロードして保存してください。
  </Accordion>
</AccordionGroup>
