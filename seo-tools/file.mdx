## 概要

画像生成は、**テキストや記事・YouTube台本などをもとに、図解・インフォグラフィック・サムネイル画像をAI（Gemini）で自動生成**するツールです。ブログのアイキャッチ、解説図、YouTubeサムネイルなどを、デザインの知識がなくても作成できます。

<Info>
  入力モードに応じて、単一の図解からURL記事のセクション別図解、YouTube台本のシーン別画像、YouTubeサムネイルまで生成できます。生成前にAIが作成したプロンプトを確認・編集でき、スタイルや言語も選べます。
</Info>

### この機能でできること

- **ブログ・記事の図解**: テキストや記事URLから、内容を要約した図解・インフォグラフィックを生成
- **YouTubeサムネイル**: タイトルから、クリックされやすいサムネイルを6パターンで生成
- **台本からシーン画像**: YouTube台本を入力し、シーンごとの画像を一括生成
- **画像から画像**: 既存画像をアップロードして、別の画像に変換・編集

## 入力モード

| モード | 入力 | 生成されるもの |
| --- | --- | --- |
| **単一画像** | タイトル＋テキスト | 1枚の図解画像 |
| **複数セクション** | タイトル＋テキスト | 内容を複数セクションに分け、各セクションの画像 |
| **記事URL** | 記事のURL | 記事の見出しを抽出し、セクションごとの図解 |
| **YouTubeサムネイル** | 動画タイトル | 16:9のYouTubeサムネイル |
| **台本** | YouTube台本テキスト＋生成枚数 | 台本をシーンに分割し、シーンごとの画像 |

## 料金

| 操作 | 消費ポイント |
| --- | --- |
| 画像生成（1枚） | **40pt** |
| 記事URLの解析 | **10pt** |
| 台本の解析 | **10pt** |
| プロンプトの生成・再生成 | 無料 |
| 保存画像の閲覧・ダウンロード | 無料 |

<Note>
  - 単一画像やYouTubeサムネイルは、プロンプト生成は無料で、画像生成時に1枚40ptを消費します。
  - 記事URL・台本モードは、解析時に10ptを消費し、そこから生成する各画像に40ptずつ消費します。
  - 例：台本を解析（10pt）してシーン画像を3枚生成 = 10 \+（3 × 40）= **130pt**
</Note>

## 画像スタイル

生成する画像のデザインスタイルを選べます。

| スタイル | 説明 |
| --- | --- |
| **シンプル** | クリーンでモダンなデザイン |
| **かわいい** | パステルカラーでポップなデザイン |
| **プロフェッショナル** | ビジネス向けの洗練されたモノトーン基調 |
| **インフォグラフィック** | グラフ・数値・アイコンを活用したデータ重視 |
| **フラット** | ベクター風イラスト、シンプルなシェイプ |
| **詳細・リアル** | 立体感・グラデーション・テクスチャを活用 |

## YouTubeサムネイル

YouTubeサムネイルモードでは、動画タイトルから次の6パターンを選んで生成できます。

| パターン | 印象 |
| --- | --- |
| **ドラマチック** | 映画ポスター風の強いコントラスト |
| **カラフル** | 鮮やかでエネルギッシュ |
| **ミニマル** | 余白を活かした洗練デザイン |
| **顔・表情** | 人物の表情を大きく配置したリアクション系 |
| **ゲーム／アニメ** | エフェクトの効いたエネルギッシュな構図 |
| **教育・解説** | 図解・アイコン中心のわかりやすいデザイン |

<Tip>
  サムネイルや台本モードでは、後からアバターやテロップを重ねるための**合成スペース**（アバター・テロップの位置）を指定できます。指定したエリアは背景のみで生成されるため、動画編集ソフトで素材を重ねやすくなります。
</Tip>

## 画像から画像（変換）

既存の画像をアップロードして、別の画像に変換・編集できます。変換の強度や生成枚数、サイズなどを調整して、元画像をベースにしたバリエーションを作成できます。

## カスタマイズ

- **プロンプト編集**: AIが生成したプロンプトを確認し、自由に編集してから生成できます
- **修正指示**: 生成した画像に対して「文字を大きく」などの修正指示を出して再生成できます
- **言語**: 画像内の文字や説明を日本語／英語で生成できます
- **透過背景**: 単一画像・複数セクション・インフォグラフィックでは、背景を透過PNGで生成できます

## 出力・保存

- **形式・比率**: 16:9を基本に、PNG形式で生成（altテキストも自動生成されます）
- **ダウンロード**: 生成画像をワンクリックでダウンロード（ファイル名に日時とタイトルを付与）
- **保存**: 生成画像をアカウントに保存して再利用できます

<Note>
  保存できる画像は **ユーザーあたり最大10枚** です。11枚目を保存すると、最も古い画像が自動的に削除されます。保存画像に有効期限はありません（手動または上限超過で削除されるまで保持されます）。残しておきたい画像はダウンロードもしておくことをおすすめします。
</Note>

## よくある質問

<AccordionGroup>
  <Accordion title="1枚生成するのにいくらかかりますか？">
    画像生成は1枚40ptです。記事URL・台本モードは解析に10ptが別途かかり、そこから生成する各画像に40ptずつ消費します。プロンプトの生成・再生成は無料です。
  </Accordion>

  <Accordion title="どんな入力から画像を作れますか？">
    テキスト（単一・複数セクション）、記事URL、YouTubeタイトル、YouTube台本から生成できます。また、既存画像をアップロードして変換することもできます。
  </Accordion>

  <Accordion title="YouTubeサムネイルにアバターやテロップを後から入れたいです">
    サムネイル・台本モードでは、アバターやテロップを重ねるための合成スペースを指定できます。その領域は背景のみで生成されるため、編集ソフトで素材を重ねやすくなります。
  </Accordion>

  <Accordion title="生成した画像はずっと保存されますか？">
    保存できるのはユーザーあたり最大10枚で、上限を超えると古いものから自動削除されます。有効期限はありませんが、残したい画像はダウンロードしておくと安心です。
  </Accordion>

  <Accordion title="日本語の文字入り画像は作れますか？">
    はい。言語に日本語を選ぶと、画像内の文字や説明が日本語で生成されます。英語も選択できます。
  </Accordion>
</AccordionGroup>
