## 概要

関連キーワード分析は、メインキーワードを起点として、関連するキーワードを階層構造で展開・分析するツールです。

<Info>
  キーワードを入力するだけで、そのキーワードに関連する語句を最大5階層まで深掘りし、各キーワードの検索ボリューム・CPC・競合度・難易度などの詳細データを取得できます。
</Info>

### 主な用途

- **キーワード拡張**: メインキーワードから派生するロングテールキーワードを発見
- **コンテンツ戦略**: 関連キーワードを網羅した包括的なコンテンツ計画を立案
- **競合分析**: 競合が狙っていないニッチなキーワードを発掘
- **サイト構造設計**: キーワードの階層構造を基にサイト設計を最適化
- **SEO機会発見**: 検索ボリュームがあり競合度が低いキーワードを特定

## 料金

関連キーワード分析は、1回の分析につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| メイン分析（初回） | 10pt |
| 深掘り分析（追加） | 10pt |

<Note>
  深掘り分析は、結果テーブル内のキーワードをクリックすることで実行できます。各深掘り分析ごとに10ポイントを消費します。
</Note>

## 階層構造（深度）について

関連キーワード分析は、キーワードを階層的に展開します。

| 深度 | 説明 | 例 |
|-----|------|-----|
| Depth 0 | メインキーワード | 「SEO対策」 |
| Depth 1 | 第1階層の関連キーワード | 「SEO対策 初心者」「SEO対策 費用」 |
| Depth 2 | 第2階層の関連キーワード | 「SEO対策 初心者 やり方」 |
| Depth 3 | 第3階層の関連キーワード | より具体的なロングテール |
| Depth 4 | 第4階層の関連キーワード | 最も詳細なキーワード |

<Tip>
  深い階層になるほど、より具体的で競合度の低いロングテールキーワードが見つかります。ニッチな検索需要を発見するのに効果的です。
</Tip>

## 出力指標

### キーワード指標

<CardGroup cols={2}>
  <Card title="検索ボリューム" icon="magnifying-glass-chart">
    月間平均検索回数。値が大きいほど需要が高いキーワード
  </Card>
  <Card title="キーワード難易度" icon="gauge">
    上位表示の難易度（0〜100）。値が高いほど競争が激しい
  </Card>
  <Card title="競合度" icon="users">
    Google Ads広告の競争度（0.0〜1.0）。値が高いほど広告競争が激しい
  </Card>
  <Card title="CPC（クリック単価）" icon="dollar-sign">
    Google Adsでの推定クリック単価（円）
  </Card>
</CardGroup>

### 競合度レベル

| レベル | 値の範囲 | 説明 |
|--------|---------|------|
| LOW | 0.0〜0.33 | 競争が少なく、参入しやすい |
| MEDIUM | 0.34〜0.66 | 中程度の競争 |
| HIGH | 0.67〜1.0 | 競争が激しく、上位表示が困難 |

### 検索意図（Search Intent）

| 意図 | 説明 | 例 |
|------|------|-----|
| Informational | 情報を得ることが目的 | 「SEO対策とは」「SEO対策 方法」 |
| Commercial | 購入前の調査・比較 | 「SEO対策 会社 比較」「SEO対策 費用」 |
| Transactional | 購入・契約が目的 | 「SEO対策 依頼」「SEO対策 見積もり」 |
| Navigational | 特定サイトへのアクセス | 「Google SEO ガイドライン」 |

### SERP要素

各キーワードの検索結果ページに表示される要素を確認できます。

| 要素 | 説明 |
|------|------|
| organic | 通常の検索結果 |
| featured_snippet | 強調スニペット（0位表示） |
| people_also_ask | 「他のユーザーも行った質問」 |
| video | 動画結果 |
| local_pack | ローカルパック（地図表示） |
| news | ニュース結果 |
| related_searches | 関連する検索 |
| ads_top | 上部広告 |

### バックリンク情報

上位表示に必要な被リンク状況の目安を確認できます。

| 指標 | 説明 |
|------|------|
| backlinks | 上位サイトの平均被リンク数 |
| referring_domains | 参照元ドメイン数 |
| main_domain_rank | ドメインランク（平均値） |

## 利用手順

<Steps>
  <Step title="メインキーワードの入力">
    分析したいキーワードを入力します。例: 「SEO対策」「Webマーケティング」
  </Step>
  <Step title="地域・言語の選択">
    分析対象の地域と言語を選択します。デフォルトは日本・日本語です。
  </Step>
  <Step title="分析開始">
    「分析開始」ボタンをクリックして分析を実行します。
    <Warning>
      分析中はページを離れないでください。分析が中断される場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、関連キーワードが階層テーブルで表示されます。
  </Step>
  <Step title="深掘り分析（任意）">
    興味のあるキーワードをクリックすると、そのキーワードをさらに深掘りできます。
    <Note>
      深掘り分析は各10ポイントを消費します。
    </Note>
  </Step>
  <Step title="CSV出力（任意）">
    「CSV出力」ボタンから分析結果をダウンロードできます。
  </Step>
</Steps>

## 対話式深掘り分析

関連キーワード分析の特徴的な機能として、対話式の深掘り分析があります。

### 使い方

1. 結果テーブルで気になるキーワードをクリック
2. 既に子キーワードがある場合は展開/折りたたみ
3. 子キーワードがない場合は深掘り分析を実行
4. 新しい関連キーワードが階層下に追加される

### キーワード履歴（ブレッドクラム）

深掘り分析を行うと、画面上部にキーワード履歴が表示されます。これにより、現在どの階層を分析しているかを把握できます。

```
SEO対策 → SEO対策 初心者 → SEO対策 初心者 やり方
```

## サンプル機能

ポイントを消費せずに関連キーワード分析機能を体験できます。

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、「SEO対策」をメインキーワードとしたサンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータ:**
- メインキーワード: 「SEO対策」
- 関連キーワード数: 15件
- 含まれるデータ: 検索ボリューム、CPC、競合度、キーワード難易度、検索意図、SERP要素

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## URL連携機能

他のページから関連キーワード分析を直接起動できます。

```
/related-keywords-analysis?keyword=SEO対策&auto=true&location=Japan&language=Japanese
```

| パラメータ | 説明 | 必須 |
|-----------|------|------|
| keyword | 分析するキーワード | ○ |
| auto | true を指定すると自動実行 | ○ |
| location | 地域（デフォルト: Japan） | × |
| language | 言語（デフォルト: Japanese） | × |

## よくある質問

<AccordionGroup>
  <Accordion title="深掘り分析はどこまでできますか？">
    最大5階層（Depth 4）まで深掘りできます。
    各深掘りごとに10ポイントを消費します。
  </Accordion>
  <Accordion title="取得できるキーワード数に制限はありますか？">
    1回の分析で最大50件の関連キーワードを取得できます。
    深掘り分析を行うことで、さらに多くのキーワードを取得できます。
  </Accordion>
  <Accordion title="同じキーワードを再分析するとポイントは消費されますか？">
    はい、再分析ごとにポイントが消費されます。
    ただし、12時間以内であれば過去の分析履歴から結果を確認することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="関連キーワードが少ない場合はどうすればいいですか？">
    以下の方法を試してください：
    - より一般的なキーワードで分析する
    - 深掘り分析で個別のキーワードを展開する
    - 異なる表現のキーワードで試す
  </Accordion>
  <Accordion title="キーワード難易度はどのように計算されていますか？">
    キーワード難易度は、上位表示サイトの被リンク数、参照ドメイン数、ドメインランクなどから算出されています。
    値が高いほど、上位表示に必要なSEO施策が多くなります。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。
    Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
  <Accordion title="分析結果はどこで確認できますか？">
    分析結果は「最近の分析結果を見る」ボタンから過去12時間以内の結果を確認できます。
    または、/related-keywords-history にアクセスしてください。
  </Accordion>
</AccordionGroup>
