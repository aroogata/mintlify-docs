## 概要

**SEO順位チェックツール**は、指定したキーワードにおけるGoogle検索順位とAI Overviews（旧SGE）順位を一元管理・計測するダッシュボードです。手動計測だけでなく、毎日自動で順位をチェックするスケジュール機能も搭載しています。

<Info>
  SEO順位だけでなく、AI Overviews内での引用順位も同時に計測。これにより、従来のSEOとGEO（Generative Engine Optimization）の両方の効果を一つのダッシュボードで確認できます。
</Info>

### 何のために使うか

- **Google検索順位の継続監視**: 重要キーワードの順位変動を長期間追跡
- **AI Overviews順位の把握**: AIによる回答生成時の引用順位を計測
- **競合分析**: 自社と競合の順位を比較し、戦略立案に活用
- **施策効果の測定**: SEO/GEO施策後の順位変動を定量的に評価
- **自動レポート作成**: スケジュール機能で毎日自動計測、CSV出力でレポート作成

## 出力指標（KPI）

計測を実行すると、以下の主要指標が表示されます。

### ダッシュボード統計

| 指標           | 説明                     | 活用方法       |
| ------------ | ---------------------- | ---------- |
| **登録キーワード数** | プロジェクトに登録されているキーワードの総数 | 監視対象の規模を把握 |
| **本日計測済み**   | 当日に計測完了したキーワード数        | 計測の進捗確認    |
| **総計測データ**   | 蓄積された順位データの総レコード数      | データ蓄積量の確認  |

### キーワード別詳細データ

各キーワードごとに以下の詳細データが確認できます：

| 項目    | 説明                   |
| ----- | -------------------- |
| キーワード | 登録した検索キーワード          |
| 現在順位  | 最新のGoogle検索順位        |
| 前回順位  | 前回計測時の順位             |
| 順位変動  | 前回比での順位変動（↑上昇 / ↓下降） |
| AIO順位 | AI Overviews内での引用順位  |
| 計測日時  | 最終計測日時（日本時間）         |
| 対象URL | 順位取得されたページURL        |

## プロジェクト設定

### 基本設定

| 設定項目        | 説明           | 選択肢                           |
| ----------- | ------------ | ----------------------------- |
| **プロジェクト名** | 識別しやすい名前     | 任意のテキスト                       |
| **対象ドメイン**  | 順位計測対象のドメイン  | 例: `example.com`              |
| **対象URL**   | 特定ページを指定する場合 | 例: `https://example.com/page` |
| **検索エンジン**  | 計測対象の検索エンジン  | Google / Bing / Yahoo         |
| **デバイス種別**  | 計測時のデバイス     | Desktop / Mobile              |
| **検索深度**    | 順位を取得する範囲    | 50位 / 100位                    |
| **対象地域**    | 検索地域の設定      | Japan / United States 等       |
| **対象言語**    | 検索言語の設定      | Japanese / English 等          |

<Note>
  検索深度「50位」は1キーワード1ポイント、「100位」は1キーワード2ポイントを消費します。
</Note>

## スケジュール機能

### スケジュールタイプ

<Tabs>
  <Tab title="手動計測のみ">
    スケジュールを無効化し、手動でのみ計測を実行します。

    - 必要なタイミングでのみ計測したい場合に最適
    - ポイント消費を細かくコントロール可能
  </Tab>
  <Tab title="毎日自動計測">
    毎日指定時刻に自動で順位を計測します。

    - 順位変動を漏れなく追跡
    - 設定した日本時間に自動実行
    - 安定した長期データ蓄積に最適
  </Tab>
  <Tab title="間隔指定計測">
    指定した日数間隔で自動計測します。

    - 2〜30日の間隔で設定可能
    - ポイント消費を抑えつつ定期監視
    - 週次・隔週監視に最適
  </Tab>
</Tabs>

### スケジュール設定項目

| 項目              | 説明           | 設定値                |
| --------------- | ------------ | ------------------ |
| **スケジュール有効/無効** | 自動計測のON/OFF  | トグルスイッチ            |
| **スケジュールタイプ**   | 計測頻度の種類      | 手動 / 毎日 / 間隔指定     |
| **間隔日数**        | 計測間隔（間隔指定時）  | 2〜30日              |
| **実行時刻**        | 計測実行時刻（日本時間） | 00:00〜23:30（30分刻み） |
| **テストモード**      | テスト用通知送信     | ON/OFF             |

<Warning>
  スケジュール実行時も通常と同じポイントが消費されます。キーワード数と検索深度に応じたポイント残高を確保してください。
</Warning>

## 利用手順

### Step 1: プロジェクトを作成

<Steps>
  <Step title="ダッシュボードにアクセス">
    サイドバーから「SEO Hub」→「順位チェック」を選択
  </Step>
  <Step title="新規プロジェクト作成">
    「+ 新規プロジェクト」ボタンをクリック
  </Step>
  <Step title="基本設定を入力">
    - **プロジェクト名**: 識別しやすい名前を入力
    - **対象ドメイン**: 順位計測するドメインを入力（例: `example.com`）
    - **検索エンジン**: Google / Bing / Yahoo から選択
    - **デバイス種別**: Desktop / Mobile を選択
    - **検索深度**: 50位（1pt/KW）または 100位（2pt/KW）を選択
  </Step>
  <Step title="キーワードを登録">
    計測したいキーワードを1行1キーワードで入力

    ```
    SEO対策 方法
    コンテンツマーケティング
    検索順位 上げ方
    ```

    <Tip>
      キーワードは後から追加・削除できます。最初は主要キーワードのみ登録することをおすすめします。
    </Tip>
  </Step>
  <Step title="スケジュール設定（任意）">
    自動計測を有効にする場合：

    - スケジュール設定をONに切り替え
    - 計測タイプ（毎日 / 間隔指定）を選択
    - 実行時刻を設定（日本時間）
  </Step>
  <Step title="保存">
    設定を確認し「保存」をクリック
  </Step>
</Steps>

### Step 2: 順位計測を実行

<Steps>
  <Step title="プロジェクトを選択">
    プロジェクトセレクターから計測対象のプロジェクトを選択
  </Step>
  <Step title="計測実行">
    「順位計測を実行」ボタンをクリック

    <Warning>
      計測には以下のポイントが消費されます：

      - **50位計測**: 1キーワード = 1ポイント
      - **100位計測**: 1キーワード = 2ポイント
    </Warning>
  </Step>
  <Step title="進行状況を確認">
    計測中は進行状況がリアルタイムで表示されます

    - 完了したキーワード数 / 総キーワード数
    - Webhookによる自動更新
  </Step>
  <Step title="結果を確認">
    計測完了後、自動的にデータテーブルとグラフが更新されます
  </Step>
</Steps>

### Step 3: 結果を確認

<Tabs>
  <Tab title="データテーブル">
    - **キーワード一覧**: 全キーワードの最新順位を一覧表示
    - **ソート機能**: 順位・変動幅・計測日時でソート可能
    - **フィルター**: 順位範囲でフィルタリング
    - **行クリック**: キーワードをクリックしてグラフに表示
  </Tab>
  <Tab title="順位変動グラフ">
    - **表示期間**: 1ヶ月 / 3ヶ月 / 6ヶ月 / 12ヶ月から選択
    - **Y軸範囲**: 10位 / 25位 / 50位 / 75位 / 100位で調整
    - **SEO順位**: 実線で表示
    - **AIO順位**: 点線（青色）で表示
    - **圏外表示**: 検索深度+1位として表示
  </Tab>
  <Tab title="プロジェクト設定">
    プロジェクトの設定内容を確認・編集：

    - 基本設定の変更
    - キーワードの追加・削除
    - スケジュール設定の変更
  </Tab>
</Tabs>

## 重複計測チェック

同日に同じキーワードを再度計測しようとすると、警告モーダルが表示されます。

<Warning>
  当日計測済みのキーワードを再計測すると、追加でポイントが消費されます。本当に再計測が必要か確認してから実行してください。
</Warning>

### 警告モーダルの選択肢

| 選択肢         | 説明                   |
| ----------- | -------------------- |
| **未計測のみ実行** | 当日未計測のキーワードのみを計測（推奨） |
| **全て再計測**   | 計測済みを含む全キーワードを再計測    |
| **キャンセル**   | 計測を中止                |

## CSV出力

計測結果はCSVファイルとしてダウンロード可能です。

### 出力形式

<Tabs>
  <Tab title="基本出力">
    最新の順位データのみを出力：

    ```csv
    キーワード,現在順位,前回順位,変動,AIO順位,計測日時,対象URL
    SEO対策 方法,5,7,+2,2,2025-01-15 10:00,https://example.com/seo
    コンテンツマーケティング,12,12,0,N/A,2025-01-15 10:00,https://example.com/content
    ```
  </Tab>
  <Tab title="時系列データ付き">
    過去の順位履歴を含む詳細出力：

    ```csv
    # SEO順位計測レポート
    # プロジェクト: [プロジェクト名]
    # 出力日時: [日時]
    
    ## 最新順位
    キーワード,順位,AIO順位,計測日時
    
    ## 順位履歴（過去3ヶ月）
    日付,SEO対策 方法,コンテンツマーケティング,...
    2025-01-15,5,12,...
    2025-01-14,6,11,...
    ```
  </Tab>
</Tabs>

### 出力方法

1. プロジェクトを選択し、順位データを表示
2. 「CSV出力」ドロップダウンをクリック
3. 「基本情報のみ」または「時系列データ付き」を選択
4. ファイルが自動的にダウンロードされます

<Tip>
  CSVファイルはUTF-8（BOM付き）形式で出力されるため、Excelで直接開いても文字化けしません。
</Tip>

## サンプルデータ表示

実際にポイントを消費せずに機能を試すことができます。

### サンプルモードの使い方

1. ダッシュボード上部の「サンプル分析結果を見る」ボタンをクリック
2. デモ用のプロジェクト・キーワード・順位データが表示されます
3. 「サンプルモードを終了」ボタンで通常表示に戻ります

### サンプルデータの内容

| 項目       | 内容               |
| -------- | ---------------- |
| プロジェクト   | クレジットカード比較サイト    |
| キーワード数   | 5キーワード           |
| 順位履歴     | 90日分のリアルなトレンドデータ |
| トレンドパターン | 上昇・下降・安定の3パターン   |

<Note>
  サンプルモードではCSV出力も可能です。出力されるのはデモデータです。
</Note>

## よくある質問

<AccordionGroup>
  <Accordion title="順位が「圏外」と表示されます">
    検索深度（50位または100位）の範囲内に順位が見つからない場合、「圏外」と表示されます。

    - 100位計測に変更することで、より広い範囲で順位を取得できます
    - ただし、100位計測は2ポイント/キーワードが消費されます
  </Accordion>
  <Accordion title="AIO順位が表示されないキーワードがあります">
    AI Overviews（AIO）は全ての検索クエリに表示されるわけではありません。

    - AIが回答を生成しないクエリではAIO順位は取得できません
    - AIO順位が「N/A」または空欄の場合、そのクエリでAI Overviewsが表示されなかったことを意味します
  </Accordion>
  <Accordion title="スケジュール計測が実行されません">
    以下を確認してください：

    - スケジュール設定が「有効」になっているか
    - ポイント残高が十分にあるか
    - 実行時刻が正しく設定されているか（日本時間）

    設定に問題がない場合は、プロジェクト設定を再保存してお試しください。
  </Accordion>
  <Accordion title="計測にどのくらい時間がかかりますか？">
    キーワード数によりますが、目安は以下の通りです：

    - 10キーワード: 約30秒〜1分
    - 50キーワード: 約2〜3分
    - 100キーワード: 約5〜10分

    計測中は進行状況がリアルタイムで表示されます。
  </Accordion>
  <Accordion title="順位データはいつまで保存されますか？">
    順位データは無期限で保存されます。過去のデータを削除したい場合は、プロジェクト自体を削除する必要があります。

    <Warning>
      プロジェクトを削除すると、全ての順位履歴が削除され、復元できません。
    </Warning>
  </Accordion>
  <Accordion title="同じキーワードを複数プロジェクトで登録できますか？">
    はい、可能です。異なるドメインや設定で同じキーワードを追跡したい場合に有効です。

    - 例: 自社サイトと競合サイトで同じキーワードを追跡
    - 例: デスクトップとモバイルで同じキーワードを追跡
  </Accordion>
  <Accordion title="当日計測済みのキーワードを再計測するとどうなりますか？">
    再計測するとポイントが追加で消費されます。警告モーダルが表示されるので、「未計測のみ実行」を選択することで不要な消費を避けられます。
  </Accordion>
  <Accordion title="キーワードの追加・削除はできますか？">
    はい、プロジェクト編集画面からいつでもキーワードの追加・削除が可能です。

    - キーワード追加: 編集画面でキーワードを入力して保存
    - キーワード削除: キーワード横の削除ボタンをクリック
  </Accordion>
</AccordionGroup>

## 技術仕様

### 計測システム

- **データソース**: DataForSEO API
- **計測方式**: Webhook非同期処理
- **リアルタイム更新**: Supabase postgres_changes
- **計測頻度制限**: 同一キーワードは1日1回を推奨

### データ保存

- **保存期間**: 無期限
- **保存形式**: PostgreSQL（Supabase）
- **タイムゾーン**: 日本時間（JST）で統一

### スケジュール実行

- **実行エンジン**: Supabase Edge Functions + pg_cron
- **実行時刻精度**: 設定時刻から±5分以内
- **失敗時リトライ**: 自動リトライ（最大3回）
