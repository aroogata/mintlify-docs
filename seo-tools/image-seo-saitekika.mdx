## 概要

画像SEO最適化は、AIの画像認識技術を活用して、アップロードした画像を詳細に分析し、SEO効果の高いファイル名・ALTテキストを自動生成するツールです。

<Info>
  画像をアップロードするだけで、検索エンジン最適化とアクセシビリティの両方に効果的なSEO要素を瞬時に生成します。
</Info>

### 主な用途

- **画像検索対策**: 検索エンジンが理解しやすいファイル名・ALTテキストで画像検索からの流入増加
- **アクセシビリティ向上**: スクリーンリーダー対応の適切なALTテキスト生成
- **コンテンツSEO強化**: ページ内容と一貫性のある画像要素でSEO評価向上
- **作業効率化**: 大量の画像に対するSEO要素作成を自動化

## 料金

画像SEO最適化は、1回の分析につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| 画像SEO最適化（1画像） | 5pt |

<Note>
  1回の分析で、ファイル名・ALTテキスト・説明文・HTMLサンプルがすべて生成されます。追加ポイントは不要です。
</Note>

## 対応形式

| 項目 | 仕様 |
|------|------|
| 対応形式 | JPG、PNG、GIF、WebP |
| 最大ファイルサイズ | 10MB |
| 推奨 | 高画質で被写体が明確な画像 |

<Warning>
  ファイルサイズが10MBを超える画像はアップロードできません。事前に画像を圧縮してください。
</Warning>

## 生成されるSEO要素

### ファイル名

| 項目 | 内容 |
|------|------|
| 形式 | 小文字、単語間ハイフン区切り |
| 長さ | 3〜5語程度 |
| 特徴 | 画像内容を反映、関連キーワード含む |
| 拡張子 | 適切な画像拡張子（.jpg、.png、.webp等） |

**良いファイル名の例:**
- `tokyo-skyline-sunset-view.jpg`
- `organic-vegetable-salad-recipe.png`
- `business-team-meeting-office.webp`

### ALTテキスト

| 項目 | 内容 |
|------|------|
| 長さ | 125文字以内（推奨） |
| 内容 | 画像の具体的な説明 |
| 特徴 | 自然なキーワード含有、アクセシビリティ対応 |

**良いALTテキストの例:**
- 「東京タワーと六本木ヒルズが見える夕暮れの東京スカイライン」
- 「新鮮なトマトとレタスを使ったオーガニック野菜サラダ」
- 「オフィスの会議室でプレゼンテーションを行うビジネスチーム」

### 説明文

AIが認識した画像の内容と、SEO最適化のポイントを解説します。

### HTMLサンプル

生成されたファイル名とALTテキストを使った、そのまま使えるHTMLコードを提供します。

```html
<img src="tokyo-skyline-sunset-view.jpg" alt="東京タワーと六本木ヒルズが見える夕暮れの東京スカイライン" />
```

## 利用手順

<Steps>
  <Step title="画像をアップロード">
    SEO最適化したい画像をドラッグ&ドロップまたはクリックしてアップロードします。
    対応形式：JPG、PNG、GIF、WebP（最大10MB）
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて以下を入力します：
    - **ターゲットキーワード**: 「マーケティング」「料理」「旅行」など
    - **ウェブサイトコンテキスト**: 「料理ブログ」「ECサイト」「旅行ガイド」など
  </Step>
  <Step title="SEO最適化を生成">
    「SEO最適化を生成」ボタンをクリックして分析を実行します。
    <Note>
      1回の分析につき5ポイントが消費されます。
    </Note>
  </Step>
  <Step title="結果の確認とコピー">
    生成された以下の要素を確認し、コピーボタンで簡単にコピーできます：
    - ファイル名
    - ALTテキスト
    - 説明文
    - HTMLサンプル
  </Step>
  <Step title="サイトに実装">
    コピーしたファイル名でファイルをリネームし、HTMLサンプルをサイトに貼り付けて実装完了です。
  </Step>
</Steps>

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はコピーして保存してください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **履歴確認**: 「最近の分析結果を見る」ボタンから確認可能

## よくある質問

<AccordionGroup>
  <Accordion title="どのような画像に効果的ですか？">
    以下のような画像で特に効果的です：
    - 製品写真（ECサイト）
    - 料理写真（レシピサイト、飲食店）
    - 観光地写真（旅行サイト）
    - ビジネスシーン写真（コーポレートサイト）
    - インフォグラフィック（ブログ記事）

    被写体が明確で、コンテンツとの関連性が高い画像ほど、効果的なSEO要素が生成されます。
  </Accordion>
  <Accordion title="生成結果はそのまま使用できますか？">
    はい、生成されたファイル名・ALTテキスト・HTMLサンプルはそのまま使用できます。
    ただし、以下の点を確認することをおすすめします：
    - 画像の内容と一致しているか
    - ページのコンテキストに適切か
    - 過度なキーワード詰め込みになっていないか

    必要に応じて手動で微調整してください。
  </Accordion>
  <Accordion title="装飾目的の画像はどうすればいいですか？">
    装飾目的の画像（背景画像、区切り線など）の場合、AIは空のALTテキスト（`alt=""`）を提案することがあります。
    これはアクセシビリティのベストプラクティスに沿った対応です。
  </Accordion>
  <Accordion title="日本語のALTテキストは生成できますか？">
    はい、日本語サイト向けに日本語のALTテキストが生成されます。
    ファイル名は英語の小文字・ハイフン区切りで生成されます（SEOのベストプラクティス）。
  </Accordion>
  <Accordion title="複数の画像を一度に処理できますか？">
    現在は1画像ずつの処理となります。
    複数の画像を処理する場合は、それぞれ個別にアップロードして分析してください。
  </Accordion>
  <Accordion title="分析結果はどこで確認できますか？">
    分析結果は「最近の分析結果を見る」ボタンから過去12時間以内の結果を確認できます。
    保持期間を過ぎた結果は自動的に削除されます。
  </Accordion>
</AccordionGroup>
