## 概要

AIブログ記事生成は、**ターゲットキーワードを入力するだけで、競合上位サイトを分析し、SEO・AI検索（AIO）に最適化されたブログ記事を自動生成**するツールです。最新情報のリサーチ、競合分析、記事の執筆、画像生成、品質チェックまでを一連の流れで行えます。

<Info>
  キーワード入力から、最新情報のリサーチ → 競合分析 → 記事設定 → 本文・画像の生成 → 品質チェックまでをガイドに沿って進められます。完成した記事はMarkdown形式でコピー・保存できます。
</Info>

### この機能でできること

- **SEO記事の量産**: キーワードから構造化された記事を高速に生成
- **競合に基づく設計**: 上位サイトの見出し・文字数・キーワードを分析して記事構成に反映
- **AI検索（AIO）対応**: 結論ファースト構成・FAQ・構造化データなどAIに引用されやすい記事に
- **画像付き記事**: アイキャッチ・本文中の図解画像を自動生成
- **トーンの作り分け**: ペルソナ・文体を選んでブランドに合った文章に

## 生成フロー

<Steps>
  <Step title="キーワード入力">
    記事のテーマとなるキーワードと言語（日本語／英語）を入力します。
  </Step>
  <Step title="リサーチ">
    キーワードに関する最新情報を引用元付きでリサーチします。
  </Step>
  <Step title="検索結果・競合分析">
    上位サイトを取得し、見出し構成・文字数・キーワードの使われ方などを分析します。
  </Step>
  <Step title="記事設定">
    記事タイプ・文字数・トーン・ペルソナ・AIモデル・画像オプションなどを設定します。
  </Step>
  <Step title="記事生成">
    設定に基づいてAIが記事と画像を生成します（数分かかる場合があります）。
  </Step>
  <Step title="完成・保存">
    生成された記事を確認し、品質チェック・コピー・保存を行います。
  </Step>
</Steps>

## 料金

ブログ記事生成は、**記事本体250pt**に加え、**画像を生成する場合は1枚につき40pt**を消費します。

| 項目 | 消費ポイント |
| --- | --- |
| 記事生成（本体・リサーチ・競合分析・品質チェックを含む） | **250pt** |
| 画像生成（アイキャッチ・本文画像） | **40pt / 枚** |

<Note>
  総消費ポイント＝ 250pt ＋（画像枚数 × 40pt）です。

  - 例：記事のみ = **250pt**
  - 例：記事 ＋ アイキャッチ1枚 ＋ 本文画像2枚 = 250 \+（3 × 40）= **370pt**

  リサーチの途中で失敗した場合は、消費したポイントが自動的に返金されます。
</Note>

## AIモデル

記事生成に使うAIモデルを選択できます。用途に応じて高速モデルから高品質モデルまで選べます。

| モデル | 特徴 |
| --- | --- |
| **GPT-5.4** | 最新GPT。多言語対応が強化され、SEO構造化記事の生成に強い |
| **Claude Sonnet 4.6** | 日本語の自然な文章力に定評。構造化された記事生成が得意 |
| **Claude Opus 4.6** | 最高品質の文章生成。長文でも一貫性を維持 |
| **Claude Haiku 4.5** | 高速・低コスト。ドラフト作成や大量生成に最適 |
| **Gemini 3.1 Pro** | 長文記事の品質が高く、大規模なコンテキストに対応 |

## 記事設定

| 項目 | 内容 |
| --- | --- |
| **記事タイプ** | SEO最適化・ハウツー・比較・製品レビュー・徹底解説・用語集など多数から選択 |
| **記事構成** | 結論ファースト（デフォルト）・ストーリー型・問題解決型・リスト型・Q&A型など |
| **文字数** | 5,000字 / 10,000字 / 10,000字以上 |
| **トーン（文体）** | 丁寧 / カジュアル / シンプル / プロフェッショナル / ストーリー調 |
| **ターゲット読者・年齢** | 想定読者と年代を指定（任意） |
| **ペルソナ** | プリセットペルソナから選択、または独自のカスタムペルソナを作成 |
| **コンテンツオプション** | 比較表・表・FAQセクションの自動挿入 |
| **画像オプション** | アイキャッチの生成有無、本文画像の枚数（0〜5枚）、画像スタイル |

### ペルソナ

文章のトーンを決めるペルソナを選べます。年代・属性・職業別のプリセットペルソナが多数用意されており、独自の**カスタムペルソナ**を作成したり、よく使うペルソナを**お気に入り**に登録したりできます。

### 画像生成

記事に合わせた画像（アイキャッチ・本文中の図解）を自動生成できます。スタイルは **シンプル・キュート・プロフェッショナル・詳細・フラット・水彩・インフォグラフィック・写真風** から選べます。画像1枚につき40ptを消費します。

## 競合分析

入力キーワードの上位サイトを取得し、各サイトの見出し構成・文字数・キーワードの使われ方・コンテンツ構造を分析します。検索意図（情報収集／比較検討／購入／特定サイト訪問）も自動判定し、記事の方向性に反映します。

## 品質チェック

生成した記事は、**構造・コンテンツ・読みやすさ・完成度**の4観点（各25点・合計100点）で評価できます。70点以上が合格の目安です。スコアと改善点を確認して、記事の仕上げに活用できます。

## 出力

生成される記事には、以下が含まれます。

- SEO最適化されたH1タイトル
- メタディスクリプション
- 導入文・目次
- H2〜H4の構造化本文
- まとめ
- FAQセクション
- 参考文献（引用元）
- SEOスコア・キーワード密度・読了時間などの指標

記事は**Markdown形式**で表示され、コピー・保存できます。

## 保存

<Info>
  完成した記事を保存すると、保存記事一覧から**いつでも再表示・コピー・削除**できます。保存した記事は自動削除されません。
</Info>

- **保存した記事**: アカウントに永続的に保管されます
- **生成途中の状態**: ブラウザに一時保持され、ページを再読み込みしても作業を継続できます（保存するまでは確定されません）

<Warning>
  生成途中の内容はブラウザの一時保存です。完成した記事は「保存」して永続化することをおすすめします。
</Warning>
