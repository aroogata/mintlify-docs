## 概要

AIブログ記事生成は、ターゲットキーワードに基づいて競合サイトを分析し、SEO・AIO（AI Overview）に最適化されたブログ記事を自動生成するツールです。

<Info>
  キーワードを入力するだけで、検索上位サイトの分析から記事生成まで、6つのステップで高品質なブログ記事を作成できます。
</Info>

### 主な用途

- **SEOコンテンツ作成**: 検索上位表示を狙った記事を効率的に作成
- **AIO対策**: AI Overview（生成AI検索結果）での参照を意識した記事構成
- **競合調査**: 上位表示サイトの構成・内容を分析してベンチマーク
- **コンテンツ戦略**: 効果的な記事構成のヒントを取得
- **執筆効率化**: 下書き・構成案作成の大幅な時間短縮

## 料金

AIブログ記事生成は、1回の記事生成につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| 記事生成（1記事） | 250pt |

<Note>
  競合分析・品質チェックを含めた全工程で250ポイントです。生成途中でキャンセルした場合、ポイントは消費されません。
</Note>

## 6ステップの記事生成フロー

AIブログ記事生成は、以下の6つのステップで進行します。各ステップで必要な情報を入力・確認しながら、最終的に高品質な記事を生成します。

### ステップ概要

| ステップ | 名称 | 内容 |
|---------|------|------|
| 1 | キーワード入力 | ターゲットキーワードを入力 |
| 2 | 検索結果取得 | 検索結果から上位サイトを取得 |
| 3 | 競合分析 | 上位サイトの内容を詳細分析 |
| 4 | 記事設定 | 記事タイプ・文字数・トーンなどを設定 |
| 5 | 記事生成 | AIが記事を自動生成 |
| 6 | 記事完成 | 生成結果の確認・保存 |

## ステップ1: キーワード入力

<Steps>
  <Step title="ターゲットキーワードの入力">
    記事のメインテーマとなるキーワードを入力します。

    **入力例:**
    - 「SEO対策 初心者」
    - 「プログラミング 独学 方法」
    - 「ダイエット 食事制限なし」

    <Tip>
      より具体的なロングテールキーワードを入力すると、競合が少なく上位表示しやすい記事を作成できます。
    </Tip>
  </Step>
  <Step title="検索対象地域の確認">
    日本のGoogle検索結果を対象に分析を行います。
  </Step>
</Steps>

### キーワード入力のポイント

| 推奨 | 非推奨 |
|------|--------|
| 具体的なキーワード（2〜4語） | 単語1つだけ |
| ユーザーの検索意図が明確 | 曖昧・広すぎるキーワード |
| 実際に検索されるフレーズ | 専門用語の羅列 |

---

## ステップ2: 検索結果取得

<Steps>
  <Step title="検索結果の取得">
    入力したキーワードで実際の検索結果を取得します。この処理は自動で実行されます。
  </Step>
  <Step title="上位サイトの一覧表示">
    検索結果から上位10サイトの情報が表示されます。

    **表示される情報:**
    - サイトタイトル
    - URL
    - メタディスクリプション（概要文）
    - 検索順位
  </Step>
  <Step title="検索意図の判定">
    キーワードの検索意図が自動判定されます。

    | 検索意図 | 説明 | 例 |
    |---------|------|-----|
    | Informational | 情報を得たい | 「〜とは」「〜方法」 |
    | Commercial | 購入検討中 | 「〜 おすすめ」「〜 比較」 |
    | Transactional | 購入・申込したい | 「〜 購入」「〜 申込」 |
    | Navigational | 特定サイトへ行きたい | ブランド名・サービス名 |
  </Step>
</Steps>

<Info>
  検索意図は記事生成時に考慮され、ユーザーのニーズに合った記事構成が提案されます。
</Info>

---

## ステップ3: 競合分析

<Steps>
  <Step title="分析対象サイトの選択">
    検索結果から分析したいサイト（最大5サイト）を選択します。

    <Tip>
      上位3〜5サイトを選択することで、より精度の高い分析結果が得られます。
    </Tip>
  </Step>
  <Step title="競合サイトの詳細分析">
    選択したサイトの内容が自動分析されます。

    **分析項目:**
    - 見出し構成（H1〜H4）
    - 総文字数
    - キーワード出現頻度
    - コンテンツ構造
    - 主要トピック
  </Step>
  <Step title="分析結果の確認">
    以下の分析インサイトが表示されます。

    | 項目 | 内容 |
    |------|------|
    | 共通トピック | 複数サイトで取り上げられているテーマ |
    | 平均文字数 | 上位サイトの平均的な記事ボリューム |
    | 推奨構成 | 効果的な見出し構成の提案 |
    | キーワード | 重要キーワードと出現頻度 |
  </Step>
</Steps>

## ステップ4: 記事設定

記事生成前に、詳細な設定を行います。

### 記事タイプ

| タイプ | 説明 | 適したケース |
|--------|------|-------------|
| SEO最適化記事 | 検索上位表示を重視した構成 | 検索流入を狙う記事 |
| 汎用ブログ記事 | バランスの取れた一般的な構成 | 幅広い用途 |
| 製品レビュー記事 | 商品・サービスのレビュー向け | アフィリエイト、比較記事 |
| ニッチトピック記事 | 専門的・マニアックなテーマ向け | 専門ブログ、技術記事 |

### 文字数設定

| 設定 | 目安文字数 | 適したケース |
|------|-----------|-------------|
| 5,000文字 | 4,000〜6,000文字 | 基本的な解説記事 |
| 10,000文字 | 8,000〜12,000文字 | 詳細な解説・まとめ記事 |
| 10,000文字以上 | 10,000文字〜 | 包括的なガイド記事 |

<Tip>
  競合分析の「平均文字数」を参考に、上位サイトと同等以上のボリュームを目指すことをおすすめします。
</Tip>

### トーン（文体）設定

| トーン | 特徴 | 適したケース |
|--------|------|-------------|
| フレンドリー | 親しみやすく読みやすい | 一般向けブログ |
| プロフェッショナル | 信頼感のある専門的な文体 | ビジネス、専門サイト |
| カジュアル | くだけた口語調 | 個人ブログ、エンタメ系 |
| エキスパート | 権威性のある専門家視点 | 技術ブログ、専門メディア |

### AIモデル選択

用途に応じて最適なAIモデルを選択できます。

| モデル | 特徴 |
|--------|------|
| Gemini 2.0 Flash | 高速・バランス型（推奨） |
| GPT-4o | 高品質・汎用性が高い |
| Claude 3.5 Sonnet | 論理的・構造化に強い |
| その他 | 特定用途向けモデル |

<Note>
  モデルによって生成される記事の特徴が異なります。初めての方は「Gemini 2.0 Flash」がおすすめです。
</Note>

### コンテンツオプション

| オプション | 説明 |
|-----------|------|
| 比較表を含める | 製品・サービスの比較表を自動生成 |
| 表・リストを多用 | 視覚的にわかりやすい構成 |
| FAQセクションを追加 | よくある質問と回答を自動生成 |

### ターゲット読者設定

記事のターゲット読者を選択することで、より適切な内容・表現で記事が生成されます。

**選択可能なターゲット:**
- 初心者・入門者
- 中級者
- 上級者・専門家
- ビジネスパーソン
- 学生
- 主婦・主夫
- シニア層
- その他（カスタム設定可能）

### SEO詳細設定

| 設定項目 | 説明 |
|---------|------|
| メインキーワード | 記事の主要キーワード（自動設定済み） |
| サブキーワード | 関連キーワード（最大5つ） |
| 検索意図 | 記事が応えるべきユーザーの意図 |

## ステップ5: 記事生成

<Steps>
  <Step title="生成開始">
    「記事を生成」ボタンをクリックすると、AIによる記事生成が開始されます。

    <Warning>
      生成中はページを離れないでください。生成が中断される場合があります。
    </Warning>
  </Step>
  <Step title="生成進捗の確認">
    生成中は進捗状況がリアルタイムで表示されます。

    **生成フェーズ:**
    1. 記事構成の作成
    2. 各セクションの執筆
    3. SEO要素の最適化
    4. 品質チェック
  </Step>
  <Step title="品質チェック">
    生成完了後、自動で品質チェックが実行されます。

    | 評価項目 | 配点 | 内容 |
    |---------|------|------|
    | 構造 | 25点 | 見出し構成、段落分け |
    | コンテンツ | 25点 | 内容の充実度、正確性 |
    | 読みやすさ | 25点 | 文章の流れ、表現 |
    | 完成度 | 25点 | 全体のまとまり |

    <Info>
      合計70点以上で品質チェック合格となります。
    </Info>
  </Step>
</Steps>

### 生成時間の目安

| 文字数設定 | 目安時間 |
|-----------|---------|
| 5,000文字 | 1〜2分 |
| 10,000文字 | 2〜4分 |
| 10,000文字以上 | 3〜5分 |

---

## ステップ6: 記事完成

<Steps>
  <Step title="生成結果の確認">
    生成された記事が表示されます。以下の情報も併せて確認できます。

    - 総文字数
    - 見出し構成
    - 品質スコア
    - 使用キーワード
  </Step>
  <Step title="記事のコピー">
    「コピー」ボタンで記事全文をクリップボードにコピーできます。

    **対応フォーマット:**
    - Markdown形式
    - プレーンテキスト
  </Step>
  <Step title="記事の保存">
    「保存」ボタンで生成した記事を保存できます。保存した記事は後から確認・編集が可能です。
  </Step>
  <Step title="再生成（必要に応じて）">
    結果に満足できない場合は、設定を変更して再生成することも可能です。

    <Note>
      再生成には追加で250ポイントが必要です。
    </Note>
  </Step>
</Steps>

## 生成される記事の構成

生成される記事には、以下の要素が含まれます。

### 基本構成

| 要素 | 内容 |
|------|------|
| タイトル | SEO最適化されたH1タイトル |
| 導入文 | 読者の関心を引くリード文 |
| 目次 | 見出し構成に基づく目次 |
| 本文 | H2〜H4で構造化された本文 |
| まとめ | 記事の要点をまとめた結論 |

### SEO要素

| 要素 | 説明 |
|------|------|
| メタディスクリプション | 検索結果に表示される概要文 |
| キーワード配置 | 適切な密度でキーワードを配置 |
| 内部リンク提案 | 関連記事へのリンク候補 |
| 見出し最適化 | 検索意図に沿った見出し構成 |

### AIO（AI Overview）対応要素

| 要素 | 説明 |
|------|------|
| 簡潔な回答 | 質問に対する直接的な回答 |
| 構造化データ | リスト・表形式での情報整理 |
| 信頼性要素 | 根拠・出典の明示 |
| ステップ形式 | 手順を明確にした説明 |

## 結果の保持

<Warning>
  分析結果・生成記事は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な記事は必ずコピーまたは保存してください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: 「保存」ボタンで永続保存、またはコピーして外部に保存

## よくある質問

<AccordionGroup>
  <Accordion title="生成された記事はそのまま公開できますか？">
    生成された記事は下書きとしてご利用ください。以下の点を確認・編集することをおすすめします：

    - 事実関係の正確性確認
    - 自社・サービスに合わせた内容の追加
    - オリジナルの画像・図表の追加
    - 最新情報への更新

    AIが生成した内容をベースに、人間がチェック・編集を加えることで、より高品質な記事になります。
  </Accordion>
  <Accordion title="生成に失敗した場合、ポイントは消費されますか？">
    生成処理が正常に完了しなかった場合、ポイントは消費されません。
    ただし、生成完了後の品質スコアが低い場合でも、ポイントは消費されます。
  </Accordion>
  <Accordion title="同じキーワードで複数回生成できますか？">
    はい、可能です。設定を変えて複数パターンの記事を生成し、最も良い結果を採用することもできます。
    ただし、生成ごとに250ポイントが必要です。
  </Accordion>
  <Accordion title="競合分析だけを行うことはできますか？">
    競合分析まで進めて、記事生成をせずに終了することは可能です。
    この場合、ポイントは消費されません。競合サイトの構成を参考にして、手動で記事を書くこともできます。
  </Accordion>
  <Accordion title="生成された記事の著作権はどうなりますか？">
    AI生成コンテンツの著作権は複雑な問題ですが、生成された記事はお客様のコンテンツとしてご利用いただけます。
    ただし、競合サイトの内容を直接コピーしているわけではなく、AIが参考にして新たに生成したオリジナルコンテンツです。
  </Accordion>
  <Accordion title="AIモデルはどれを選べばいいですか？">
    用途に応じて以下を参考にしてください：

    - **Gemini 2.0 Flash**: 速度と品質のバランスが良く、初心者におすすめ
    - **GPT-4o**: 高品質な文章、幅広いトピックに対応
    - **Claude 3.5 Sonnet**: 論理的な構成、技術系記事に強い

    迷った場合は「Gemini 2.0 Flash」をお試しください。
  </Accordion>
  <Accordion title="品質スコアが70点未満の場合どうなりますか？">
    品質スコアが70点未満でも記事は生成されますが、以下の改善提案が表示されます：

    - 構造の改善点
    - コンテンツの追加推奨箇所
    - 読みやすさの向上ポイント

    これらを参考に、手動で編集することをおすすめします。
  </Accordion>
  <Accordion title="生成時間が長い場合はどうすればいいですか？">
    以下の点をご確認ください：

    - 文字数設定が大きいほど時間がかかります
    - ネットワーク環境をご確認ください
    - 5分以上経過しても完了しない場合は、ページを更新して再試行してください
  </Accordion>
</AccordionGroup>
