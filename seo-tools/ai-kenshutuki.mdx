## 概要

AI検出器は、**Copyleaks Authenticity API**を活用して、テキストコンテンツがAIによって生成されたものか、人間によって書かれたものかを高精度で判定するツールです。

<Info>
  URLを入力するだけで、Webページのテキストを自動取得してAI検出分析を実行できます。
  テキストを直接入力して分析することも可能です。
</Info>

### 主な用途

- **コンテンツの品質管理**: 外注記事やライター納品物のAI使用率をチェック
- **SEO対策**: Google品質ガイドラインに準拠したオリジナルコンテンツの確保
- **学術・教育分野**: 論文やレポートのAI生成コンテンツ検出
- **メディア運営**: 投稿コンテンツの真正性確認

## 入力モード

<Tabs>
  <Tab title="URL入力モード">
    WebページのURLを入力して分析するモードです。

    **特徴:**
    - URLを入力するだけで自動的にページ内容を取得
    - Tavily APIを使用した高精度なテキスト抽出
    - ページタイトルと本文を自動認識

    **使い方:**
    1. 「URL入力」タブを選択
    2. 分析したいWebページのURLを入力
    3. 「分析開始」ボタンをクリック

    <Note>
      JavaScript動的生成コンテンツも取得可能ですが、ログインが必要なページは分析できません。
    </Note>
  </Tab>
  <Tab title="テキスト直接入力モード">
    テキストを直接入力して分析するモードです。

    **特徴:**
    - コピー&ペーストで簡単に分析
    - 非公開コンテンツの分析に最適
    - 100,000文字まで入力可能

    **使い方:**
    1. 「テキスト入力」タブを選択
    2. 分析したいテキストを入力または貼り付け
    3. 「分析開始」ボタンをクリック

    <Tip>
      下書き段階の記事や、Web未公開のコンテンツを分析する際に便利です。
    </Tip>
  </Tab>
</Tabs>

## 検出オプション

### 感度設定

検出の感度を3段階で調整できます。

| レベル | 設定値 | 説明 | 推奨用途 |
|--------|--------|------|----------|
| 低 | 1 | 厳格な判定。明確なAI生成パターンのみ検出 | 誤検知を最小限に抑えたい場合 |
| 中 | 2 | バランスの取れた判定（デフォルト） | 一般的な用途 |
| 高 | 3 | 敏感な判定。疑わしいパターンも検出 | 厳格なチェックが必要な場合 |

<Info>
  感度を高くするとAI検出率は上がりますが、誤検知（人間が書いた文章をAIと判定）のリスクも高まります。
</Info>

### 除外オプション

特定のコンテンツ要素を分析から除外することで、より正確な結果を得られます。

| オプション | 説明 |
|-----------|------|
| 引用（Quotes） | 引用符で囲まれたテキストを除外 |
| 参照（Citations） | 参照・引用元表記を除外 |
| 参考文献（References） | 参考文献リストを除外 |
| 目次（Table of Contents） | 目次部分を除外 |
| タイトル（Titles） | 見出し・タイトルを除外 |
| コード（Code） | プログラムコードブロックを除外 |

<Tip>
  技術記事やブログ記事では「コード」と「引用」を除外することで、本文のみを正確に分析できます。
</Tip>

### 言語設定

分析対象テキストの言語を指定できます。

| 言語 | 説明 |
|------|------|
| 日本語（ja） | 日本語テキストの分析に最適化 |
| 英語（en） | 英語テキストの分析に最適化（デフォルト） |

### 文単位の分析

各文ごとにAIスコアを算出し、詳細な分析結果を提供します。

| 分類 | AIスコア範囲 | 表示色 |
|------|-------------|--------|
| 人間作成（Human） | 0〜39% | 緑色 |
| 混合（Mixed） | 40〜59% | 黄色 |
| AI生成（AI） | 60〜100% | 赤色 |

### 詳細分析指標

| カテゴリ | 指標 | 説明 |
|---------|------|------|
| 文体分析 | 一貫性 | 文体の統一性スコア |
| 文体分析 | 自然な流れ | 文章の自然さスコア |
| 文体分析 | 語彙の多様性 | 使用語彙のバリエーション |
| コンテンツパターン | 反復パターン | 繰り返し表現の検出 |
| コンテンツパターン | テンプレート構造 | 定型的な構造の検出 |
| コンテンツパターン | 一般的表現 | AIが使いがちな表現の検出 |
| 言語特性 | 文の複雑さ | 文構造の複雑度 |
| 言語特性 | 接続表現の質 | 段落間の繋がりの自然さ |
| 言語特性 | 文脈の関連性 | 文脈の一貫性 |

## 利用手順

<Steps>
  <Step title="入力モードの選択">
    「URL入力」または「テキスト入力」タブを選択します。
  </Step>
  <Step title="コンテンツの入力">
    URL入力モードの場合はWebページのURLを、テキスト入力モードの場合は分析したいテキストを入力します。
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて、感度設定、除外オプション、言語設定を調整します。
  </Step>
  <Step title="分析開始">
    「分析開始」ボタンをクリックして分析を実行します。
    <Warning>
      分析中はページを離れないでください。分析が中断される場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、AI生成スコア、文単位の分析結果、詳細指標が表示されます。
  </Step>
  <Step title="レポート出力（任意）">
    必要に応じて「PDFレポート」ボタンから結果をダウンロードできます。
  </Step>
</Steps>

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はPDFレポートとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件
- **保存方法**: PDFレポートをダウンロード

## 料金

### ポイント消費計算

AI検出のポイント消費は、テキストの単語数に応じて動的に計算されます。

<Note>
  **計算式**: 英語250単語 = 1クレジット = 32ポイント
</Note>

| 単語数（英語換算） | クレジット | 消費ポイント |
|-------------------|-----------|-------------|
| 1〜250単語 | 1 | 32pt |
| 251〜500単語 | 2 | 64pt |
| 501〜750単語 | 3 | 96pt |
| 751〜1,000単語 | 4 | 128pt |
| 1,001〜2,000単語 | 5〜8 | 160〜256pt |
| 2,001〜5,000単語 | 9〜20 | 288〜640pt |

### ポイント消費タイミング

- **分析成功時**: 実際に使用したクレジット数に応じてポイント消費
- **分析失敗時**: ポイントは消費されません
- **サンプル表示時**: ポイントは消費されません

<Tip>
  分析前に推定ポイント消費量が表示されます。実際の消費量は分析完了後に確定します。
</Tip>

## よくある質問

<AccordionGroup>
  <Accordion title="AI検出の精度はどのくらいですか？">
    Copyleaks Authenticity APIは、ChatGPT、Claude、Geminiなど主要なAIモデルで生成されたテキストを高精度で検出できます。
    ただし、人間による大幅な編集が加えられたテキストは、検出が困難な場合があります。
  </Accordion>
  <Accordion title="日本語テキストも正確に分析できますか？">
    はい、日本語に対応しています。言語設定で「日本語」を選択することで、日本語テキストに最適化された分析が実行されます。
  </Accordion>
  <Accordion title="ログインが必要なページは分析できますか？">
    いいえ、ログインが必要なページは分析できません。
    その場合は、テキストをコピーして「テキスト入力モード」で分析してください。
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常、1,000単語程度のテキストで10〜30秒程度です。
    テキスト量が多い場合は、1分以上かかることがあります。
  </Accordion>
  <Accordion title="同じURLを再分析するとポイントは消費されますか？">
    はい、再分析ごとにポイントが消費されます。
    ただし、12時間以内であれば過去の分析結果を参照することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="感度設定はどれを選べばいいですか？">
    一般的な用途では「中」がおすすめです。
    - 誤検知を避けたい場合: 「低」
    - 厳格なチェックが必要な場合: 「高」
  </Accordion>
  <Accordion title="PDFレポートには何が含まれますか？">
    PDFレポートには、分析対象URL/テキスト、全体スコア、文単位の分析結果、詳細指標が含まれます。
    レポート提出や記録保存に活用できます。
  </Accordion>
  <Accordion title="APIエラーが発生した場合はどうなりますか？">
    APIエラーが発生した場合、ポイントは消費されません。
    エラーメッセージを確認し、入力内容を見直してから再度お試しください。
  </Accordion>
</AccordionGroup>
