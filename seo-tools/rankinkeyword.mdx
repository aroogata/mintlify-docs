## 概要

ランクインキーワード分析は、指定したドメインやURLがGoogle検索でランクインしているキーワードを網羅的に取得・分析するツールです。

<Info>
  ドメインを入力するだけで、そのサイトが上位表示されているキーワード一覧と、各キーワードの検索ボリューム・順位・競合度・推定トラフィックなどの詳細データを取得できます。
</Info>

### 主な用途

- **競合サイト分析**: 競合がどのキーワードで上位表示されているかを把握
- **自社サイト診断**: 自社サイトのSEO状況を客観的に分析
- **キーワード発掘**: 競合サイトから効果的なキーワードを発見
- **コンテンツ戦略**: ランクインキーワードを基にコンテンツ計画を立案
- **AI Overview対策**: AI Overviewでの参照状況を把握

## 料金体系

ランクインキーワード分析は従量課金制で、取得件数に応じてポイントを消費します。

### 通常分析

| 取得件数 | 消費ポイント |
|---------|-------------|
| 100件 | 10pt |
| 200件 | 20pt |
| 500件 | 50pt |
| 1,000件 | 100pt |

### 詳細分析

詳細分析では、追加でバックリンク情報や詳細なSERP情報を取得できます。

| 取得件数 | 消費ポイント |
|---------|-------------|
| 100件 | 15pt |
| 200件 | 30pt |
| 500件 | 75pt |
| 1,000件 | 150pt |

<Note>
  詳細分析では、通常分析の1.5倍のポイントを消費しますが、より詳細なバックリンク情報やSERP分析データが取得できます。
</Note>

## マッチタイプ

分析対象の範囲を指定できます。

| マッチタイプ | 説明 | 例 |
|------------|------|-----|
| ドメイン全体 | ドメイン配下の全ページを対象 | `example.com` → example.com/*, www.example.com/* 等すべて |
| URL配下 | 指定URLのプレフィックス配下を対象 | `example.com/blog` → example.com/blog/* のみ |
| 完全一致 | 指定したURLのみを対象 | `example.com/page` → そのページのみ |

<Tip>
  競合サイト全体を分析したい場合は「ドメイン全体」、特定のディレクトリ（ブログなど）のみ分析したい場合は「URL配下」を選択してください。
</Tip>

### キーワード指標

<CardGroup cols={2}>
  <Card title="検索順位" icon="arrow-up-1-9">

  <Card title="検索ボリューム" icon="magnifying-glass">
    月間平均検索回数
  </Card>
  <Card title="キーワード難易度" icon="gauge">
    上位表示の難易度（0〜100）
  </Card>
  <Card title="競合度" icon="users">
    Google Ads広告の競争度（0.0〜1.0）
  </Card>

    Google Adsでの推定クリック単価

### 順位変動指標

| 指標 | 説明 |
|------|------|
| previous_position | 前回計測時の順位 |
| position_change | 順位の変動幅（+/-） |
| rank_trend | 順位のトレンド（上昇/下降/維持） |

### AI Overview指標

AI Overviewでの参照状況を確認できます。

| 指標 | 説明 |
|------|------|
| ai_overview_mentions | AI Overviewでの参照回数 |
| ai_overview_presence | AI Overviewへの掲載有無 |
| ai_overview_position | AI Overview内での表示位置 |

### ドメイン指標

分析対象ドメイン全体の指標を表示します。

| 指標 | 説明 |
|------|------|
| domain_rank | ドメインの総合評価スコア |
| total_backlinks | 被リンク総数 |
| referring_domains | 参照元ドメイン数 |
| organic_keywords | ランクインキーワード総数 |
| organic_traffic | 推定オーガニックトラフィック |

### SERP特徴

各キーワードの検索結果ページに表示される要素を確認できます。

| 要素 | 説明 |
|------|------|
| featured_snippet | 強調スニペット（0位表示） |
| people_also_ask | 「他のユーザーも行った質問」 |
| video | 動画結果 |
| image_pack | 画像パック |
| local_pack | ローカルパック（地図表示） |
| knowledge_panel | ナレッジパネル |
| sitelinks | サイトリンク |
| shopping_results | ショッピング結果 |

## 利用手順

<Steps>
  <Step title="ドメイン/URLの入力">
    分析したいドメインまたはURLを入力します。
    例: `example.com`、`example.com/blog/`
  </Step>
  <Step title="マッチタイプの選択">
    分析範囲を「ドメイン全体」「URL配下」「完全一致」から選択します。
  </Step>
  <Step title="取得件数の選択">
    取得したいキーワード数を選択します（100件〜1,000件）。
    <Note>
      取得件数が多いほど消費ポイントも増加します。まずは100件で試すことをおすすめします。
    </Note>
  </Step>
  <Step title="詳細分析オプション（任意）">
    より詳細なバックリンク・SERP情報が必要な場合は「詳細分析」を有効にします。
  </Step>
  <Step title="分析開始">
    「分析開始」ボタンをクリックして分析を実行します。
    <Warning>
      分析中はページを離れないでください。分析が中断される場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、キーワード一覧が表示されます。各指標でソート・フィルタリングが可能です。
  </Step>
  <Step title="CSV出力（任意）">
    必要に応じて「CSV出力」ボタンから結果をダウンロードできます。
  </Step>
</Steps>

## フィルタリングとソート

### フィルタリング機能

取得したキーワードを以下の条件で絞り込みできます。

| フィルター | 説明 |
|-----------|------|
| キーワード検索 | 特定の文字列を含むキーワードを検索 |
| 検索順位 | 1位〜10位、11位〜50位、51位〜100位で絞り込み |
| 検索ボリューム | 最小〜最大の範囲で絞り込み |
| キーワード難易度 | Easy / Medium / Hard で絞り込み |
| AI Overview参照 | AI Overviewで参照されているキーワードのみ表示 |

### ソート機能

各列ヘッダーをクリックすることで、昇順・降順のソートが可能です。

- 検索順位順（デフォルト: 昇順）
- 検索ボリューム順
- 推定トラフィック順
- キーワード難易度順
- CPC順

## サンプル機能

ポイントを消費せずにランクインキーワード分析機能を体験できます。

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、サンプルドメインでの分析結果を確認できます。
</Info>

**サンプルデータ:**
- サンプルドメイン: `example-seo-company.co.jp`
- キーワード件数: 12件
- 含まれるデータ: 検索順位、検索ボリューム、推定トラフィック、競合度、AI Overview指標

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## よくある質問

<AccordionGroup>
  <Accordion title="どのくらいの期間のデータが取得できますか？">
    現在のランクイン状況を取得します。過去のデータは含まれませんが、順位変動（前回比較）は確認できます。
    定期的に分析を行うことで、順位の推移を追跡できます。
  </Accordion>
  <Accordion title="自社サイトと競合サイト、どちらを先に分析すべきですか？">
    まず自社サイトを分析して現状を把握し、その後競合サイトを分析することをおすすめします。
    競合との比較により、狙うべきキーワードや改善すべきポイントが明確になります。
  </Accordion>
  <Accordion title="キーワードが少ししか取得できません">
    以下の原因が考えられます：
    - 指定したドメイン/URLでランクインしているキーワードが少ない
    - マッチタイプが「完全一致」になっている（「ドメイン全体」に変更してください）
    - 新しいサイトでまだ十分にインデックスされていない
  </Accordion>
  <Accordion title="推定トラフィックはどのように計算されていますか？">
    検索ボリュームと検索順位に基づくCTR（クリック率）から算出されています。
    1位のCTRは約30%、10位は約2%程度として計算されます。
  </Accordion>
  <Accordion title="AI Overview参照とは何ですか？">
    GoogleのAI Overviewは、AIが生成する検索結果の要約です。
    AI Overview参照は、対象サイトがAI Overviewで情報源として引用されている回数を示します。
    AI SEO対策の重要な指標となります。
  </Accordion>
  <Accordion title="詳細分析と通常分析の違いは何ですか？">
    詳細分析では、以下の追加データが取得できます：
    - 被リンク数の詳細（dofollow/nofollow比率）
    - SERP特徴の詳細分析
    - 競合ページの詳細情報
    通常分析で十分な場合が多いですが、詳細なSEO分析が必要な場合は詳細分析をご利用ください。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。
    Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
</AccordionGroup>
