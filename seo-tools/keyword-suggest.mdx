## 概要

キーワードサジェストは、検索エンジンのオートコンプリート機能で提案されるキーワード候補を取得・分析するツールです。

<Info>
  シードキーワードを入力するだけで、関連するサジェストキーワードを最大1,000件まで取得し、検索ボリューム・競合度・CPC・検索意図などの詳細な分析データを提供します。
</Info>

### 主な用途

- **コンテンツ企画**: ユーザーが実際に検索しているキーワードを発見
- **SEO戦略**: 検索ボリュームと競合度を把握し、狙うべきキーワードを特定
- **キーワード拡張**: シードキーワードから派生する関連キーワードを網羅的に取得
- **市場調査**: ターゲット市場でのキーワードトレンドを分析

## 取得件数と料金

キーワードサジェストは従量課金制で、取得件数に応じてポイントを消費します。

| 取得件数   | 消費ポイント |
| ------ | ------ |
| 50件    | 5pt    |
| 100件   | 10pt   |
| 200件   | 20pt   |
| 500件   | 50pt   |
| 1,000件 | 100pt  |

<Note>
  取得件数はデフォルトで100件に設定されています。取得件数の変更は検索フォームで行えます。
</Note>

## 出力指標

分析結果では以下の指標が表示されます。

<CardGroup cols={2}>
  <Card title="検索ボリューム" icon="magnifying-glass-chart">
    月間平均検索回数。値が大きいほど需要が高いキーワード
  </Card>
  <Card title="キーワード難易度" icon="gauge">
    上位表示の難易度（0〜100）。値が高いほど競争が激しい
  </Card>
  <Card title="競合度" icon="users">
    Google Ads広告の競争度（0.0〜1.0）。値が高いほど広告競争が激しい
  </Card>
  <Card title="CPC（クリック単価）" icon="dollar-sign">
    Google Adsでの推定クリック単価（円）
  </Card>
</CardGroup>

### 競合度レベル

| レベル    | 値の範囲      | 説明             |
| ------ | --------- | -------------- |
| LOW    | 0.0〜0.33  | 競争が少なく、参入しやすい  |
| MEDIUM | 0.34〜0.66 | 中程度の競争         |
| HIGH   | 0.67〜1.0  | 競争が激しく、上位表示が困難 |

### 検索意図（Search Intent）

| 意図            | 説明          | 例                       |
| ------------- | ----------- | ----------------------- |
| Informational | 情報を得ることが目的  | 「SEO対策とは」「SEO対策 方法」     |
| Commercial    | 購入前の調査・比較   | 「SEO対策 会社 比較」「SEO対策 費用」 |
| Transactional | 購入・契約が目的    | 「SEO対策 依頼」「SEO対策 見積もり」  |
| Navigational  | 特定サイトへのアクセス | 「Google SEO ガイドライン」     |

### SERP要素

取得したキーワードの検索結果ページに表示される要素を確認できます。

| 要素               | 説明             |
| ---------------- | -------------- |
| organic          | 通常の検索結果        |
| featured_snippet | 強調スニペット（0位表示）  |
| people_also_ask  | 「他のユーザーも行った質問」 |
| video            | 動画結果           |
| ads_top          | 上部広告           |
| local_pack       | ローカルパック（地図表示）  |
| knowledge_panel  | ナレッジパネル        |

### バックリンク情報

上位表示に必要な被リンク状況の目安を確認できます。

| 指標                | 説明            |
| ----------------- | ------------- |
| backlinks         | 上位サイトの平均被リンク数 |
| dofollow          | フォロー属性のリンク数   |
| referring_domains | 参照元ドメイン数      |
| rank              | ドメインランク（平均値）  |
| main_domain_rank  | メインドメインランク    |

## 利用手順

<Steps>
  <Step title="シードキーワードの入力">
    分析したいキーワードを入力します。例: 「SEO対策」「Webマーケティング」
  </Step>
  <Step title="取得件数の選択">
    取得したいキーワード数を選択します（50件〜1,000件）。

    <Note>
      取得件数が多いほど消費ポイントも増加します。まずは100件で試すことをおすすめします。
    </Note>
  </Step>
  <Step title="分析開始">
    「分析開始」ボタンをクリックして分析を実行します。

    <Warning>
      分析中はページを離れないでください。分析が中断される場合があります。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、キーワード一覧が表示されます。各指標でソート・フィルタリングが可能です。
  </Step>
  <Step title="CSV出力（任意）">
    必要に応じて「CSV出力」ボタンから結果をダウンロードできます。
  </Step>
</Steps>

## フィルタリングとソート

### フィルタリング機能

取得したキーワードを以下の条件で絞り込みできます。

| フィルター   | 説明                                                              |
| ------- | --------------------------------------------------------------- |
| キーワード検索 | 特定の文字列を含むキーワードを検索                                               |
| 検索ボリューム | 最小〜最大の範囲で絞り込み                                                   |
| 競合度レベル  | LOW / MEDIUM / HIGH で絞り込み                                       |
| 検索意図    | Informational / Commercial / Transactional / Navigational で絞り込み |

### ソート機能

各列ヘッダーをクリックすることで、昇順・降順のソートが可能です。

- 検索ボリューム順（デフォルト: 降順）
- キーワード難易度順
- 競合度順
- CPC順

## CSV出力機能

分析結果をCSVファイルとして出力できます。

<Tabs>
  <Tab title="現在のページを出力">
    現在表示中のページのキーワードのみをCSV出力します。 フィルタリング・ソート結果がそのまま反映されます。
  </Tab>
  <Tab title="全データを出力">
    取得した全キーワードをCSV出力します。 大量データの場合はAPI呼び出しが複数回行われ、追加ポイントが消費される場合があります。
  </Tab>
</Tabs>

### CSV出力項目

| 項目                 | 説明                      |
| ------------------ | ----------------------- |
| keyword            | キーワード                   |
| search_volume      | 月間検索ボリューム               |
| keyword_difficulty | キーワード難易度                |
| competition        | 競合度（0.0〜1.0）            |
| competition_level  | 競合度レベル（LOW/MEDIUM/HIGH） |
| cpc                | クリック単価（円）               |
| search_intent      | 検索意図                    |

## サンプル機能

ポイントを消費せずにキーワードサジェスト機能を体験できます。

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、「SEO対策」をシードキーワードとしたサンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータ:**

- シードキーワード: 「SEO対策」
- サジェスト件数: 20件
- 含まれるデータ: 検索ボリューム、競合度、CPC、検索意図、SERP情報、バックリンク情報

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。 必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## URL連携機能

他のページからキーワードサジェストを直接起動できます。

```
/keyword-suggestions?keyword=SEO対策&auto=true&limit=100
```

| パラメータ   | 説明                        | 必須 |
| ------- | ------------------------- | --- |
| keyword | 分析するキーワード                 | ○  |
| auto    | true を指定すると自動実行           | ○  |
| limit   | 取得件数（50/100/200/500/1000） | ×  |

<Tip>
  キーワード競合分析ページから「キーワードサジェストで分析」をクリックすると、この連携機能が使用されます。
</Tip>

## よくある質問

<AccordionGroup>
  <Accordion title="同じキーワードを再分析するとポイントは消費されますか？">
    はい、再分析ごとにポイントが消費されます。 ただし、12時間以内であれば過去の分析履歴から結果を確認することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="取得件数を増やすとより多くのキーワードが取得できますか？">
    はい、取得件数を増やすことで、より多くの関連キーワードを取得できます。 ただし、シードキーワードによっては、サジェスト候補が少なく、指定した件数に満たない場合があります。
  </Accordion>
  <Accordion title="日本語以外のキーワードも分析できますか？">
    現在は日本語（日本国内での検索）に最適化されています。 英語や他の言語での分析は、結果の精度が保証されません。
  </Accordion>
  <Accordion title="検索ボリュームが0のキーワードはなぜ表示されますか？">
    検索ボリュームが非常に少ない（月間10回未満）キーワードは、0として表示されることがあります。 ロングテールキーワードとして有効な場合もありますので、削除せずに検討してください。
  </Accordion>
  <Accordion title="キーワード難易度はどのように計算されていますか？">
    キーワード難易度は、上位表示サイトの被リンク数、参照ドメイン数、ドメインランクなどから算出されています。 値が高いほど、上位表示に必要なSEO施策が多くなります。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。 Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
  <Accordion title="分析結果はどこで確認できますか？">
    分析結果は「最近の分析結果を見る」ボタンから過去12時間以内の結果を確認できます。 保持期間を過ぎた結果は自動的に削除されます。
  </Accordion>
  <Accordion title="類似キーワードを除外することはできますか？">
    現在、類似キーワード（シノニム）は自動的に除外されています。 将来的にはUI上で切り替えられるようにする予定です。
  </Accordion>
</AccordionGroup>
