## 概要

サイト関連キーワード分析は、指定したサイトやドメインに関連するキーワードを網羅的に取得し、検索ボリューム、CPC、競合レベルなどの詳細データを分析するツールです。

<Info>
  URLまたはドメインを入力するだけで、そのサイトに関連するキーワードの広告パフォーマンスデータを取得できます。
</Info>

### 主な用途

- **競合サイト分析**: 競合サイトがターゲットにしているキーワードを発見
- **SEO戦略立案**: 自社サイトに関連する検索キーワードの調査
- **広告戦略策定**: サイトに適した広告出稿キーワードの選定
- **コンテンツ企画**: ユーザーがサイトに求めるテーマの把握

## 料金

サイト関連キーワード分析は、1回の分析につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| サイト関連キーワード分析 | 15pt |

<Note>
  分析対象のサイトやキーワード数に関わらず、1回の分析につき**15ポイント固定**です。
</Note>

### ロケーション設定

| ロケーション | 説明 |
|-------------|------|
| 日本 | 日本国内での検索データを取得（デフォルト） |
| アメリカ | 米国内での検索データを取得 |

### 言語設定

| 言語 | 説明 |
|------|------|
| 日本語 | 日本語キーワードの分析に最適化（デフォルト） |
| 英語 | 英語キーワードの分析に最適化 |

### オプション設定

| オプション | 説明 |
|-----------|------|
| 検索パートナーを含む | Google検索パートナーサイトのデータを分析に含める |
| アダルトキーワードを含む | アダルト関連キーワードを結果に含める |

<Tip>
  日本市場向けのサイト分析では、「日本」「日本語」の組み合わせがおすすめです。
</Tip>

## 出力指標

分析結果では以下の指標が表示されます。

<CardGroup cols={2}>
  <Card title="キーワード" icon="key">
    サイトに関連する検索キーワード
  </Card>
  <Card title="検索ボリューム" icon="chart-bar">
    月間の平均検索回数
  </Card>
  <Card title="CPC" icon="yen-sign">
    平均クリック単価（日本円表示）
  </Card>
  <Card title="競合レベル" icon="gauge-high">
    広告出稿の競合状況（Low/Medium/High）
  </Card>
</CardGroup>

### 詳細指標

| 指標 | 説明 |
|------|------|
| キーワード | サイトに関連する検索キーワード |
| 検索ボリューム | 月間の平均検索回数 |
| CPC | 平均クリック単価（リアルタイム為替レートで円換算） |
| 競合レベル | Low（低）/ Medium（中）/ High（高）の3段階 |
| 競合指数 | 競合の激しさを0〜100%で数値化 |
| 最小入札額 | 検索結果上部に表示されるための最低入札価格（円） |
| 最大入札額 | 検索結果上部に表示されるための推奨入札価格（円） |

### 競合レベルの見方

| レベル | 表示色 | 説明 |
|--------|--------|------|
| Low | 緑 | 広告出稿の競合が少ない。参入しやすいキーワード |
| Medium | 黄 | 中程度の競合。バランスの取れた競争状況 |
| High | 赤 | 広告出稿の競合が激しい。高い入札額が必要な可能性 |

<Info>
  CPC、最小入札額、最大入札額は、リアルタイムの為替レートで日本円に変換して表示されます。
</Info>

## 利用手順

<Steps>
  <Step title="URL/ドメインの入力">
    分析したいサイトのURLまたはドメインを入力します。

    **入力例:**
    - `https://example.com`
    - `example.com`
    - `https://example.com/category/page/`

    <Note>
      完全なURLとドメイン名、どちらでも分析可能です。
    </Note>
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて、ロケーション、言語、その他のオプションを設定します。

    **推奨設定:**
    - 日本向けサイト: ロケーション「日本」、言語「日本語」
    - 海外向けサイト: ロケーション「アメリカ」、言語「英語」
  </Step>
  <Step title="分析開始">
    「サイト関連キーワード分析を開始」ボタンをクリックして分析を実行します。

    <Warning>
      分析には15ポイント消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、関連キーワードの一覧が表示されます。各列のヘッダーをクリックすることで、データをソートできます。
  </Step>
  <Step title="CSV出力（任意）">
    「CSV出力」ボタンから分析結果をダウンロードできます。
  </Step>
</Steps>

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、サンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータの内容:**
- サンプルサイトに関連するキーワード一覧
- 検索ボリューム、CPC、競合レベルなどの表示形式確認
- ソート機能の動作確認

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## 活用例

### 競合サイト分析

競合サイトのURLを入力することで、競合がターゲットにしているキーワードを発見できます。

1. 競合サイトのドメインを入力
2. 取得したキーワードリストを確認
3. 検索ボリュームの高いキーワードを特定
4. 自社サイトのコンテンツ戦略に活用

### SEOコンテンツ企画

自社サイトを分析して、関連性の高いコンテンツテーマを発見できます。

1. 自社サイトのURLを入力
2. 関連キーワードの検索ボリュームを確認
3. 競合レベルの低い（Low）キーワードを優先的にリストアップ
4. 記事やコンテンツのテーマとして活用

### 広告キーワード選定

リスティング広告のキーワード選定に活用できます。

1. ランディングページのURLを入力
2. CPC（クリック単価）と競合レベルを確認
3. 費用対効果の高いキーワードを選定
4. 最小入札額・最大入札額を参考に予算を策定

## よくある質問

<AccordionGroup>
  <Accordion title="URLとドメインの違いは何ですか？">
    どちらを入力しても分析可能です。
    - **URL**: 特定のページに関連するキーワードを取得（例: `https://example.com/products/`）
    - **ドメイン**: サイト全体に関連するキーワードを取得（例: `example.com`）

    より幅広いキーワードを取得したい場合は、ドメインのみの入力がおすすめです。
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常、10〜30秒程度で分析が完了します。
    サイトの規模や関連キーワードの数によっては、1分程度かかる場合があります。
  </Accordion>
  <Accordion title="同じサイトを再分析するとポイントは消費されますか？">
    はい、再分析ごとに15ポイントが消費されます。
    ただし、12時間以内であれば過去の分析結果を履歴から参照することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="取得できるキーワード数に上限はありますか？">
    サイトの規模や関連性によって、取得できるキーワード数は変動します。
    通常、数十〜数百件のキーワードが取得されます。
  </Accordion>
  <Accordion title="ロケーション設定はどちらを選べばいいですか？">
    ターゲットとする市場に合わせて選択してください。
    - 日本市場向けのサイト: 「日本」
    - 海外（英語圏）向けのサイト: 「アメリカ」

    異なるロケーションで分析することで、地域ごとの検索傾向の違いを確認することもできます。
  </Accordion>
  <Accordion title="CPCや入札額の通貨は何ですか？">
    画面上の表示はすべて日本円（¥）です。
    リアルタイムの為替レートを使用して、元のUSDデータから自動変換しています。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。
    Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
  <Accordion title="検索パートナーとは何ですか？">
    Google検索パートナーとは、Googleの検索ネットワークに参加しているサイト（Google以外の検索エンジンやポータルサイトなど）です。
    このオプションを有効にすると、パートナーサイトでの検索データも含めた分析結果が得られます。
  </Accordion>
</AccordionGroup>
