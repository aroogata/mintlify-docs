## 概要

関連キーワード分析は、入力したキーワードに関連する類似キーワードを網羅的に取得し、検索ボリューム、CPC、競合レベルなどの詳細データを分析するツールです。

<Info>
  キーワードを入力するだけで、そのキーワードに関連する類似キーワードの広告パフォーマンスデータを取得できます。
</Info>

### 主な用途

- **キーワード拡張**: ターゲットキーワードから関連キーワードを発見
- **SEOコンテンツ企画**: メインキーワードに関連するサブキーワードの調査
- **広告戦略立案**: 関連キーワードの広告出稿可能性を評価
- **競合調査**: 関連キーワードの競争状況を把握

## 料金

関連キーワード分析は、1回の分析につき固定ポイントを消費します。

| 操作 | 消費ポイント |
|------|-------------|
| 関連キーワード分析 | 15pt |

<Note>
  分析するキーワード数に関わらず、1回の分析につき**15ポイント固定**です。
</Note>

### キーワード入力

| 項目 | 仕様 |
|------|------|
| 入力形式 | 改行区切り または カンマ区切り |
| 最大キーワード数 | **20個** |
| 入力例 | `Webマーケティング`<br/>`SEO対策`<br/>`コンテンツマーケティング` |

<Warning>
  キーワードは**最大20個まで**入力可能です。21個以上のキーワードを分析したい場合は、複数回に分けて実行してください。
</Warning>

### ロケーション設定

| ロケーション | 説明 |
|-------------|------|
| 日本 | 日本国内での検索データを取得（デフォルト） |
| アメリカ | 米国内での検索データを取得 |

### 言語設定

| 言語 | 説明 |
|------|------|
| 日本語 | 日本語キーワードの分析に最適化（デフォルト） |
| 英語 | 英語キーワードの分析に最適化 |

### オプション設定

| オプション | 説明 |
|-----------|------|
| 検索パートナーを含む | Google検索パートナーサイトのデータを分析に含める |
| アダルトキーワードを含む | アダルト関連キーワードを結果に含める |

<Tip>
  日本市場向けのキーワード分析では、「日本」「日本語」の組み合わせがおすすめです。
</Tip>

## 出力指標

分析結果では以下の指標が表示されます。

<CardGroup cols={2}>
  <Card title="キーワード" icon="key">
    入力キーワードに関連する類似キーワード
  </Card>
  <Card title="検索ボリューム" icon="chart-bar">
    月間の平均検索回数
  </Card>
  <Card title="CPC" icon="yen-sign">
    平均クリック単価（日本円表示）
  </Card>
  <Card title="競合レベル" icon="gauge-high">
    広告出稿の競合状況（Low/Medium/High）
  </Card>
</CardGroup>

### 詳細指標

| 指標 | 説明 |
|------|------|
| キーワード | 入力キーワードに関連する類似キーワード |
| 検索ボリューム | 月間の平均検索回数 |
| CPC | 平均クリック単価（リアルタイム為替レートで円換算） |
| 競合レベル | Low（低）/ Medium（中）/ High（高）の3段階 |
| 競合指数 | 競合の激しさを0〜100%で数値化 |
| 最小入札額 | 検索結果上部に表示されるための最低入札価格（円） |
| 最大入札額 | 検索結果上部に表示されるための推奨入札価格（円） |

### 競合レベルの見方

| レベル | 表示色 | 説明 |
|--------|--------|------|
| Low | 緑 | 広告出稿の競合が少ない。参入しやすいキーワード |
| Medium | 黄 | 中程度の競合。バランスの取れた競争状況 |
| High | 赤 | 広告出稿の競合が激しい。高い入札額が必要な可能性 |

<Info>
  CPC、最小入札額、最大入札額は、リアルタイムの為替レートで日本円に変換して表示されます。
</Info>

## 利用手順

<Steps>
  <Step title="キーワードの入力">
    分析したいキーワードを入力します。

    **入力方法:**
    - 1キーワードずつ改行で区切る
    - カンマ区切りで複数入力

    **入力例:**
    ```
    Webマーケティング
    SEO対策
    コンテンツマーケティング
    ```

    <Note>
      最大20キーワードまで一度に分析できます。
    </Note>
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて、ロケーション、言語、その他のオプションを設定します。

    **推奨設定:**
    - 日本市場向け: ロケーション「日本」、言語「日本語」
    - 海外市場向け: ロケーション「アメリカ」、言語「英語」
  </Step>
  <Step title="分析開始">
    「関連キーワード分析を開始」ボタンをクリックして分析を実行します。

    <Warning>
      分析には15ポイント消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、関連キーワードの一覧が表示されます。各列のヘッダーをクリックすることで、データをソートできます。
  </Step>
  <Step title="CSV出力（任意）">
    「CSV出力」ボタンから分析結果をダウンロードできます。
  </Step>
</Steps>

## サンプル機能

ポイントを消費せずに関連キーワード分析機能を体験できます。

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、サンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータの内容:**
- サンプルキーワードに関連するキーワード一覧
- 検索ボリューム、CPC、競合レベルなどの表示形式確認
- ソート機能の動作確認

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。
  必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## 活用例

### キーワード拡張・発見

メインキーワードから関連キーワードを発見し、ターゲットを拡大できます。

1. メインキーワードを入力（例：「ダイエット」「筋トレ」）
2. 取得した関連キーワードリストを確認
3. 検索ボリュームの高いキーワードを特定
4. 広告やコンテンツのターゲットキーワードとして活用

### SEOコンテンツ企画

記事のサブキーワードやロングテールキーワードを発見できます。

1. 記事のメインキーワードを入力
2. 関連キーワードの検索ボリュームを確認
3. 競合レベルの低い（Low）キーワードを優先的にリストアップ
4. 見出しや本文のキーワードとして活用

### 広告キーワード拡張

リスティング広告のキーワードリストを拡張できます。

1. 現在出稿中のキーワードを入力
2. CPC（クリック単価）と競合レベルを確認
3. 費用対効果の高い関連キーワードを選定
4. 最小入札額・最大入札額を参考に予算を策定

## よくある質問

<AccordionGroup>
  <Accordion title="入力できるキーワード数の上限は？">
    最大20キーワードまで一度に分析できます。
    21個以上のキーワードを分析したい場合は、複数回に分けて実行してください。
    キーワード数に関わらず、1回の分析につき15ポイント固定です。
  </Accordion>
  <Accordion title="検索ボリューム分析との違いは？">
    **関連キーワード分析**:
    - 入力キーワードに「関連する別のキーワード」を発見するツール
    - 最大20キーワード入力可能
    - キーワード拡張・発見に最適

    **検索ボリューム分析**:
    - 入力したキーワード「そのもの」の検索データを取得するツール
    - 最大1000キーワード入力可能
    - 既知のキーワードの詳細データ確認に最適
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常、10〜30秒程度で分析が完了します。
    キーワードの数や関連キーワードの量によっては、1分程度かかる場合があります。
  </Accordion>
  <Accordion title="同じキーワードを再分析するとポイントは消費されますか？">
    はい、再分析ごとに15ポイントが消費されます。
    ただし、12時間以内であれば過去の分析結果を履歴から参照することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="どのようなキーワードを入力すればいいですか？">
    以下のようなキーワードが効果的です：
    - ビジネスや商品に関連するメインキーワード
    - 広告やSEOでターゲットにしたいキーワード
    - 競合が出稿しているキーワード

    具体的で検索ボリュームがあるキーワードを入力すると、より多くの関連キーワードが取得できます。
  </Accordion>
  <Accordion title="ロケーション設定はどちらを選べばいいですか？">
    ターゲットとする市場に合わせて選択してください。
    - 日本市場向けのキーワード: 「日本」
    - 海外（英語圏）向けのキーワード: 「アメリカ」

    異なるロケーションで分析することで、地域ごとの検索傾向の違いを確認することもできます。
  </Accordion>
  <Accordion title="CPCや入札額の通貨は何ですか？">
    画面上の表示はすべて日本円（¥）です。
    リアルタイムの為替レートを使用して、元のUSDデータから自動変換しています。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。
    Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
  <Accordion title="検索パートナーとは何ですか？">
    Google検索パートナーとは、Googleの検索ネットワークに参加しているサイト（Google以外の検索エンジンやポータルサイトなど）です。
    このオプションを有効にすると、パートナーサイトでの検索データも含めた分析結果が得られます。
  </Accordion>
</AccordionGroup>
