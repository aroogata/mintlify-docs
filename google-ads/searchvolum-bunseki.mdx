## 概要

検索ボリューム分析は、指定したキーワードの月間検索ボリューム、クリック単価（CPC）、競合レベルなどの詳細データを取得し、広告やSEO戦略に活用できるツールです。

<Info>
  キーワードを入力するだけで、Google Adsのデータに基づいた検索ボリューム・競合状況を即座に取得できます。
</Info>

### 主な用途

- **キーワード調査**: ターゲットキーワードの検索需要を把握
- **広告戦略策定**: CPCと競合レベルから広告予算を算出
- **SEOコンテンツ企画**: 検索ボリュームに基づいた記事テーマ選定
- **市場分析**: キーワードの季節変動・トレンドを確認

## 料金

検索ボリューム分析は、1回の分析につき固定ポイントを消費します。

| 操作        | 消費ポイント |
| --------- | ------ |
| 検索ボリューム分析 | 15pt   |

<Note>
  分析するキーワード数に関わらず、1回の分析につき**15ポイント固定**です。 1キーワードでも1000キーワードでも同じ料金です。
</Note>

## 入力オプション

分析時に以下のオプションを設定できます。

<CardGroup cols={2}>
  <Card title="キーワード" icon="keyboard">

    日本またはアメリカを選択。対象地域の検索データを取得

    日本語または英語を選択。対象言語のキーワードデータを取得
  </Card>

### キーワード入力

| 項目       | 仕様                                |
| -------- | --------------------------------- |
| 入力形式     | 改行区切り または カンマ区切り                  |
| 最大キーワード数 | 1000個                             |
| 入力例      | `クレジットカード`<br />`住宅ローン`<br />`投資` |

<Tip>
  複数のキーワードを分析する場合は、各キーワードを改行で区切って入力するのがおすすめです。
</Tip>

### ロケーション設定

| ロケーション | 説明                    |
| ------ | --------------------- |
| 日本     | 日本国内での検索データを取得（デフォルト） |
| アメリカ   | 米国内での検索データを取得         |

### 言語設定

| 言語  | 説明                     |
| --- | ---------------------- |
| 日本語 | 日本語キーワードの分析に最適化（デフォルト） |
| 英語  | 英語キーワードの分析に最適化         |

### ソート順設定

| ソート順        | 説明                   |
| ----------- | -------------------- |
| 関連性         | 入力キーワードとの関連性順（デフォルト） |
| 検索ボリューム     | 月間検索回数の多い順           |
| 競合レベル       | 競合の激しさ順              |
| CPC（クリック単価） | クリック単価の高い順           |

### オプション設定

| オプション        | 説明                          |
| ------------ | --------------------------- |
| 検索パートナーを含む   | Google検索パートナーサイトのデータを分析に含める |
| アダルトキーワードを含む | アダルト関連キーワードを結果に含める          |

  </Card>
  <Card title="検索ボリューム" icon="chart-bar">
    月間の平均検索回数
  </Card>
  <Card title="CPC" icon="dollar-sign">
    平均クリック単価（USD表示）

  <Card title="競合レベル" icon="gauge-high">
    広告出稿の競合状況（Low/Medium/High）
  </Card>

### 詳細指標

| 指標      | 説明                             |
| ------- | ------------------------------ |
| キーワード   | 分析対象のキーワード                     |
| 検索ボリューム | 月間の平均検索回数                      |
| CPC     | 平均クリック単価（USD表示）                |
| 競合レベル   | Low（低）/ Medium（中）/ High（高）の3段階 |
| 競合指数    | 競合の激しさを0〜100%で数値化              |

### 競合レベルの見方

| レベル    | 表示色 | 説明                       |
| ------ | --- | ------------------------ |
| Low    | 緑   | 広告出稿の競合が少ない。参入しやすいキーワード  |
| Medium | 黄   | 中程度の競合。バランスの取れた競争状況      |
| High   | 赤   | 広告出稿の競合が激しい。高い入札額が必要な可能性 |

## 表示モード

分析結果は2つのモードで確認できます。

<Tabs>
  <Tab title="データ表">
    すべてのキーワードを一覧表形式で表示します。

    **特徴:**

    - キーワード、検索ボリューム、CPC、競合レベル、競合指数を一覧表示
    - 各列のヘッダーをクリックしてソート可能
    - CSV出力に対応

    **おすすめ用途:**

    - 複数キーワードの比較
    - 詳細な数値の確認
    - データのエクスポート
  </Tab>
  <Tab title="時系列グラフ">
    各キーワードの月別検索ボリューム推移をグラフで表示します。

    **特徴:**

    - 過去12ヶ月の検索ボリューム推移を可視化
    - 季節変動やトレンドを把握
    - キーワードごとに個別のグラフを表示

    **おすすめ用途:**

    - 季節性の確認
    - トレンドキーワードの発見
    - 検索需要の変動分析

    <Note>
      月別データがAPIから提供されていない場合、グラフは表示されません。
    </Note>
  </Tab>
</Tabs>

## 利用手順

<Steps>
  <Step title="キーワードの入力">
    分析したいキーワードを入力します。

    **入力方法:**

    - 1キーワードずつ改行で区切る
    - カンマ区切りで複数入力

    **入力例:**

    ```
    クレジットカード
    住宅ローン
    投資信託
    ```

    <Tip>
      最大1000キーワードまで一度に分析できます。
    </Tip>
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて、ロケーション、言語、ソート順、その他のオプションを設定します。

    **推奨設定:**

    - 日本市場向け: ロケーション「日本」、言語「日本語」
    - 海外市場向け: ロケーション「アメリカ」、言語「英語」
  </Step>
  <Step title="分析開始">
    「検索ボリューム分析を開始」ボタンをクリックして分析を実行します。

    <Warning>
      分析には15ポイント消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、データ表または時系列グラフで結果を確認します。 各列のヘッダーをクリックすることで、データをソートできます。
  </Step>
  <Step title="CSV出力（任意）">
    「CSV出力」ボタンから分析結果をダウンロードできます。
  </Step>
</Steps>

## サンプル機能

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、サンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータの内容:**

- サンプルキーワードの検索ボリューム・CPC・競合レベル
- データ表・時系列グラフの表示形式確認
- ソート機能の動作確認

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。 必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## 活用例

### 広告キーワード選定

リスティング広告のキーワード選定に活用できます。

1. 候補キーワードをまとめて入力
2. 検索ボリュームとCPCを確認
3. 競合レベルがLow〜Mediumのキーワードを選定
4. CPCを参考に広告予算を策定

### SEOコンテンツ企画

ブログ記事やコンテンツのテーマ選定に活用できます。

1. ターゲット領域の関連キーワードを入力
2. 検索ボリュームの高いキーワードを特定
3. 競合レベルがLowのキーワードを優先
4. 記事のメインキーワード・サブキーワードとして活用

### 季節トレンド分析

時系列グラフを使って、キーワードの季節変動を分析できます。

1. 分析したいキーワードを入力
2. 「時系列グラフ」タブを選択
3. 月別の検索ボリューム推移を確認
4. ピーク時期に合わせたコンテンツ・広告戦略を立案

## よくある質問

<AccordionGroup>
  <Accordion title="何キーワードまで一度に分析できますか？">
    最大1000キーワードまで一度に分析できます。 キーワード数に関わらず、1回の分析につき15ポイント固定です。
  </Accordion>
  <Accordion title="分析にどのくらい時間がかかりますか？">
    通常、数秒〜30秒程度で分析が完了します。 キーワード数が多い場合は、1分程度かかることがあります。
  </Accordion>
  <Accordion title="CPCの通貨は何ですか？">
    CPCはUSD（米ドル）で表示されます。 日本円に換算する場合は、表示金額に現在の為替レートを掛けてください。
  </Accordion>
  <Accordion title="時系列グラフが表示されない場合は？">
    月別の詳細データがAPIから提供されていない場合、グラフは表示されません。 これはキーワードによって異なり、検索ボリュームが少ないキーワードでは月別データが提供されないことがあります。
  </Accordion>
  <Accordion title="同じキーワードを再分析するとポイントは消費されますか？">
    はい、再分析ごとに15ポイントが消費されます。 ただし、12時間以内であれば過去の分析結果を履歴から参照することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="ロケーション設定はどちらを選べばいいですか？">
    ターゲットとする市場に合わせて選択してください。

    - 日本市場向けのキーワード: 「日本」
    - 海外（英語圏）向けのキーワード: 「アメリカ」

    同じキーワードでも、地域によって検索ボリュームやCPCが異なります。
  </Accordion>
  <Accordion title="ソート順はどれを選べばいいですか？">
    目的に応じて選択してください。

    - 検索需要を把握したい: 「検索ボリューム」
    - 広告費用を把握したい: 「CPC（クリック単価）」
    - 参入しやすさを把握したい: 「競合レベル」
    - 入力順に近い形で確認したい: 「関連性」
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。 Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
</AccordionGroup>
