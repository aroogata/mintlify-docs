## 概要

広告トラフィック予測分析は、指定したキーワードと入札価格に基づいて、Google広告のトラフィック（インプレッション、クリック数）、費用、CTRなどを予測するツールです。

<Info>
  キーワードと入札価格を入力するだけで、広告出稿時の期待パフォーマンスを事前にシミュレーションできます。
</Info>

### 主な用途

- **広告予算策定**: 入札価格と期待トラフィックから広告費用を試算
- **ROI予測**: クリック数と費用から費用対効果を事前に評価
- **入札戦略立案**: 最適な入札価格の検討
- **キーワード選定**: 複数キーワードのパフォーマンス比較

| 操作           | 消費ポイント |
| ------------ | ------ |

### キーワード入力

| 項目       | 仕様                                      |
| -------- | --------------------------------------- |
| 入力形式     | 改行区切り または カンマ区切り                        |
| 最大キーワード数 | **20個**                                 |
| 入力例      | `WEBマーケティング`<br />`デジタル広告`<br />`SEO対策` |

<Warning>
  キーワードは**最大20個まで**入力可能です。21個以上のキーワードを分析したい場合は、複数回に分けて実行してください。
</Warning>

### 入札価格設定

| 項目    | 仕様                |
| ----- | ----------------- |
| 入力単位  | 日本円（¥）            |
| 最小値   | 1円                |
| 最大値   | 149,850円（\$999相当） |
| デフォルト | 999円              |

<Info>
  入力された円価格は、リアルタイムの為替レートでUSDに変換されてAPIに送信されます。 結果表示時には再度円に変換して表示されます。
</Info>

### マッチタイプ設定

| マッチタイプ | 説明                         |
| ------ | -------------------------- |
| 完全一致   | キーワードと完全に一致する検索のみ対象（デフォルト） |
| 部分一致   | キーワードに関連する幅広い検索も対象         |
| フレーズ一致 | キーワードを含むフレーズの検索が対象         |

<Tip>
  **完全一致**は精度が高く、**部分一致**はリーチが広くなります。目的に応じて使い分けてください。
</Tip>

### 対象期間設定

| 期間 | 説明                  |
| --- | ------------------- |
| 来月 | 翌月1ヶ月間の予測データ（デフォルト） |
| 来週 | 翌週1週間の予測データ         |
| 今月 | 当月の残り期間の予測データ       |
| 今週 | 当週の残り期間の予測データ       |

### 詳細指標

| 指標       | 説明               |
| -------- | ---------------- |
| キーワード    | 分析対象のキーワード       |
| インプレッション | 広告が表示される予測回数     |
| クリック数    | 広告がクリックされる予測回数   |

### 指標の見方

| 指標       | 高い値の意味      | 活用方法           |
| -------- | ----------- | -------------- |
| インプレッション | 多くの露出が期待できる | ブランド認知向上に効果的   |
| クリック数    | 多くの流入が期待できる | コンバージョン獲得に有効   |
| CTR      | 広告の訴求力が高い   | 広告文やターゲティングが適切 |
| 平均CPC    | 競争が激しい      | 予算管理に注意が必要     |

<Info>
  すべての金額はリアルタイムの為替レートで日本円に変換して表示されます。
</Info>

## 利用手順

<Steps>
  <Step title="キーワードの入力">
    広告を出稿したいキーワードを入力します。

    **入力方法:**

    - 1キーワードずつ改行で区切る
    - カンマ区切りで複数入力

    **入力例:**

    ```
    WEBマーケティング
    デジタル広告
    SEO対策
    ```

    <Note>
      最大20キーワードまで一度に分析できます。
    </Note>
  </Step>
  <Step title="入札価格の設定">
    シミュレーションしたい入札価格を円単位で入力します。

    **入札価格の目安:**

    - 低競合キーワード: 50〜200円
    - 中競合キーワード: 200〜500円
    - 高競合キーワード: 500〜2,000円以上

    <Tip>
      複数の入札価格でシミュレーションして、最適な入札額を見つけましょう。
    </Tip>
  </Step>
  <Step title="マッチタイプ・期間の設定">
    広告のマッチタイプと予測対象期間を選択します。

    **推奨設定:**

    - 初めての場合: 完全一致 + 来月
    - リーチ重視: 部分一致 + 来月
    - 短期キャンペーン: 完全一致 + 来週
  </Step>
  <Step title="オプション設定（任意）">
    必要に応じて、ロケーション、言語、検索パートナーのオプションを設定します。

    **推奨設定:**

    - 日本市場向け: ロケーション「日本」、言語「日本語」
    - 海外市場向け: ロケーション「アメリカ」、言語「英語」
  </Step>
  <Step title="分析開始">
    「広告トラフィック予測分析を開始」ボタンをクリックして分析を実行します。

    <Warning>
      分析には15ポイント消費されます。十分なポイント残高があることを確認してください。
    </Warning>
  </Step>
  <Step title="結果の確認">
    分析完了後、各キーワードの予測パフォーマンスが表示されます。 各列のヘッダーをクリックすることで、データをソートできます。
  </Step>
  <Step title="CSV出力（任意）">
    「CSV出力」ボタンから分析結果をダウンロードできます。
  </Step>
</Steps>

## サンプル機能

ポイントを消費せずに広告トラフィック予測分析機能を体験できます。

<Info>
  「サンプル分析結果を見る」ボタンをクリックすると、サンプルデータで分析結果の表示形式を確認できます。
</Info>

**サンプルデータの内容:**

- サンプルキーワードの予測パフォーマンス
- インプレッション、クリック数、CTR、費用などの表示形式確認
- ソート機能の動作確認

## 結果の保持

<Warning>
  分析結果は**12時間**保持されます。12時間経過後、結果は自動的に削除されます。 必要な結果はCSVファイルとしてダウンロードしてください。
</Warning>

- **保持期間**: 12時間
- **最大保持件数**: 50件（ユーザーあたり）
- **保存方法**: CSVファイルをダウンロード

## 活用例

### 広告予算の策定

新規広告キャンペーンの予算を策定する際に活用できます。

1. 出稿予定のキーワードを入力
2. 想定入札価格を設定
3. 予測される総費用を確認
4. 月間予算・日予算を逆算して策定

### 入札価格の最適化

最適な入札価格を見つけるために活用できます。

1. 同じキーワードで異なる入札価格を試す
2. 入札価格ごとのクリック数・CTRを比較
3. 費用対効果が最も高い入札価格を特定
4. 実際の広告運用に反映

### キーワード選定

複数キーワードのパフォーマンスを比較して選定できます。

1. 候補キーワードをまとめて入力
2. 同じ入札価格での予測パフォーマンスを比較
3. CTR・クリック数が高いキーワードを優先
4. 広告グループのキーワードとして採用

### マッチタイプの検討

マッチタイプによるパフォーマンスの違いを確認できます。

1. 同じキーワード・入札価格で分析
2. 完全一致・部分一致・フレーズ一致を比較
3. リーチとコストのバランスを検討
4. 最適なマッチタイプを選択

## よくある質問

<AccordionGroup>
  <Accordion title="予測と実際の結果は一致しますか？">
    予測値は過去のデータに基づく推定であり、実際の結果とは異なる場合があります。 季節要因、競合状況、広告品質などによって実際のパフォーマンスは変動します。 あくまで目安として活用し、実際の広告運用では継続的な最適化を行ってください。
  </Accordion>
  <Accordion title="入札価格の上限はいくらですか？">
    入札価格の上限は149,850円（\$999相当）です。 為替レートによって円換算の上限は変動します。
  </Accordion>
  <Accordion title="マッチタイプはどれを選べばいいですか？">
    目的に応じて選択してください：

    - **完全一致**: 精度重視、予算を抑えたい場合
    - **部分一致**: リーチ重視、新規キーワード発見したい場合
    - **フレーズ一致**: 両者のバランスを取りたい場合

    迷った場合は「完全一致」から始めることをおすすめします。
  </Accordion>
  <Accordion title="対象期間はどれを選べばいいですか？">
    - **来月**: 翌月のキャンペーン計画に最適（デフォルト）
    - **今月**: 今すぐ出稿開始する場合
    - **来週/今週**: 短期キャンペーンの計画に

    通常は「来月」を選択し、1ヶ月単位での計画立案をおすすめします。
  </Accordion>
  <Accordion title="同じキーワードを再分析するとポイントは消費されますか？">
    はい、再分析ごとに15ポイントが消費されます。 ただし、12時間以内であれば過去の分析結果を履歴から参照することで、ポイント消費を避けられます。
  </Accordion>
  <Accordion title="他のGoogle Ads分析機能との違いは？">
    **広告トラフィック予測分析**:

    - 入札価格を指定して広告パフォーマンスを**予測**
    - インプレッション、クリック数、費用を事前にシミュレーション
    - 広告予算策定・入札戦略に最適

    **検索ボリューム分析**:

    - キーワードの**現在**の検索ボリュームやCPCを取得
    - キーワード調査・市場分析に最適

    **関連キーワード分析**:

    - 入力キーワードに関連する**別のキーワード**を発見
    - キーワード拡張・発見に最適
  </Accordion>
  <Accordion title="CPCや費用の通貨は何ですか？">
    画面上の表示はすべて日本円（¥）です。 リアルタイムの為替レートを使用して、元のUSDデータから自動変換しています。
  </Accordion>
  <Accordion title="CSV出力で文字化けする場合はどうすればいいですか？">
    CSV出力はUTF-8 BOM形式で行われます。 Excelで開く場合は、「データ」→「テキストから」でインポートし、文字コードを「UTF-8」に指定してください。
  </Accordion>
  <Accordion title="検索パートナーとは何ですか？">
    Google検索パートナーとは、Googleの検索ネットワークに参加しているサイト（Google以外の検索エンジンやポータルサイトなど）です。 このオプションを有効にすると、パートナーサイトでの配信を含めた予測結果が得られます。
  </Accordion>
</AccordionGroup>
